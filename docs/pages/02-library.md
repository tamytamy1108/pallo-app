# 라이브러리

> **제안 경로:** `/library?map=:id`, `/library/:level/:lesson`, `/library/book/:id`, `/library/:level/:lesson/listen`
> **모듈:** 라이브러리 · **기준:** v342
> 관련 코드: `renderStudyLib`, `MAP_LIST`, `LIB`, `STUDY_LV`, `STUDY_STEPS`, `SITS`, `SIT_SOON`, `openStudy`, `openListen`, `LESSON_INFO`

## 개요

교재와 상황별 학습을 고르는 곳이에요. **① 맵 칩 → ② 섬 지도 → ③ 과(장면) 목록** 순서로 내려가고, 과를 누르면 과 화면(예습 · 본학습 · 복습)이 오른쪽에서 밀려 들어와요. 문제 풀이 자체는 [레슨](./03-lesson.md) 문서에 있어요.

## 화면 구성

### ① 맵 칩 (위 줄)

| 묶음 | 칩 | 비고 |
|---|---|---|
| 커리큘럼 맵 | 영어 · 일본어 · 중국어 · 스페인어 | 언어 색 |
| 상황 맵 | 여행 · 비즈니스 · 카페 | 새 맵은 분홍 점 |
| 곧 열릴 맵 | 새 맵 · 준비 중 (주제 · 일정 미정) | 점선. 누르면 알림 안내 |

### ② 커리큘럼 섬 지도

- **레벨 = 섬.** 아래에서 위로 뱃길을 따라 Lv.0 → Lv.4.
- 섬마다 표시: Lv.0 새싹 · Lv.1 야자수 · Lv.2 빨간 지붕 집 · Lv.3 깃발 꽂힌 산 · Lv.4 등대.
- 섬 색(v207): Lv.1 틸 `#4FB6A6` · Lv.2 라일락 `#9C8BDB` · Lv.3 핑크 `#E890A6` · Lv.4 앰버 `#F5B850` · Lv.0 연두 `#9ED48A`. 위는 밝고 아래는 어두운 음영.
- 섬 아래 이름표에 진도(끝낸 과 / 전체). 고른 섬은 노랑 테두리가 깜빡이고, 내 교재 섬에는 팔로가 서 있어요.
- 데이터가 없는 섬: 양옆 작은 구름 + 흰 자물쇠 배지, '이 섬은 아직 구름에 가려 있어요' → [교재 소개 보기].
- 파도 · 배가 살짝 움직여요 (동작 줄이기면 멈춤).

### ② 상황 섬 지도

- **장면 = 섬 위 정류장.** 길을 따라 장면이 이어지고, 끝낸 장면은 체크 도장, 다음 장면은 START + 팔로, 아직 없는 장면은 점선(곧 열려요).

### ③ 아래 카드

- 커리큘럼: 고른 레벨의 과 목록 (처음부터 전부 보임, 접기 없음). 각 줄에 예습 · 본학습 · 복습 진도 점. 데이터 없는 과는 제목 · 패턴과 함께 '준비 중'.
- 상황 맵: 장면 목록.
- 레벨 카드에서 '리스닝 룸'(그 레벨 전체 문장)으로 들어갈 수 있어요.

## 지금 들어 있는 데이터

| 언어 | 레벨 | 교재 | 문제 데이터 |
|---|---|---|---|
| 영어 | Lv.0 | HELLO ENGLISH | 없음 (잠김) |
| 영어 | Lv.1 | EVERYDAY ENGLISH · 20과 (교재 4교 목차 전체) | **1과 Cafe Complaint** (`LV1_01`) |
| 영어 | Lv.2 | REAL ENGLISH · 20과 목차 | **1과 Not in the Mood** (`LV2_01`) |
| 영어 | Lv.3 | TOPIC TALK (이름 임시) | **#54 Activities / Digital detox** (`LV3_54`) · #89 · #47은 준비 중 |
| 영어 | Lv.4 | FREE TALK & DEBATE (이름 임시) | **1 Behind the Mask** (`LV4_HW`) · 2는 준비 중 |
| 일본어 | 레벨 0 · 0.5 · 1 · 2 | 日本語の花 · 旅 · 夢 (표지만) | 없음 |
| 중국어 · 스페인어 | — | — | 없음 |
| 상황 | 여행 | 8장면 중 3개 (공항 체크인 · 기내 주문 · 입국 심사) | 있음 |
| 상황 | 비즈니스 | 5장면 중 1개 (첫 미팅 자기소개) | 있음 |
| 상황 | 카페 | 3장면 중 1개 (주문 바꾸기) | 있음 |

**과 하나 = 데이터 객체 하나.** 같은 형식으로 넣으면 화면이 자동으로 생겨요. **새 상황 맵 = `SITS`에 객체 하나** (`id, title, series, c, about, lessons[]`, 장면은 `{ title, sub, icon, data: { expr, rp } }`, 열리기 전 맵은 `SIT_SOON`에 `{ id, title, when }`). 지도 · 칩 · 목록이 자동으로 생겨야 해요. 상황 맵은 계속 늘어나요.

## 과 화면

| 요소 | 내용 |
|---|---|
| 위 줄 | 왼쪽 `<`(라이브러리로) · 가운데 `LV.1 EVERYDAY ENGLISH ▾`(누르면 과 목록 시트) |
| 표지 · 제목 | 교재 표지, 과 제목, 한 줄 이야기(예: Lily invites Logan out on Saturday) · 교재 쪽 |
| 핵심 패턴 카드 | '이번 과 핵심 패턴' 3개 (영어 틀 + 우리말 뜻) — Lv.3 · 4는 '이번 회차 구성' |
| 탭 | 예습 · 본학습 · 복습 (`n/4`, `n/3`). 탭을 바꿔도 스크롤 위치 유지 |
| 단계 카드 | 이름 · 설명 · `n분 · +nP`. 다음 할 단계 = 연노랑 + '다음', 하다 만 단계 = '이어서', 끝낸 단계 = 체크(예습 노랑 · 본학습 분홍 · 복습 하늘) |
| 리스닝 룸 카드 | 보라 카드, 그 과 문장 |

## 레벨별 단계 구성

한 과 = **예습 → 본학습 → 복습.** 레벨마다 교재 구성이 달라서 단계가 달라요 (`STUDY_STEPS`). 아이스브레이킹 단계는 모든 레벨에서 뺐어요.

| 레벨 | 교재 구성 | 예습 (세션 전) | 본학습 (AI 대신 세션) | 복습 (세션 후) |
|---|---|---|---|---|
| Lv.1 · 2 패턴형 | 패턴 3개 + 대화문 + Word/Speaking Bank | 오늘의 패턴 (5분 · +5P) · 대화문 (6분 · +10P) · Bank 퀴즈 (3분 · +5P) | Lv.1: 상황 활동(Look, Find & Choose · 호텔 로비) · My Story · AI 프리토킹 / Lv.2: Not Today 역할극 · My Story · AI 프리토킹 | 스피킹 퀴즈 (+10P) · 1분 말하기 챌린지 (+10P) |
| Lv.3 토픽형 | DAILY TOPIC(질문 6 · 키워드 12) + TOPIC 지문 + USEFUL EXPRESSIONS + IMPROVEMENT | KEYWORDS 즉답 스프린트 · DAILY TOPIC 답변 준비 · TOPIC 지문 · USEFUL EXPRESSIONS | DAILY TOPIC 토론(AI 리더 Lily + 멤버 Mina · Jun) · IMPROVEMENT(회차마다 4유형 중 하나) · ACTIVITY(회차마다 형식) | VOCABULARY REVIEW · IMPROVEMENT 리라이트 · JOURNAL 말하는 일기 (+15P) · Before / After |
| Lv.4 디베이트형 | FREE TALK 5 + SAY IT BETTER + TWO SIDES 토론 + KEY EXPRESSIONS | FREE TALK 준비 · KEY EXPRESSIONS · 내 입장 정하기 | FREE TALK 1:1 · DEBATE(AI Logan, 3라운드) · FOLLOW-UP 질문 만들기 | SAY IT BETTER · 편 바꾸기 · FINAL POSITION + 즉흥 룰렛 |

- **본학습** = 세션 시간에 하는 활동을 앱에서 AI와 하는 버전이에요. 오프라인에 못 온 날이나 앱 구독자가 써요. 프로토타입은 대본이 정해진 대화이고, 실제 앱은 같은 자리에 AI 응답을 붙여요.
- **회차마다 바뀌는 양식 (Lv.3):** 회차 데이터의 `session` 한 칸만 바꿔요. `session.improvement.type` = `natural` · `grammar` · `pron` · `confuse`, `session.activity.format` = `guess` · `present` · `duo`.
- 교재에 뜻 · 해석이 없는 부분(Lv.3 키워드 뜻 · 지문 해석, Lv.4 KEY EXPRESSIONS 뜻 · 예문, Lv.2 Speaking Bank 빈칸 정답, 1분 챌린지 모범 답)은 프로토타입 예시예요 → Q-C2.

## 상황 맵 장면

장면 하나 = **표현 익히기(5개) → 상황 퀴즈(15문제) → AI 롤플레이.** 끝내면 지도에 도장.

상황 퀴즈는 장면마다 실제로 겪는 상황 15개로 만들어요. 같은 상황이라도 레벨에 따라 묻는 방식과 보기가 달라요. 퀴즈를 시작하면 먼저 난이도 화면이 나오고(내 레벨이 골라져 있어요), 고른 뒤에 들어가요. 결과 화면에서 '다른 난이도로 다시 풀기'로 돌아갈 수 있어요.

| 레벨 | 묻는 방식 | 오답 보기 |
|---|---|---|
| Lv.1 입문 | 한국어 뜻을 보고 표현 고르기 · 쉬운 빈칸 | 같은 장면의 다른 표현 (확실히 달라요) |
| Lv.2 기초 | 한국어 상황(+상대의 말)을 보고 표현 고르기 · 빈칸 | 비슷하지만 상황에 안 맞는 말 1개 + 다른 표현 |
| Lv.3 중급 | 상대의 영어 말을 듣고 답 고르기 (한국어 없음) | 그럴듯하지만 틀린 대답 2개 |
| Lv.4 고급 | 글자 없이 듣기만 하고 답 고르기 · 가장 자연스러운 말 고르기 | 그럴듯한 오답 + 한국어식 직역 표현 (lend/borrow, name card, consent 같은 함정) |

보기와 '다음 문제' 버튼은 화면 아래에 고정돼요. 답을 고르면 정답과 내가 고른 보기만 남아요.

## 교재 소개 (잠긴 교재)

표지 · 소개 · 목차(1과만 미리 보기) · [이 레벨 상담 신청] → 체험 신청 흐름(언어 미리 골라짐).

## 리스닝 룸

| 요소 | 내용 |
|---|---|
| 들어가는 곳 | 과 화면 보라 카드(그 과) · 레벨 카드(그 레벨 / 상황 맵 전체) |
| 문장 목록 | 과 데이터에서 자동으로 모아요 (`lrItemsOf`): Lv.1 · 2 패턴 예문 · 대화문 · Bank / Lv.3 키워드 예문 · 지문 · 자연스러운 표현 / Lv.4 FREE TALK 질문 · SAY IT BETTER · KEY 예문 / 상황 맵 표현 · 롤플레이 대사 |
| 위 보라 카드 (붙어 있음) | 지금 문장 크게 + 뜻 + 단계(영어 듣기 · 따라 말해 보세요 3·2·1 · 뜻 듣기) + 이전 · 재생/멈춤 · 다음 |
| 설정 칩 (기기에 남음) | 자동 재생 켬/끔 · 순서(영어→뜻 / 영어만 / 뜻→영어 = 통역 연습) · 따라 말하기(끔 / 2초 / 4초) · 반복(1~3번) · 속도(천천히 / 보통 / 빠르게) · 영어 가리기 · 섞기 |
| 재생 목록 칩 | 전체 · 패턴/파트별 · 저장한 문장(내 표현함) |
| 행 | 누르면 거기서부터 재생, 책갈피로 저장, 들은 문장 노랑 체크. 위 진행 바 = 들은 비율 |
| 소리 끄기 | 영어 가리기 꺼짐 |

뜻은 한국어 기기 음성으로 읽어요. 실서비스는 원어민 녹음 권장(Q-T5).

## 상호작용

- **맵 칩 누르기:** 지도와 아래 카드가 그 맵으로 바뀜.
- **섬 누르기:** 아래 카드가 그 레벨 과 목록으로 바뀌고 스크롤.
- **잠긴 섬 누르기:** 잠김 안내 + 교재 소개.
- **과 누르기:** 과 화면이 오른쪽에서 밀려 들어옴 (0.34초 · 동작 줄이기면 없음).
- **단계 카드 누르기:** 레슨 진행기 또는 단계 화면. 멈춘 곳이 있으면 '이어서 할까요?' [이어서 하기 / 처음부터 시작하기].
- **곧 열릴 맵 누르기:** '12월에 열려요' 알림 안내.

## 화면 연결

- **오는 곳:** 하단 탭, 홈 스터디 맵(정류장 · 전체 보기), 마이 '다음 세션 · 예습하기', 알림(예습 남음), 공지 버튼.
- **가는 곳:** 과 화면 → 레슨, 리스닝 룸, 교재 소개 → 체험 신청.
- **데이터 연결:** 진도 · 멈춘 위치는 홈 스터디 맵 · 마이와 공유. 저장한 문장은 내 표현함.

## 수용 기준

- [ ] 맵 칩에 커리큘럼 4개 언어 · 상황 맵 · 곧 열릴 맵이 데이터대로 나온다.
- [ ] 상황 맵 하나를 데이터로 추가하면 칩 · 지도 · 목록이 코드 수정 없이 생긴다.
- [ ] 데이터가 없는 레벨은 잠긴 섬, 데이터가 없는 과는 '준비 중'으로 보이고 눌러도 레슨이 열리지 않는다.
- [ ] 과 화면에서 예습 · 본학습 · 복습 탭을 바꿔도 스크롤 위치가 유지된다.
- [ ] 단계 카드에 다음 · 이어서 · 끝냄 상태가 맞게 보인다.
- [ ] 레벨 구성(패턴형 · 토픽형 · 디베이트형)에 따라 단계가 표대로 나온다.
- [ ] 리스닝 룸 설정이 다음에 열어도 유지된다.
