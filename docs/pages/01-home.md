# 홈

> **제안 경로:** `/home` · **모듈:** 홈 · **기준:** v342
> 관련 코드: `#page-home`, `renderHero`, `rsvpOpen` · `qrOpen`, `openScanner`, `renderMap`, `notiHTML`, `noticeDHTML`

## 개요

앱을 열면 처음 보이는 화면이에요. **오늘 세션 출석**과 **오늘 할 학습(스터디 맵)**을 가장 크게 두고, 공지와 라운지 소식을 함께 보여 줘요. 스터디 회원은 출석 카드, 앱 구독자는 '오늘의 목표' 카드가 맨 위에 와요.

## 화면 구성 (위 → 아래)

| # | 영역 | 내용 |

| 2 | 인사말 | `Hey Tammy, let’s talk!` — 이름은 회원 닉네임, `talk!`에 형광 표시 |

## 스터디 카드 (출석)

### 필드

| 칸 | 내용 | 형식 |
|---|---|---|
| 위 띠 | 닫힌 클래퍼(잉크 · 크림 사선 줄무늬, 움직이지 않음) | 장식 |
| 스터디 | 내 수업 시작 시간 | `20:00` |
| 시작까지 | 남은 시간, 1초마다 줄어듦. 시작 뒤엔 '진행 중 +10:04' | `mm:ss` |
| DATE | 오늘 날짜 | `11.15` |
| 상태 | 아래 상태 표 | 글씨 (박스 없음) |
| 제목 | 홈에 올 때마다 `Take the stage.` → `Your stage is ready.` → `The stage is yours.` 차례로 (다음 실행 때 이어짐). 진행 중엔 `You're on stage.` | Unbounded 22px |
| 캐릭터 | 보라 팔로 3D, 제목과 함께 포즈가 기본 → 기울이기 → 점프로 바뀜, 3초마다 깜빡임 | 이미지 |
| 버튼 | 상태에 따라 | 아래 표 |

언어는 카드에 보여 주지 않아요. 출석 시트에서 골라요.

### 상태

| 상태 | 조건 | 상태 글씨 | 버튼 |
|---|---|---|---|
| 출석 전 | 사전 출석 안 함 · QR 시간 아님 | `READY` | [사전 출석체크 →] |
| 참석 예정 | 사전 출석 함 · QR 시간 전 | `READY · 참석 예정` | (잠김) `19:30부터 출석` + [변경] |
| 출석 가능 | 어느 수업이든 QR 창이 열림 | `● ACTION!` (빨간 점 퍼짐) | [출석체크 하기 →] — 5초마다 흰 빛이 3초에 걸쳐 스침 |
| 입장 완료 | 출석함 · 시작 전 | `READY · 입장 완료` | (표시) `입장 완료!` |
| 스터디 중 | 출석함 · 시작 후 | `● ON AIR · 스터디 중` | (표시) `입장 완료 · 무대 위` |
| 오늘은 쉬어요 | 불참을 알림 | `오늘은 쉬어요` | [그래도 갈래요 →] |

> `[TBC]` '오늘은 쉬어요' 상태는 코드에 있지만, 지금 화면에는 불참을 고르는 버튼(`#noBtn`)이 없어요. 불참 알리기를 넣을지 정해야 해요.

### 출석 규칙

| 항목 | 프로토타입 값 | 상태 |
|---|---|---|
| 세션 시간 | 18:00, 20:00 (`SLOTS`) | 지점별 시간표에서 받아야 함 |
| 내 수업 | 20:00 · 영어 (`MY_SLOT`, `MY_LANG`) | 회원 수강 정보에서 |
| 사전 출석 | 그 수업 시작 전까지 | 마감 시점 결정 필요 |
| QR 출석 | 시작 30분 전 ~ 시작 20분 후 (`QR_BEFORE`, `QR_AFTER`) | 확정 필요 |

## 출석 시트

같은 시트를 두 모드로 써요 (`S.mode`).

| | 사전 출석 (`rsvp`) | 출석 (`checkin`) |
|---|---|---|
| 제목 | 사전 출석체크 | 출석체크 |
| 시간 칩 | 아직 시작 전인 시간대 | 지금 QR 창이 열린 시간대만 |
| 언어 칩 | 4개 언어, **처음엔 아무것도 안 골라짐**(점선) | 사전 출석했으면 그 언어, 아니면 비어 있음 |
| 못 고르는 칩 | 빗금 + '출석 마감' | 같음 |
| 아래 버튼 | 언어 전: 회색 '언어를 골라주세요' / 고른 뒤: `20:00 · 영어 참석 알리기` | `20:00 · 영어 QR 찍고 출석` |
| 결과 | 카드가 '참석 예정'으로 | QR 스캐너 열림 |

### QR 스캐너

- 위에 고른 수업(`20:00 · 영어`)이 계속 보여요. 다른 수업으로 왔으면 [참석 정보 변경] → 시트로 돌아가요.
- 프로토타입: 1.8초 뒤 자동 성공. 실제 앱: 카메라 + QR 해석 → 서버에 출석 기록 → 성공.

### 출석 완료 시트

- 보라 원형 출석 도장(PALLO / 출석 / 날짜)이 쾅 찍히고 노랑 팔로가 옆에서 폴짝, 축하 소리.
- 문구: `출석 완료!` → `20:00 · 영어 스터디` → `오늘도 와줘서 반가워요. 즐겁게 말하고 와요!`
- 보상 줄(박스 없이): `출석 포인트 +30P | 이번 주 n번째 출석`
- 버튼: [좋아요, 다녀올게요] (노랑)

## 스터디 맵

라이브러리 지금 과의 단계를 게임 맵처럼 보여 줘요. 라이브러리와 **같은 진도 기록**을 써요.

### 머리

| 요소 | 내용 |
|---|---|
| 라벨 | `스터디 맵 · Lv.1` |
| 이번 주 진도 칩 | `이번 주 진도 5 & 6챕터` (`WEEK_LESSONS`, 실제로는 지점 진도표). 누르면 챕터 줄에서 5과 · 6과가 가운데로 오고 통통 튐 |
| [전체 보기] | 라이브러리 과 화면 열기 |
| 과 제목 | `1과 Cafe Complaint`, 2줄까지 (넘치면 …) |
| 챕터 줄 | 1과~20과 칩. 선택됨(검정) · 진행 중(노란 점) · 완료(노랑 + 체크) · 이번 주 과(베이지 `#F1EBDC` + 잉크 테두리). **아무 과나 바로 골라요** |
| 진행 막대 | 끝낸 단계 / 전체 |

### 정류장

- Lv.1 기준 8개: 예습(오늘의 패턴 · 대화문 · Bank 퀴즈) → 본학습(상황 활동 · My Story · AI 프리토킹) → 복습(스피킹 퀴즈 · 1분 말하기 챌린지).
- 구역 머리: 색 알약(예습 노랑 · 본학습 분홍 · 복습 하늘) + 흰 동그라미 번호 + 이름 + `건너뛰기`.
- 길은 왼쪽 → 가운데 → 오른쪽으로 크게 꺾이는 지그재그(SVG 곡선, 끝낸 구간 실선 · 남은 구간 점선).
- 정류장 동그라미는 볼록한 동전 음영. 지금 할 정류장은 통통 튀고 노란 스포트라이트.
- **팔로**: 마이에서 꾸민 내 캐릭터가 지금 단계 동그라미 위에 올라타 통통 뛰어요 (꾸민 적 없으면 기본 노랑). 3번에 1번쯤 공중에서 반대 방향으로 돌아요.
- 홈에 오면 **마지막으로 연 단계**(`ST.last`)가 화면 가운데쯤 와요. 처음이면 안 한 첫 단계.
- 계절 파티클: 봄 벚꽃잎 · 여름 풀잎 · 가을 단풍 · 겨울 눈송이(PALLO 별표). 기기 날짜로 자동. 정류장 뒤에서 움직이고 터치를 막지 않아요.

### 정류장 누르기 → 가운데 팝업

| 상태 | 팝업 내용 | 버튼 |
|---|---|---|
| 처음 | 팔로 · 단계 이름 · `6분 · +10P` (코인 아이콘 + 큰 `+10P`) | [시작하기!] |
| 하다 멈춤 | `3/7까지 했어요` + 진행 막대 | [이어서 하기] · [처음부터 하기] |
| 끝냄 | 단계 이름 | [다시 하기] |

어두운 배경 · X · 바깥을 누르면 닫혀요. 시작하면 라이브러리 그 단계가 열려요.

### 구간 건너뛰기

- 아직 안 끝난 구역 머리의 [건너뛰기] → 짧은 테스트 → 통과하면 처음부터 그 구역까지 남은 단계가 모두 완료돼요 (라이브러리 단계도 같이).
- 프로토타입은 1.2초 뒤 통과. **테스트 문항과 통과 기준은 정해지지 않았어요** (Q-C5).

### 아래

- [다음 챕터 · 2과 →] 버튼. 과를 다 끝내면 보상 상자(`[보상]`, Q-B5).

## 라운지 미리보기

- 내 지점 · 해외살이 · 동아리 인기 글이 2.5초마다 넘어가는 순환 슬라이드. 가운데 카드 78% 너비, 양옆은 작고 흐리게.
- 카드: 큰 사진(채널 색 배지 · `1/4`) + 작성자 · 시간 + 글 2줄 + 좋아요 · 댓글 수. 작성자 아래에는 지점(두 지점이면 `A · B`).
- 호스트가 쓴 글: 노란 링 · `HOST` 배지 · `★ 4.9`(산정 방식 Q-B6).
- 손으로 밀기 · 옆 카드 누르기 · 아래 점 누르기로도 넘어가요. 카드를 누르면 라운지로 가요 (실제 앱은 그 글 상세로 가야 해요).

## 상호작용

### 화면 열 때
- 지금 시각으로 스터디 카드 상태 계산, 1초마다 남은 시간 갱신.
- 제목 문구 · 팔로 포즈를 다음 순서로 (기기에 저장된 순번).
- Notice board · 라운지 슬라이드 자동 넘김 시작 (동작 줄이기면 멈춤).
- 스터디 맵을 마지막 단계 위치로 스크롤.

### 사전 출석
- **누름:** [사전 출석체크] → 시트(사전 출석 모드)
- **검사:** 시간 · 언어 둘 다 골라야 버튼이 켜짐
- **성공:** 시트 닫힘 · 카드 '참석 예정' · `20:00 · 영어 참석 예정`

### 출석
- **누름:** [출석체크 하기] → 시트(출석 모드) → [QR 찍고 출석] → 스캐너
- **성공:** 출석 완료 시트 · +30P · 랭킹 · 포인트 바로 반영
- **실패 (실제 앱에서 정해야 함):** QR이 다른 지점 · 다른 시간 · 만료 · 네트워크 오류

## 화면 연결

- **오는 곳:** 앱 실행, 하단 탭, 축하 화면 홈 버튼(라이브러리로 감), 알림.
- **가는 곳:** 출석 시트 · 스캐너, 라이브러리 과 화면 · 레슨, 알림함, 공지, 라운지, 마이 › 랭킹(숨긴 포인트 타일).
- **데이터 연결:** 스터디 맵 진도 = 라이브러리 진도(`ST.done`). 출석 · 학습 포인트 → 랭킹 · 마이. 마이 꾸미기 저장 → 맵 팔로 모습.

## 수용 기준

- [ ] 서버 시각 기준으로 스터디 카드 상태가 표대로 바뀐다 (출석 전 · 참석 예정 · 출석 가능 · 입장 완료 · 스터디 중).
- [ ] QR 창 밖의 시간대는 출석 시트에서 누를 수 없고 '출석 마감'으로 보인다.
