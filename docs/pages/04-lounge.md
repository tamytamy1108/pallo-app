## 개요

세션 밖에서 회원끼리 이어지는 커뮤니티예요. 사진 글 · 스토리 · 번개(한 번 만나요) · 동아리(매주 만나요) · 챌린지 · 해외살이 · 여행 동행이 있어요. 이벤트는 별도 탭([06-event](./06-event.md)), 챌린지 자세한 내용은 [05-challenge](./05-challenge.md)에 있어요.

- 고른 지점의 글 · 번개 · 동아리 · 하이라이트만 보여요. **전 지점 행사는 늘 보여요.** 두 지점을 다니는 멤버 글은 둘 중 하나만 맞아도 보여요.

## 스토리

### 줄 구성 (왼쪽 → 오른쪽)

1. **내 스토리** — 내 얼굴 + 오른쪽 아래 + (올리기). 올린 게 있으면 보기.
2. **사람별 스토리** — 올린 지 24시간 안. 안 본 사람 → 본 사람 순. 얼굴 + 카테고리 점 + 시간. 이름은 넘치면 ….
3. 세로 구분선
4. **카테고리 하이라이트** — 이벤트 · 챌린지 · 동아리 · 번개 후기 · 일상 · 해외. 새 글 있는 하이라이트가 앞(이벤트는 늘 맨 앞), 다 본 건 회색 테두리로 뒤로. 매니저 고정 스토리는 압정 + 맨 앞.

- 동그라미 62px · 간격 10px · 테두리는 노랑 한 색, 스토리 개수만큼 칸이 나뉘어요(본 칸은 얇은 회색).
- **24시간이 지나면** 사람 줄에서 빠지고 올릴 때 고른 카테고리 하이라이트로 자동으로 옮겨져요.

### 스토리 보기

- 전체 화면, 5초씩 넘어감. 왼쪽 / 오른쪽 누르기로 이동, 누르고 있으면 멈춤. 사람 → 다음 사람 → … → 하이라이트 순으로 이어져요.
- 사진이 화면을 꽉 채우고 위 · 아래만 살짝 어둡게, 제목 · 설명은 아래 흰 글씨.
- 맨 아래: `○○에게 댓글 달기` 입력칸 + 보내기(노랑) + ♡ · 💬(48px 정사각). 입력칸을 누르면 멈추고, 보내면 공개 댓글로 올라가고 다시 넘어가요. 💬 = 전체 댓글 창. '답장 보내기'는 올린 사람에게만 가는 비공개.
- 번개 · 파티 스토리는 위에 [참여하기] 한 줄. 내 스토리는 위 막대에 [지우기]. 개인 스토리 아래 '24시간이 지나면 ○○ 하이라이트로 옮겨져요'.
- 매니저 도구: [고정하기 / 고정 풀기] · [내리기].

### 스토리 올리기

- 카테고리 고르기(이벤트는 프로 · 지점 관리자만) · 사진 · 글.
- 체크 옵션: '커뮤니티 피드에도 올리기 · 24시간 뒤에도 남아요', (매니저) '매니저 고정 · 사라지지 않고 맨 앞에 보여요'.

## 커뮤니티 (사진 글)

### 카드

| 요소 | 내용 |
|---|---|
| 머리 | 프로필 · 이름 · 지점 · 역할(프로 · 지점 관리자) · 시간 · ⋯ 메뉴 |
| 사진 | 고른 비율 그대로, 여러 장이면 옆으로 밀거나 눌러서 다음 장. 두 번 누르면 좋아요(하트 터짐) |
| 아래 줄 | ♡ 129 · 💬 12 · 공유 (수는 아이콘 바로 옆). 하트 수 누르면 좋아요 누른 사람 목록(30명까지 + '외 N명', 내가 눌렀으면 맨 위), 댓글 수 누르면 댓글 창 |
| 글 | 낱말 단위 줄바꿈 |

새로 올린 글은 예시 댓글 없이 '첫 댓글 달기'로 시작해요.

### 글쓰기 (2단계)

1. **새 게시물** — 앨범에서 고르기(한 번에 최대 10장) · 사진 찍기(휴대폰은 카메라 바로). 원본 비율로 미리 보기. 4:6보다 세로로 길거나 1.91:1보다 가로로 길면 그 한계로 자동 맞춤. 두 손가락 확대 · 축소(최대 4배) · 한 손가락 이동. 왼쪽 아래 ⤢ = 원본 비율 ↔ 1:1(모든 사진에 같이 적용, 한 게시물은 한 비율). 아래 줄에서 사진을 바꿔 가며 맞추고, + 로 더 넣고, [사진 빼기]. [사진 없이 다음]도 됨.
2. **글쓰기** — 글 칸 먼저(쓴 만큼 늘어남, 최소 110px, 화면 60% 뒤엔 칸 안 스크롤) → '어떤 글인가요?' 카테고리 한 줄 알약.

- [다음] · [올리기]는 창 아래 고정. `‹`로 사진 단계로 돌아가도 맞춘 사진 · 카테고리 · 글이 남아요.
- 올릴 때 보이는 그대로 잘라 **긴 변 최대 1080px JPEG**로 줄여요. 원본은 **20MB 이하**. 10장을 넘거나 20MB 넘는 사진은 빼고 알려 줘요.
- 다른 탭에서 올려도 올리면 커뮤니티 탭으로 이동해요.

## 번개 · 동아리

### 지도

- 한국 지도(Natural Earth 윤곽 + 시 · 도 경계선): 크림 바다 · 노랑 땅 · 잉크 테두리 · 그림자(스티커 느낌). 이웃 나라는 연하게.
- 지역 표시 = PALLO 스파크 심볼. 분홍 = 번개, 보라 = 동아리. 많을수록 조금 커지고 개수는 하얀 동그라미. 고른 지역은 스파크가 천천히 돌고 보라 말풍선 `서울 6`.
- 지역(`LG_REG`): 서울 · 경기 · 천안 · 대전 · 대구 · 울산 · 부산. 지역을 누르면 아래가 그 지역만.

### 번개 (한 번 만나요)

| 요소 | 내용 |
|---|---|
| 날짜 줄 | 전체 · 오늘 · 다음 6일 + 더보기(점선) → 5주 달력(개수 배지, 지난 날 흐림). 번개 없는 날은 흐리게 + '이날 번개 열기' |
| 카드 = 티켓 | 포스터가 카드 맨 위까지 꽉, 포스터 위 `번개 · D-8`(포스터 색에 맞춰 흰색/잉크), 점선 + 양옆 반원 홈, 제목 · 날짜 · 장소 · 인원 바 · 금액(무료면 '무료') · 노랑 버튼 |
| 보는 방식 | '번개 n개 · 옆으로 넘겨 보세요' 옆으로 넘기는 카드 줄(한 장씩 딱딱 멈춤) |
| 꽉 참 | [빈자리 알림 받기] → '알림 받는 중' |
| 지난 번개 | 카드 줄 맨 끝 점선 카드 → 회색 카드 줄(후기 보기) · [접기] |
| 내 번개 | [모집 닫기] (바로) |

**번개 열기 폼**: 포스터 여러 장(최대 10장, 첫 장이 대표, 누르면 대표로, × 빼기) · 제목 · **날짜 = 오늘부터 14일까지**의 2주 달력(오늘 · 내일 표시, 토 파랑 · 일 빨강) + 시간 칩 + 확인 문장('11월 15일 (일) 오후 8:00에 만나요') · **장소 = 지도에서 고르기**(지역 지도 핀: 지점 라운지 · 카페 · 펍 · 공원 · 식당 · 책방 + 아래 목록 → 이름 · 주소 자동) + '상세 주소 · 직접 적어요 (선택)' · 정원 · 참가비. 올리면 지도 숫자에 바로 반영.

### 동아리 (매주 만나요)

| 요소 | 내용 |
|---|---|
| 목록 | 카테고리 아이콘 줄(전체 · 러닝 · 운동 · 북클럽 · 영화 · 드라마 · 맛집 · 카페 · 회화 스터디) + 정렬(추천 · 멤버 많은 순 · 새로 생긴) + 한 줄 목록(포스터 썸네일 · 이름 · 한 줄 소개 · 카테고리 · 지점 · 멤버 수 · 최근 대화). 5개 넘으면 더보기 |
| 카드 = 회원증 | 뒤에 카드 두 장이 겹쳐 보임, 보라 가입 버튼 |

**동아리 만들기**: 카테고리 · 포스터(최대 10장) · 이름 · 소개 · 가입 조건(누구나 → 바로 가입 / 나머지 → 신청) · '채팅방 공지 (가입하면 보여요)'. 올리면 **매니저 승인 대기 카드**.

## 상세 화면 (번개 · 동아리 · 이벤트 공통 틀)

- 오른쪽에서 밀려 나와요. 포스터가 맨 위부터 좌우 끝까지 꽉 차요(4:5). 2장 이상이면 3초마다 0.6초 페이드로 넘어감, 누르면 전체 화면 크게 보기(옆으로 넘기기 · `1 / 3`).
- 뒤로 · 공유는 포스터 위 아이콘만(어두운 포스터 위 흰색, 밝은 포스터 위 잉크). 내려서 제목이 가려지면 위 막대에 크림 배경 + 모임 이름이 0.25초에 나타나요.
- 정보 줄: 일시 · 장소(이름 → 주소 → 상세 주소 굵게 + 복사 아이콘, 복사하면 주소 + 상세 주소) · 호스트 · 인원(남은 자리) · 참가비. 동아리는 호스트 · 코호스트 · 가입 조건.
- 소개(8줄 넘으면 더보기 / 접기), 번개 안전 안내.
- **함께하는 멤버**: 이름 · 역할(호스트 · 코호스트 · 나) · 지점 · 인사말, 5명 넘으면 '모두 보기 ›'(회색 글자 링크). 참여한 멤버는 인사 남기기, 내 인사 아래 수정 · 삭제.
- 아래 고정 바: 찜(하트) + [참여하기 / 가입하기 / 후기 보기].

### 참여 · 가입

- **카드에서 바로 참여하지 않아요.** 카드의 참여 · 가입 → 상세 → 아래 버튼.
- 참여 확인 시트: 모임 내용(날짜 · 장소 · 인원 · 호스트 · 비용) + '모임 내용과 안내를 확인했어요' 체크(줄 전체가 체크 칸) → 버튼 켜짐.
- 동아리 가입: '동아리 안내를 확인했어요' 체크 → 가입 → '가입했어요! 가입 인사 남길래요?' [인사 남기기 / 다음에 할게요]. 승인이 필요하면 '가입 신청을 보냈어요 · 미리 남길래요?'. 가입하면 채팅 맨 아래 'Tammy님이 들어왔어요'(한 번만). 안내: '호스트에게만 내 지점이 보여요'.
- 참여 완료 · 가입 완료를 누르면 '참여를 취소할까요? / 동아리에서 나갈까요?'. 동아리에서 나가면 참석하기로 한 정기 모임도 함께 취소.

### 동아리 상세 탭

| 탭 | 내용 | 볼 수 있는 사람 |
|---|---|---|
| 홈 | 소개 · 모임 정보 · 다가오는 정기 모임 타임라인 · 호스트 소개(호스트가 쓴 글, 운영 기간 · 정기 모임 수 · 또 만나고 싶어요) · 멤버(NEW) · 같은 카테고리 추천 | 누구나 |
| 게시판 | 전체 · 공지 · 모임 후기 · 가입 인사. 필독 공지 위. 글쓰기(호스트는 공지도) · 좋아요 · 댓글. 내 글 · 댓글 수정 · 삭제(되돌리기) | 멤버. 가입 전엔 글 2개 흐리게 + '글 n개 더 · 가입하면 모두' |
| 사진첩 | 사진 + 캡션, 누르면 크게(올린 사람 · 캡션 · 옆으로) | 멤버. 가입 전 6장 흐리게 |
| 채팅 | 위 호스트 안내 고정, 날짜 구분, 입장 알림, 내 말 노랑 말풍선 | 멤버. 가입 전 최근 4줄 흐리게 + 잠금 |

- 탭을 바꿔도 보던 자리를 유지해요. 탭이 위에 붙어 있는 동안만 위 막대 뒤에 크림 배경.
- 아래 고정: '최근 30일 동안 N명이 가입했어요' + 찜 + 가입하기.
- 코호스트 정하기: 호스트 · 매니저만, 멤버 중 인원 제한 없이.

### 정기 모임

- **타임라인**: 4주 안 최대 4회. 날짜 칩(다음 회차 노랑) · 시간 · 회차 주제 · 인원 · `OO 외 N ›`(그날 참석 멤버) · 참석 / 참석 완료 / 빈자리 알림.
- **일정 목록** `일정 N · 더보기 ›` (12주): 날짜 블록 · [언어] 회차 주제 · 시간 · 인원 · 상태 글씨(모집 중 분홍 · 마감 회색 · 참석 완료 보라) · 왕관 N회차 · 내 지점 N명 · 썸네일.
- **회차 상세**: D-day · 동아리 이름 · 회차 주제 · 일시 · 장소(이름 + 상세 주소 + 복사) · 인원 · 준비물 · 참석 멤버(인사말). 아래 버튼: 가입하고 참석하기 / 참석하기 · 남은 자리 / 참석 취소 / 빈자리 알림.
- 참석하면 '참석 완료!' 창 → [인사말 남기기](내 줄 입력칸 열림) / [다음에 할게요]. 회차 상세에는 보라 '✓ 참석 완료 · 전날 알림을 보내 드려요' 막대 + 취소. 참석 전엔 '참석하면 한마디 남길 수 있어요'.

## 해외 동행

- 세계 지도(해안선만, 같은 스티커 스타일). 해외살이 = 보라, 여행 동행 = 분홍 스파크. 나라(`LG_CC`) 누르면 그 나라만.
- **해외살이**: 여권 카드('나도 해외에 있어요' 등록) + 이야기 · 질문 글. 해외살이 쪽에선 스토리 줄이 나라 목록으로 바뀌어요.
- **여행 동행**: 탑승권 카드(D-day · 동행 방식 · 스타일 · 인원). 동행 방식(`LG_TYPES`): 전체 동행 · 부분 동행 · 식사 · 투어 · 숙소 …, 스타일(`LG_STY`): 맛집 · 사진 · 느긋하게 · 알차게 · 미술관 · 액티비티 …
- 신청: **안전 수칙 4개를 모두 체크해야** 신청 → 수락 대기 → 오픈채팅.
  1. 처음 만나는 곳은 사람 많은 공개 장소로 해요
  2. 여권 · 돈은 각자 챙기고 빌려주지 않아요
  3. 일정과 숙소를 가족이나 친구에게 알려요
  4. 불편하면 언제든 그만두고 신고할 수 있어요
- '동행 구하기' 폼.

## 수용 기준

- [ ] 탭은 추천 · 커뮤니티 · 챌린지 · 번개 · 동아리 · 해외 동행 5개이고, 이벤트 탭에 갔다 와도 보던 탭으로 돌아온다.
- [ ] 지점 선택이 글 · 번개 · 동아리 · 하이라이트에 적용되고, 전 지점 행사는 늘 보인다.
- [ ] 스토리는 올린 지 24시간 뒤 사람 줄에서 빠지고 고른 카테고리 하이라이트로 옮겨진다. 매니저 고정 스토리는 맨 앞에 남는다.
- [ ] 사진은 최대 10장 · 원본 20MB 이하만 받고, 올릴 때 긴 변 1080px로 줄여 고른 비율 그대로 피드에 보인다.
- [ ] 카드의 참여 · 가입 버튼은 상세 화면을 열고, 참여는 확인 체크를 한 뒤에만 된다.
- [ ] 동아리 게시판 · 사진첩 · 채팅은 가입 전엔 흐린 미리보기만, 가입 후엔 전부 보인다.
- [ ] 동아리에서 나가면 참석하기로 한 정기 모임도 취소된다.
- [ ] 번개 날짜는 오늘부터 14일 안에서만 고를 수 있고, 장소는 지도에서 고른다.
- [ ] 여행 동행은 안전 수칙 4개를 모두 체크해야 신청된다.
- [ ] 권한별 차이 표대로 버튼이 보이거나 막힌다.
