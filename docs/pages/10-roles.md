# 10. 역할별 앱 화면

누가 로그인했는지에 따라 앱이 보여 주는 화면 · 버튼이 달라요. 가입 · 연동 · 비회원 잠금은 [09-onboarding](./09-onboarding.md#3-3-회원--비회원-권한)에 있고, 이 문서는 **회원 위 역할**(프로 · 지점 관리자 · 본사 운영자)과 **모임 안 역할**(호스트 · 코호스트)을 정리해요.

화면 시안: `prototype/role-screens.html` (지금 앱 화면을 찍어 역할마다 달라지는 정보만 바꾼 것, `?tab=all|my|home|ops|lounge|club|note|noti`).

> **정한 것 (2026-11-25)**
> - 사람은 크게 **멤버 · 직원 · 프로** 세 무리예요. 멤버 = 비회원 · 체험 · 회원(모임 안에서는 호스트 · 코호스트도 돼요), **직원 = 지점 관리자 · 본사 운영자**, 프로 = 세션을 맡는 강사.
> - **프로 = 리더**예요. 앱 · 문서 이름은 **프로**로 통일해요 (예전 '리더'). 교재 속 'AI 리더 Lily'는 그대로예요.
> - **지점 관리자는 지점 하나**만 맡아요. 지점 바꾸기는 없어요.
> - **프로는 출석 · 수업(프로 출석 체크 · 프로스 노트 · 출석 명단 · 반 공지) 말고는 멤버와 똑같아요** (2026-11-26). 연기 · 이용권 · 이벤트 신청이 진짜로 되고, 공지 고정 · 글 숨기기 · 이벤트 바로 열기 같은 라운지 도구는 없어요.
> - 지점 관리자 · 본사 운영자(직원)는 처음 온 회원에게 **자기 앱으로 쓰는 법을 보여 줘야** 해요. 그래서 회원 화면이 다 열려 있지만 **신청 · 제출은 되지 않는 '보여 주기 모드'**로 써요.
> - **본사 운영자**도 세션을 맡을 땐 **프로로 앱을 써요** (프로 출석 체크를 해야 해서).
> - 프로 출석 체크는 **시간 제한 · 지각 표시가 없어요**. 본사 운영자는 세션이 없는 날 따로 볼 화면이 없어요. 프로는 학생의 연기 요청을 보지 않고(지점 관리자만), **대강(대신 맡기)은 앱에서 다루지 않아요** (2026-11-25).
> - 라운지 · 프로필에 **역할 표시**를 붙여요: 프로는 `PRO`, 직원은 모두 `STAFF`. 얼굴 옆 표시는 호스트 · 코호스트 왕관과 헷갈리지 않게 모양을 달리해요 (8장).
> - **프로 · 스텝은 출석 체크에 제약이 없어요** (2026-11-25): 등록된 팀이 아니어도 어느 세션이든 테이블 QR로 들어가고, 찍을 때 **현장에서 프로로 / 멤버로** 골라요 (3-1 참고).
> - **프로가 출석 체크를 하면 그 세션의 프로스 노트가 바로 열려요** (2026-11-25). 세션 내내 이 화면에서 노트를 채우고, 끝나면 반에 보내요.
> - **직원도 이벤트 신청은 진짜로 해요** (2026-11-26). 보여 주기 모드에서 빼요.
> - **지점 연동 요청은 연동 전(비회원)에게만 보여요** (2026-11-26). 이미 연동된 사람(멤버 · 프로 · 직원)에게는 연동 버튼이 없어요.

## 1. 역할 한눈에

세 무리로 보면: **멤버**(아래 표의 위 네 줄) · **프로** · **직원**(지점 관리자 · 본사 운영자).

| 역할 | 종류 | 누구 | 앱 첫 화면 | 하단 탭 |
|---|---|---|---|---|
| 비회원 · 체험 · 연동 대기 | 계정 | 아직 연동 안 된 사람 | 둘러보는 중 · 체험 · 잠긴 출석 카드 | 홈 · 라이브러리 · 라운지 · 이벤트 · 마이 |
| **회원** | 계정 | 지점에 다니고 연동된 사람 | 오늘 스터디(출석) | 홈 · 라이브러리 · 라운지 · 이벤트 · 마이 |
| **호스트** | 모임 안 | 번개 · 동아리 · 챌린지를 연 회원 | 회원과 같아요 | 회원과 같아요 (모임 화면 안에 `관리`) |
| **코호스트** | 모임 안 | 호스트가 정한 동아리 멤버 (인원 제한 없음) | 회원과 같아요 | 회원과 같아요 (모임 화면 안에 `관리`) |
| **프로** | 계정 | 세션을 맡는 강사 | **오늘 내 세션** | 회원과 같아요 (운영 탭 없음) |
| **지점 관리자** | 계정 | 지점 하나를 맡은 운영자 | 회원과 같은 출석 카드 + 아래 **지점 현황 요약** | 회원과 같아요 |
| **본사 운영자** | 계정 | 본사 직원 | 세션을 맡을 땐 오늘 내 세션 | 회원과 같아요 |

- **앱에는 운영 탭이 없어요** (2026-11-25). 모든 역할의 하단 탭이 회원과 같아요 (이벤트 탭 그대로). 연동 · 체험 · 회원 요청 · 신고 같은 처리는 **전산(관리자) 웹**에서 해요.
- 프로 일은 홈 출석 카드 · 마이(PRO'S NOTE 카드 · 내 수업 카드)에서 해요.
- 알림은 모든 역할이 회원과 같아요 (연동 요청 등 처리 알림은 앱으로 오지 않아요, 전산 웹에서).
- 한 사람이 두 역할을 가질 수 있어요: 프로이면서 동아리 호스트 → 프로 화면 + 동아리 `관리`.

## 2. 보여 주기 모드 (지점 관리자 · 본사 운영자)

프로는 보여 주기 모드가 없어요 — 출석 · 수업 말고는 회원과 똑같이 진짜로 신청해요 (2026-11-26).

회원 화면을 **똑같이** 열어 보여 줄 수 있어요. 마지막 **신청 · 제출 · 결제** 버튼만 막혀요.

| 회원 기능 | 지점 관리자 | 본사 운영자 |
|---|---|---|
| 홈 · 스터디 맵 · 상황맵 · 레슨 (모든 챕터) | ○ 끝까지 풀 수 있어요 | ○ |
| 사전 출석 · QR 출석 (회원용) | ○ **진짜로 돼요** · 등록된 팀이 아니어도 아무 세션이나 (멤버로 참여) | 맡은 세션 = **프로 출석 체크**(3장) · 그 밖의 세션 = **멤버로 참여** (제약 없음) |
| 연기 · 팀 · 지점 변경 | 화면 · 고르기까지 ○, **[신청하기]만 막힘** | **열 수 없어요** (마이에서 칸이 흐리게) |
| 이용권 · 홀딩 · 연장 · 재등록 | 화면 ○, 신청 막힘 | 화면 ○, 신청 막힘 |
| 체험 예약 | 화면 ○, 보내기 막힘 | 화면 ○, 보내기 막힘 |
| 지점 연동 요청 | 안 보여요 (이미 연동됨) | 안 보여요 (이미 연동됨) |
| 이벤트 신청 · 입금 | ○ **진짜로 돼요** (2026-11-26) | ○ **진짜로 돼요** (2026-11-26) |
| 라운지 글 · 댓글 · 번개 · 동아리 | ○ 진짜로 돼요 (운영자 표시가 붙어요) | ○ 진짜로 돼요 (STAFF 표시) |
| 꾸미기 · 랭킹 · 퀘스트 | ○ (랭킹에 들어가요) | ○ (랭킹에 들어가요) |

- 막힌 버튼은 모양은 그대로 두고, 누르면 토스트 `보여 주기용이라 신청되지 않아요`. 회원에게 보여 주는 중이라 흐리게 만들지 않아요.
- 화면 맨 위에 작은 띠 `보여 주기 모드` (끌 수 없어요). 회원이 '진짜 신청됐다'고 오해하지 않게요.
- 프로 · 스텝도 **랭킹에 들어가요** (2026-11-25).

## 3. 프로 (= 예전 리더) · 본사 운영자

### 홈: 오늘 내 세션
- 카드: 시간 · 팀 · 언어 · 레벨 · 교실 · 시작까지 남은 시간 (회원 출석 카드와 같은 클래퍼보드, 색만 달라요).
- **프로 출석 체크**: 세션 날 언제든 `출석 체크` (시간 제한 · 지각 표시 없음) → 회원과 같은 **테이블 QR**을 찍어요 (`role: 리더`로 보냄). 체크하면 `입장 완료 · 19:12`, 지점 관리자 · 본사에 기록이 남아요.
- **출석 체크 → 프로스 노트가 바로 열려요.** 서버가 돌려준 `prosNoteId`로 그 세션의 노트 쓰기 화면이 자동으로 떠요 (닫았다가 홈 카드 `프로스 노트 이어 쓰기`로 다시 열어요).
  - 세션 중: 표현 · 바로잡기 · 뜻 · 질문 항목을 바로바로 적어요 (학생 이름을 붙이면 그 학생에게만).
  - 세션 뒤: 마무리 인사를 적고 `반에 보내기` → 회원에게 '프로님이 프로 노트를 보냈어요' 알림.
  - 보내기 전까지는 임시 저장. 회원 화면에는 `오늘 준비 중`으로 보여요.
- 오늘 세션이 여러 개면 카드를 옆으로 넘겨요. 세션이 없는 날은 `오늘은 세션이 없어요 · 다음 세션 11.27 (금) 19:30`.

### 프로가 쓰는 화면 (운영 탭 없이)

프로는 운영 탭이 없어서, 아래 화면은 **마이 › 내 수업** 카드에서 들어가요 (세션 줄을 누르면 그 세션 화면 — 정할 것). `내 일정 전체 보기` = 이번 주 · 다음 주 맡은 세션 전체 목록 (보기만).

| 화면 | 내용 |
|---|---|
| **출석 명단** | 오늘 세션별: 사전 출석 / QR 출석 / 아직 안 옴. 손으로 출석 체크 (QR이 안 될 때) · 지각 · 결석 표시 |
| **세션 진행** | 이번 주 진도(과 · 단계), 오늘 토픽 · 질문 카드(Lv.3 · 4), 발표 타이머 |
| **프로스 노트** | 출석 체크하면 자동으로 열려요. 오늘 세션 노트 이어 쓰기 · 보낸 노트 목록 · 고마워요 · 감사 인사 보기 |
| **내 반 학생** | 학생별 진도 · 출석률 · 최근 노트 · 프로필 |
| **반 공지** | 내 반 회원에게만: 휴강 · 교실 변경 · 준비물 (푸시 + 알림함) |
| **내 일정** | 이번 주 · 다음 주 맡은 세션 (보기만 · 대강은 앱에서 다루지 않아요) |
| **이벤트 관리** | 내가 연 이벤트: 신청자 · 설문 결과 |

### 라운지 · 이벤트 권한
회원과 같아요 (2026-11-26). 예전 리더 권한(글 메뉴 공지 고정 · 글 숨기기, 스토리 '이벤트' 카테고리, 이벤트 바로 열기 + 신청 설문 만들기)은 지점 관리자 · 본사 운영자에게만 남아요. 이벤트는 회원처럼 **제안**하고 신청해요. 프로필 · 글에 프로 표시 (8장).

### 마이
회원 마이와 같아요. 다만 이용권 칸 대신 **이번 달 맡은 세션 수 · 출석 체크 기록**.

**앱에 들어간 것 (2026-11-25)**
- 숫자 칸: **이번 달 세션 · 출석률 · 보낸 노트 · 받은 고마워요** (세션 · 출석률을 누르면 내 일정, 노트 · 고마워요는 보낸 노트 목록). 출석률 = 이번 달 맡은 세션 중 테이블 QR 에서 '프로로 참여'로 출석한 비율 (2026-11-26, 예: 13/14 → 93%). 서버 값 `proStats.attendanceRate` 가 없으면 `–`.
- PRO'S NOTE 카드: 위에 **[보낸 노트 n] [받은 노트 n]**. 보낸 노트 = 내가 반에 보낸 최신 노트 · `n/m명 읽음 · 고마워요 n`, 받은 노트 = 회원과 같아요 (프로도 멤버로 참여하면 노트를 받아요). 모두 보기 → 같은 탭으로 목록.
- 노트 목록 (`/me/notes`): 프로는 맨 위 밑줄 탭 **보낸 노트 · 받은 노트**. 보낸 노트 줄 = 날짜 · 팀 · n/m명 읽음 · 고마워요. 보낸 노트를 열면 같은 노트 모양 + 반에 남긴 인사 · 읽음 수 · 받은 감사 인사 (고마워요 · 감사 인사 보내기 버튼은 없어요).
- 내 스터디 카드 → **내 수업** 카드: 이번 주 맡은 세션 (날짜 · 시간 · 팀 · 언어 · 테이블 · 학생 수). 버튼 없음. 숫자 칸(이번 달 세션 · 출석 체크)을 누르면 **담당팀** 시트(이번 주만). 이용권 · 남은 횟수 · 연기 · 팀 변경은 없어요.
- **지점 관리자도 프로와 같은 마이**예요 (이름 옆 STAFF · 아래 줄 `지점 · 지점 관리자`만 달라요). 둘 다 현장에서 프로로 참여해 노트를 보낼 수 있어서예요 (`state/me` `isProLike`).
- 화면 제목: 마이 = `My page`.
- 샘플 데이터: `data/account.ts` `PRO_CLASSES` · `PRO_SENT_NOTES` · `PRO_STATS`. 맞는 API(제안): 프로 일정 · 보낸 노트(+읽음 수) · 마이 숫자.

## 3-1. 프로 · 스텝 출석: 현장에서 프로로 / 멤버로 고르기

프로 · 스텝은 **등록된 팀 · 지점이 아니어도** 어느 세션이든 들어가요 (이용권 · 남은 횟수도 따지지 않아요). 테이블 QR을 찍으면 지금 앱의 메뉴 시트로 고르게 해요:

> **어떻게 참여할까요?**
> - **프로로 참여** — 이 세션을 맡아요 · 프로스 노트가 바로 열려요
> - **멤버로 참여** — 학생으로 들어가요 · 회원과 같은 출석 · 포인트

| | 프로로 참여 | 멤버로 참여 |
|---|---|---|
| 누가 | 프로 · 스텝 (맡은 세션이 아니어도, 대신 맡을 때 등) | 프로 · 스텝 |
| QR을 찍은 뒤 | 프로스 노트가 바로 열려요 | 회원과 같은 출석 완료 (노트 안 열림, 그 세션 프로의 노트를 받아요) |
| 홈 출석 카드 | 세션 시각 · `프로 출석 체크` | **회원 카드와 똑같아요** |
| 출석 명단 · 랭킹 | 프로로 표시 | 멤버로 표시 · 출석 포인트 · 랭킹에 들어가요 |
| 사전 출석 · 연기 | — | 사전 출석 ○ · 연기는 없어요 (등록된 세션이 아니라서) |

- 맡은 세션이면 `프로로 참여`를 위에, 아니면 `멤버로 참여`를 위에 둬요. 회원은 이 시트가 뜨지 않아요.
- 스텝의 멤버 출석은 보여 주기 모드여도 **진짜로 기록**돼요.

| 공지 · 정기 모임 · 참석 확인 | 호스트 · 코호스트 | 작은 메뉴 시트 3줄: **공지 쓰기**(게시판 공지 + 채팅방 위 고정) · **정기 모임 일정**(요일 · 시간 · 장소, 이번 회차 쉬기) · **참석 확인**(지난 회차를 고르면 멤버마다 왔어요 / 안 왔어요). | 공지 → 멤버 모두에게 알림. 회차 쉬기 · 시간 변경 → 참석 신청한 멤버에게 알림. 참석 확인 → 호스트 점수 ★과 멤버 '함께한 모임'에 쓰여요 (알림 없음). |
| 호스트 넘기기 | 호스트만 · 빨강 | 멤버 고르기 시트 → 확인 창 'Leo님에게 호스트를 넘길까요? 나는 코호스트가 돼요.' | 받는 사람에게 '호스트를 맡아 줄래요?' 알림 → **수락해야** 넘어가요. 거절하면 나에게 알림, 그대로. |
| 동아리 닫기 | 호스트만 · 빨강 | 확인 창 '원서 북클럽을 닫을까요? 멤버 7명에게 알림이 가고, 다가오는 정기 모임 12회가 취소돼요. 게시판 · 사진은 30일 동안 볼 수 있어요.' [닫기](빨강) · [취소]. | 닫으면 라운지 목록에서 빠지고 멤버 모두에게 알림. 30일 뒤 게시판 · 사진이 지워져요. |

- **가입 승인 · 대기자는 없어요 (2026-11-26)**: 신청하면 바로 가입돼요. 가입 인사는 가입한 뒤에 남기는 선택이에요.
- **잠금은 가입 안 한 사람만 (2026-11-26)**: 멤버 · 호스트 · 코호스트(정해진 뒤) · 스텝(지점 관리자)은 게시판 · 사진첩 · 채팅 · 정기 모임을 잠금 없이 봐요 (model `clubOpen`).
- 동아리 화면의 호스트 줄은 얼굴(왕관) · 이름 · `HOST`, 코호스트는 얼굴(흰 왕관) · 이름 · `CO-HOST`. 누르면 그 사람 프로필 (2026-11-25 앱에 반영).
- 앱의 모든 얼굴 · 이름은 누르면 프로필이 열려요 (내 얼굴은 마이).

## 7. 데이터 · API 바뀔 곳 (백엔드)

> API 문서에 옮겼어요 (2026-11-25): `docs/api/openapi.yaml` 맨 위 '누가 부를 수 있나' · API 마다 `x-roles` · `x-demo-blocked` · '프로 · 직원' 태그 15개, 화면별은 `docs/api/screens.md#staff`. 아래는 요약이에요.

- **역할 값**: `role` = `guest · member · pro · manager · hq` (예전 `leader` → `pro`). 본사 운영자는 `hq`, 앱에서는 프로와 같은 화면 + 맡은 세션. `branchId` 는 지점 관리자에게 하나.
- **보여 주기 모드**: `role` 이 `manager · hq` 이면 서버도 회원 신청 API(연기 · 홀딩 · 연장 · 체험)를 **막아요** (앱만 막으면 안 돼요). 응답 `403 demo_account`. 이벤트 신청은 막지 않아요. **`pro` 는 출석 · 수업 말고는 `member` 와 같아서 막지 않아요** (2026-11-26). 지점 연동 요청 버튼은 연동 전(guest)에게만 보여요.
- **프로 · 스텝 출석은 제약 없음**: 프로 · 스텝 계정은 등록된 팀 · 이용권 확인 없이 어느 세션이든 check-in 돼요. 앱이 고른 대로 `role: 리더`(→ `prosNoteId`) 또는 `role: 멤버`를 보내요.
- **프로 출석 체크**: 이미 있는 `POST /study/sessions/{sessionId}/check-in {tableId, role: 리더}` → 응답의 `prosNoteId` 로 노트 쓰기를 바로 열어요 (api/screens.md '리더 출석 → prosNoteId'). 오늘 맡은 세션은 `GET /staff/sessions/today` (새로).
- **출석 명단**: `GET /staff/sessions/:id/roster` · `PATCH /staff/sessions/:id/roster/:memberId` (손 출석 · 지각 · 결석).
- **프로스 노트 쓰기**: `GET · PUT /pros-notes/{noteId}` (항목 · 마무리 인사 임시 저장) · `POST /pros-notes/{noteId}/send` (반에 보내기 → 알림). 백엔드 노트는 지금 '리더 질문 → AI 답' 모양이라, 앱의 태그 항목(표현 · 바로잡기 · 뜻 · 질문)을 담을지 정해야 해요.
- **반 공지**: `POST /staff/teams/:id/notices`.
- ~~**지점 관리자 처리함**: `GET /manager/inbox`~~ → 앱에 두지 않아요. 연동 · 체험 · 신고 · 동아리 승인 · 이벤트 제안 · 회원 요청 처리는 전산(관리자) 웹 (4장, 2026-11-25).
- **오늘 지점 현황**: `GET /manager/branch/today` (세션별 출석 인원 · 테이블별 인원 · 프로 출석 체크). 요약 카드 숫자도 이 응답에서 앱이 더해요.

## 8. 역할 표시 (얼굴 · 이름 옆)

라운지 글 · 댓글 · 스토리 · 프로필 · 멤버 목록에서 누가 프로 · 직원 · 호스트인지 바로 보이게 해요. **두 줄로 나눠요**:

| 역할 | 얼굴 오른쪽 아래 표시 | 이름 옆 글자 | 어디서 |
|---|---|---|---|
| 프로 | 보라 동그라미 속 흰 PALLO 스파크 | `PRO` (보라) | 어디서나 (계정 역할) |
| 직원 (지점 관리자 · 본사 운영자) | 잉크 동그라미 속 노랑 집 | `STAFF` (잉크 바탕 노랑 글자) | 어디서나 (계정 역할) |
| 호스트 | 노랑 왕관 (지금 그대로) | `HOST` | 그 모임 화면 · 그 모임 글 · 마이 · 프로필(운영 중일 때) |
| 코호스트 (예전 '서브 호스트') | 흰 왕관 (지금 그대로) | `CO-HOST` | 그 모임 화면 · 그 모임 글 · 마이 · 프로필(운영 중일 때) |

- **마이 · 멤버 프로필 이름 옆 (2026-11-26)**: 계정 역할 `PRO` · `STAFF` 다음에, **운영 중인 동아리가 1개 이상이면** `HOST`(내가 호스트인 동아리가 있음) 또는 `CO-HOST`(호스트가 나를 코호스트로 정한 동아리만 있음)가 붙어요. 둘 다면 `HOST`만. 프로필에는 이름 아래 `동아리 n개 운영 중 · 호스트` 한 줄. 운영 중인 동아리가 0개가 되면(닫힘 · 관리자 닫기) 바로 없어지고, 관리자가 뱃지만 뗄 수도 있어요 (`roleBadgeOff`, A32). 코드: model `useMyClubRoles` · `useMemberRoleTags`.
- **마이 › 참여 중인 모임 · 내 모임 순서**: 동아리 → 번개 → 챌린지 → 이벤트 (`MY_MEET_ORDER`). 동아리 탭에서는 **운영 중인 동아리**(HOST · CO-HOST 글자)가 가입한 동아리보다 먼저예요. 찜한 모임 목록도 같은 순서예요.
- **왕관은 모임 역할 전용**이에요. 프로 · 직원 표시는 왕관이 아닌 다른 모양이에요.
- 한 사람이 둘 다면(프로이면서 동아리 호스트): 그 모임 화면에서는 얼굴에 **왕관**, 이름 옆에 `PRO` `HOST` 둘 다. 다른 곳에서는 얼굴에 프로 표시.
- 직원은 지점 관리자 · 본사 운영자 모두 `STAFF` 하나로 보여요. 역할 이름은 그대로 **지점 관리자**예요 — `STAFF`는 이름 옆 글자일 뿐이고, 문서 · 관리 화면 · 권한 표는 지점 관리자로 써요. 이름 아래 작은 줄에 소속이 나와요: 지점 관리자는 지점 이름(`하남점 · 1시간 전`), 본사 운영자는 `PALLO` (`PALLO · 어제`). 화면에 '본사'라는 말은 쓰지 않아요.
- 본사 운영자가 세션을 맡아 프로처럼 앱을 써도, 표시는 계정 역할대로 `STAFF`예요.
- 얼굴 표시는 시안 C로 정했어요 (2026-11-25).
- 시안: `prototype/role-badge-options.html`

### 마이 · 알림 · 설정 (시안, 2026-11-25)

시안 `prototype/role-screens.html` — **지금 앱 화면을 그대로 찍고 정보만 바꿨어요** (디자인 · 부품은 그대로, 2026-11-25 사용자 규칙). 회원 화면이 기준이에요.

| 역할 | 마이 | 알림 (회원 알림에 더해) | 설정 |
|---|---|---|---|
| 프로 | 이름 옆 `PRO` · 아래 줄 지점 · 가르치는 언어 · 숫자 칸 = 이번 달 세션 · 출석률 · 보낸 노트 · 받은 고마워요 · PRO'S NOTE 카드 = 쓰는 중인 내 노트 · 내 스터디 카드 → **내 수업**(이번 주 맡은 세션, 버튼 = 내 일정 전체 보기) · 랭킹 · 내 활동 · 기타는 회원과 같아요 (보낸 노트는 PRO'S NOTE 카드 › 모두 보기) | = | = |
| 스텝 | 이름 옆 `STAFF` · 아래 줄 하남점 · 지점 관리자 · 나머지는 회원과 같아요 (내 스터디 = **보여 주기 예시**). 본사 운영자는 소속 PALLO | = | = (내 활동 · 기타는 회원과 같아요) |
| 호스트 | 팔로워 옆 **운영 중 n** (누르면 운영 · 참여 모임 목록) · 숫자 칸 받은 배지 → **호스트 점수 ★** · 내 활동 + 내가 연 모임 (가입 신청 n) | = | = |
| 코호스트 | 팔로워 옆 **운영 중 n** · 내 활동 + 함께 운영하는 모임 (가입 신청 n) | = | = |

- 마이의 **이용권 · 결제 내역** 줄은 모든 역할에서 빼요 (2026-11-25).
- **다른 사람 프로필**(시트): 학습 언어 · 팔로잉 · 팔로워 옆에 **운영 중 n**. 숫자를 누르면 팔로워 목록 시트와 같은 시트에 **운영 중 · 참여 중 · 참여 예정** 탭(동아리 · 번개 · 챌린지 · 이벤트), 줄을 누르면 그 모임 화면. 내 마이도 같아요 (2026-11-25).
- **앱에 들어간 것 (2026-11-25):** 다른 사람 프로필 시트 — 이름 아래 줄 `학습 언어 · 지점 · 가입 연도` (@아이디는 뺐어요) (학습 언어 칸은 뺐어요). 숫자 칸은 **팔로잉 · 팔로워 · 참여 중**. 참여 중을 누르면 팔로워 목록 시트와 같은 모양의 시트에 분야별 탭 **동아리 · 번개 · 챌린지** (번개는 다가오는 것만). 그 사람이 호스트인 것(운영 중)은 탭 맨 위에 `HOST` 글자. 줄을 누르면 시트를 닫고 그 상세로. 참여는 API가 없어서 지금은 샘플이에요 (components/my/profile-meets.tsx).
- **동아리 관리**: 아래 `가입 신청` 버튼 자리가 `관리`로 바뀌고, 누르면 지금 앱의 메뉴 시트(⋯ 글 메뉴 시트)에 관리 항목이 떠요.
- **PRO'S NOTE**: 프로는 회원이 받는 노트 화면을 그대로 써서 쓰고 보내요 (목록 = 보낸 노트 · n명 읽음, 아래 버튼 = 항목 더하기 · 반에 보내기).
- 라운지 이름 옆 역할 글자(지금 '리더')와 ⋯ 메뉴의 '공지로 고정 · 이 글 숨기기'는 지금 앱에 있어요 → 글자만 프로 · STAFF로.
- 왕관 · HOST · CO-HOST는 마이에 붙지 않아요 (그 모임 안에서만).
- 백엔드: 마이 숫자(이번 달 세션 · 보낸 노트 · 받은 고마워요 · 호스트 점수 · 운영 중 수)가 새로 필요해요. 알림 종류는 회원과 같아요.
