# 챌린지

> **제안 경로:** `/lounge?tab=chal`, `/lounge/challenge/:id` · **모듈:** 챌린지 (라운지 안 탭) · **기준:** v342
> 관련 코드: `LG_CHCAT`, `lgChalDetail`, `lgChkSheet`, `chxSheet`, `CH_SRC`, `CH_PW`, `cardOf`

## 개요

회원이 함께 꾸준히 하는 도전이에요. 두 종류가 있어요.

| 종류 | 무엇 | 참여 · 인증 |
|---|---|---|
| **일상 챌린지** | 공부 습관 · 건강 · 식단 · 운동 · 아침 루틴 · 자유 | 기간 · 인증 주기가 있고, 정해진 방법(댓글 / 사진 + 댓글)으로 인증. 순위 있음 |
| **표현 챌린지** ('나만의 문장 완성하기') | 내 표현함의 표현 하나 | 기간만 있음. 누구나 그 표현으로 **내 이야기 문장**을 쓰면 참여 |

학습에서 저장한 표현을 다른 회원과 실제로 써 보게 이어 주는 곳이에요 (흐름 F4).

## 챌린지 탭 구성 (위 → 아래)

1. **지금 핫한 챌린지 TOP 3** — 참여 + 좋아요 + 오늘 인증 수로 골라요. 누르면 상세.
2. **표현 챌린지** — '3개 · 옆으로 넘겨 보세요' 옆으로 넘기는 한 줄(카드 폭 84%) + '모두 보기 ›'(표현 필터로).
3. **진행 중 N | 참여 중 N** 탭 — 참여 중인 챌린지가 있으면 참여 중이 먼저 열려요. 오른쪽에 '오늘 인증 1개 남았어요'.
4. **곧 시작해요** 묶음.
5. 맨 위에 **내가 연 챌린지**(노란 빛 반짝, 일정 · 인증 방법, 시작 전이면 [멤버 초대]).

필터: 전체 · 참여 중 · 카테고리(표현 · 공부 습관 · 건강 · 식단 · 운동 · 아침 루틴 · 자유). 표현 필터에서는 검색(표현 · 뜻 · 예문 · 연 사람 · 출처).

## 카드

### 일상 챌린지 카드 (가로형, 약 125px)

왼쪽 색 칸(카드 문구 두 줄 — 예: EAT WELL · MOVE DAILY · WAKE UP) + 오른쪽 상태 · 이름 · 일정 한 줄 · 인원(프사 3명 + `+7`) + 진행 막대 + 버튼 하나([참여하기] / 시작 전 [도전 신청] / '참여 중'). 아래에 연 사람 프사.

### 표현 챌린지 카드

맨 위 `나만의 문장 완성하기 · 연 사람 · 14일 남음` → 표현 크게 · 뜻(보라 한 줄) · 나온 곳 · 듣기 → [문장 쓰기](연필) → `4명 · 문장 4`. 댓글이 없으면 '첫 댓글로 이 표현을 써 보세요'.

## 챌린지 상세 (일상)

| 영역 | 내용 |
|---|---|
| 위 | 진행 카드 (`17/30일` + 게이지) |
| 탭 | 홈 · 인증 · 순위 |
| 홈 | 인증 가이드, 기간 · 주기, 인증 방법, 호스트, 멤버, 내 인증 7일, 최근 인증 |
| 인증 | 멤버 인증 피드: 사진(고른 비율) → 좋아요 · 답글 아이콘 → 글. 답글 창(원래 인증 + 답글, 대댓글 · 수정 · 삭제) |
| 순위 | 인증 횟수 순. 맨 위 내 순위 카드(몇 위 · 앞사람까지 며칠) 또는 '참여하면 순위에 들어가요', 1~3위 시상대, 4~10위 목록(호스트 표시), 10위 밖이면 맨 아래 내 줄 |
| 아래 고정 | 찜 · [참여하기] / [오늘 인증하기] |

- 카드의 [참여하기]는 상세를 열기만 해요. 상세에서 한 번 더 눌러야 참여돼요.
- 참여하면 응원 시트: 팔로 + '챌린지 성공을 응원해요!' + 이름 · 함께하는 인원 · [나중에 할게요] [바로 인증하러 가기]. 곧 시작하는 챌린지는 '도전 신청'.
- **오늘 인증**: 댓글 방식은 한 줄 소감. 사진 + 댓글 방식은 커뮤니티 글쓰기와 같은 사진 편집(앨범 · 촬영 · 위치 · 비율 · 여러 장) → 다음 → 한 줄 소감. **사진 없이는 다음으로 못 가요.** 이미 인증했으면 '오늘은 이미 인증했어요'.

## 표현 챌린지 창

- 위에 표현 카드(예문) + '예문 말고, 내 이야기로 문장을 만들어요.'
- 탭: **나만의 문장 | 팁 · 질문**. 좋아요 · 답글.
- 문장 · 팁 · 답글을 **처음 다는 순간 자동 참여**('챌린지에 참여했어요'), 카드에 '참여 중'. 댓글을 달지 않았으면 참여 중이 아니에요(v341).

## 챌린지 열기

| 필드 | 일상 | 표현 |
|---|---|---|
| 카테고리 | 공부 습관 · 건강 · 식단 · 운동 · 아침 루틴 · 자유 | 표현 |
| 이름 | 필수 | 없음 (표현이 이름) |
| 카드 문구 | 영어 두 줄 · 한 줄 9자 · 자동 대문자 · 왼쪽 색 미리 보기. 비우면 카테고리 문구 | — |
| 시작 | 오늘 · 내일 · 다음 주 월요일 | 바로 (곧 시작 없음) |
| 기간 | 3 · 7 · 14 · 21 · 30일 | 3 · 7 · 14 · 30일 |
| 인증 주기 | 매일 / 주 몇 회(1~6, − +) / 요일 정하기(여러 개) | 없음 |
| 요약 | '인증 N번이면 완주해요' 자동 계산 | — |
| 인증 방법 | 댓글로 인증 / 사진 + 댓글 | 댓글 고정 |
| 어떻게 인증하나요? | 안내 칸 | — |
| 표현 | — | '아래 표현에서 불러오세요' — 내 표현함에서 **한 번에 하나** |
| 첫 문장 | — | '내가 먼저 만든 문장' (고른 표현 예문이 예시로) |

- **표현 고르기 목록**: 찾기(표현 · 뜻), 나온 곳 칩(전체 · 교재 · 상황 · 프리토킹 · 리스닝), 6개씩 + 'N개 더 보기', 고른 표현은 맨 위. 나온 곳 한 줄(넘치면 …).
- **같은 표현 중복 막기**: 기간이 남은 같은 표현 챌린지가 있으면 '이미 있는 챌린지예요' + [참여하기 / 보러 가기], [챌린지 열기]는 흐려지고 안 눌려요. 같은 표현 판단은 소문자 · 기호 없이 비교하고 한쪽이 다른 쪽을 품어도 같다고 봐요 (예: `Could you say that again` ↔ `say that again`). 기간이 끝난 표현은 다시 열 수 있어요.

## 수용 기준

- [ ] 표현 챌린지는 내 표현함의 표현 하나로만 열리고, 기간이 남은 같은 표현이 있으면 열리지 않고 그 챌린지로 안내한다.
- [ ] 표현 챌린지는 문장 · 팁 · 답글을 처음 단 순간부터 '참여 중'이다.
- [ ] 일상 챌린지의 '인증 N번이면 완주해요'가 시작 · 기간 · 주기로 맞게 계산된다.
- [ ] 사진 + 댓글 방식은 사진 1장 이상 없이 인증할 수 없다.
- [ ] 하루에 한 번만 인증된다.
- [ ] 카드의 참여하기는 상세를 열고, 상세에서 다시 눌러야 참여된다.
- [ ] 순위는 인증 횟수 순이고, 10위 밖이면 내 줄이 맨 아래에 보인다.
