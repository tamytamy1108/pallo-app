# 공통 요소

> **모듈:** 공통 · **기준:** v342
> 관련 코드: `lgGate`, 체험 신청(`TR_BR`, `TR_TIMES`), `lgComments`, `toast`, `lgSheet`, 신고 · 차단 메뉴, 신고함

여러 화면이 같이 쓰는 시트와 동작이에요.

## 체험 안내 시트 (비회원 막힘)

- 비회원이 댓글 · 참여 · 가입 · 글쓰기 · 제안 같은 행동을 누르면 떠요 (`lgGate(이유)`). **좋아요는 막지 않아요** (v291).
- 내용: `함께하려면 체험부터 해요` · 이유 한 줄 + 'PALLO 체험 세션에서 시작해요' · 체험하면 되는 것(가까운 지점 체험 세션 1회 · 번개 · 동아리 · 파티 참여 · 좋아요 · 댓글 · 글쓰기) · '지금은 구경만 할 수 있어요. 체험 신청은 1분이면 끝나요.'
- 버튼: [구경 계속하기] · [체험 신청하기].

## 체험 신청 (3단계 + 완료)

| 단계 | 필드 | 규칙 |
|---|---|---|
| 1 지점 | 지점 목록(이름 · 주소 · 가까운 역) | 필수 |
| 2 언어 · 날짜 · 시간 | 언어 4개 / 날짜 달력 / 시간 칩(예시 10:30 · 14:00 · 19:30 · 20:30) | **일요일 휴무**, 마감된 시간은 표시 · 못 고름. 교재 소개 · 다른 언어에서 오면 언어가 미리 골라짐 |
| 3 내 정보 | 이름 · 휴대폰 · 실력 · 개인정보 동의([보기] → 처리방침) | 동의 필수 |
| 완료 | 예약 요약 · 오시는 길 | — |

들어오는 곳: 체험 안내 시트, 교재 소개 '이 레벨 상담 신청', 마이 › 학습 언어 › 다른 언어 배우기. 체험 시간표 · 예약 확정 방식은 Q-B1 · Q-T2.

## 댓글 창 (모든 댓글 통일)

- 커뮤니티 글 · 스토리 · 동아리 게시판 · 챌린지 인증 모두 같은 큰 창(화면 84%).
- 가운데 '댓글' 제목, 프로필 · 이름 · 시간 · 작성자 표시, [답글 달기] · '답글 N개 더 보기', 오른쪽 좋아요 하트 + 수.
- 내 댓글은 수정 · 삭제(되돌리기). 아래 입력칸 고정. 낱말 단위 줄바꿈.
- 스토리 댓글은 공개, '답장 보내기'는 비공개 (올린 사람에게만).

## 신고 · 차단

- 모든 글 ⋯ 메뉴, 멤버 프로필 [차단 · 신고].
- **신고하기**: 사유 고르기 → 접수. 신고한 사람은 상대에게 알려지지 않아요(이벤트 안내 문구). 내 신고는 설정 › 신고 내역에 쌓여요.
- **차단하기**: 그 사람 글이 바로 사라짐, 되돌리기 가능. 설정 › 차단한 멤버에서 풀어요.
- **신고함 (매니저)**: 글 메뉴 '신고함 보기 · 이번 주 신고 2건' → 처리 전 · 처리 완료 탭, 남은 시간 → 누르면 원문 + [숨기기] [경고] [이용 제한] [문제 없음] → 처리 완료로 이동. 공지 문구 기준 '신고되면 매니저가 24시간 안에 확인'. 단계 · 기간은 Q-B8.
- **프로 · 지점 관리자 글 메뉴**: 공지 고정 · 글 숨기기.

## 시트 · 확인 창

- 아래에서 올라오는 크림 시트(모서리 28px). 긴 시트는 [적용하기] · [올리기] 같은 버튼이 아래 고정.
- 입력칸 글자색은 잉크로 고정 (어두운 모드 기기에서 흰 글씨로 안 보이던 문제 방지).
- 되돌릴 수 없는 행동은 확인 창을 거쳐요 (참여 취소 · 동아리 나가기 · 신청 취소 · 학습 그만두기 · 로그아웃 · 탈퇴).

## 아이콘 · 캐릭터 · 효과음

- 아이콘: `ICONS` / `ICON(이름, 크기)` (48×48 기준, 진한 테두리 + 브랜드 색, 일부에 캐릭터 눈 `EYES`). 라벨 · 칩 · 공지 태그에는 아이콘을 넣지 않아요.
- 캐릭터 원본: `characters/3d`, 줄인 파일 `prototype/assets/c-*.png`, `assets/av/*`. 원본 PNG의 반투명 그림자 픽셀은 지웠어요.
- 효과음: `SFX` (임시, 사운드 디자이너 음원으로 교체).

## 수용 기준

- [ ] 비회원이 막힌 행동을 누르면 같은 체험 안내 시트가 뜨고, 좋아요는 바로 된다.
- [ ] 체험 신청에서 일요일과 마감된 시간은 고를 수 없고, 개인정보 동의 없이 완료할 수 없다.
- [ ] 모든 댓글 창이 같은 모양 · 같은 기능(답글 · 좋아요 · 내 댓글 수정 · 삭제)이다.
- [ ] 차단하면 그 사람 글이 바로 사라지고, 되돌리기 · 차단 목록에서 풀 수 있다.
- [ ] 신고함은 매니저에게만 보이고, 처리하면 처리 완료 탭으로 옮겨진다.
