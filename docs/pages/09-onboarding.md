# 시작 · 가입 · 사용 가이드

> **제안 경로:** `/start`, `/signup/:step`, `/branch-link`, `/guide`
> **모듈:** 시작 · 가입 · **기준:** 시안 [`prototype/onboarding-options.html`](../../prototype/onboarding-options.html) (2026-11-23)
> `prototype/index.html`에는 아직 없어요. 시안이 정해지면 옮겨요.

## 개요

앱을 처음 열었을 때부터 홈에 들어가기까지예요. 세 덩어리로 나뉘어요.

1. **첫 화면**: 그림 + 로그인 버튼. 그림과 문구는 운영팀이 **관리자 웹에서 올려요**.
2. **가입 단계**: 처음 로그인한 계정만 거쳐요. 약관 → 닉네임 → 캐릭터 → 지점 회원 확인 → (회원) **지점 연동 요청** → 알림 → 환영.
   지점 회원은 연동 요청을 보내고 **지점이 전산과 맞춰 연동해야** 회원 기능이 열려요.
3. **사용 가이드 5장**: 로그인에 성공하면 홈 전에 슬라이드로 보여요. 5장 모두 **관리자 웹에서 올려요**.

첫 화면과 사용 가이드는 앱 업데이트 없이 바꿀 수 있어야 해요. 연동 요청은 지점 매니저가 관리자 웹에서 처리해요. 앱은 틀(배치 · 버튼 · 넘기는 동작)만 갖고, 그림 · 글은 서버에서 받아요.

## 흐름

```
앱 열기
 └─ 첫 화면 (관리자 웹 그림이 화면을 꽉 채움 + 그 위에 앱 고정 로그인 버튼)
     ├─ [카카오로 시작하기] → 카카오 동의 창 → 로그인 성공
     ├─ [Apple로 계속하기] → 로그인 성공
     ├─ [다른 방법] → 구글 · 휴대폰 번호
     └─ [먼저 둘러볼게요] → 비회원 구경 모드 (라운지 · 이벤트 보기 + 좋아요)

로그인 성공
 ├─ 처음 가입한 계정 → 약관 동의 → 닉네임 → 캐릭터 → 지점 회원이에요?
 │                     ├─ 네 → 지점 연동 요청 보내기 → 연동 기다리는 중 (둘러보기는 됨)
 │                     │        └ 지점이 처리하면 알림 → 연동 완료(회원) / 연동 안 됨(이유 + 다시 요청)
 │                     ├─ 체험해 보고 싶어요 / 앱으로만 → 언어 · 레벨

사용 가이드 1 → 2 → 3 → 4 → 5 [PALLO 시작하기] → 홈
             (어느 장에서든 [건너뛰기] → 홈)
```

## 1. 첫 화면

> **정한 것 (2026-11-23):** 첫 화면은 포스터 'YOUR FIRST STAGE'를 움직이게 만든 시안으로 해요 → [`prototype/start-screen-motion.html`](../../prototype/start-screen-motion.html). 조명이 깜빡이며 켜지고 → 무대가 펼쳐지고 → 팔로가 떨어져 착지하고 → 문구가 올라온 뒤, 조명이 좌우로 흔들리고(한쪽 2.8초) 팔로가 숨 쉬듯 움직여요. 로고 줄은 상태 바 바로 아래, 한국어 문구는 카카오 버튼 위 28px. 로고는 브랜드 원본 스파크 심볼 + PALLO! 워드마크. 앱에 넣는 방식(소리 없는 반복 영상 vs Lottie)은 아직 안 정했어요.

### 무엇을 누가 바꾸나요

| 칸 | 내용 | 누가 |
|---|---|---|
| 화면 전체 그림 | 같은 그림을 화면 비율 3가지로 만든 3장 + 바탕색 + 그림 설명. 글씨는 그림 안에 | **관리자 웹** |
| 로그인 버튼 | 그림 위 아래쪽(버튼 자리)에 떠 있는 카카오로 시작하기 · Apple로 계속하기 · 다른 방법 · 먼저 둘러볼게요 | **앱 고정** |
| 버튼 · 링크 색 | 바탕색이 어두우면 흰 테두리 · 흰 글씨, 밝으면 잉크 | **앱이 자동으로** |
| 기본 화면 | PALLO 글자 + 보라 캐릭터 (크림 바탕) | **앱에 넣어 둠** |

로그인 버튼은 관리자 웹에서 못 바꿔요. 카카오 · Apple 버튼 사용 규칙(색 · 심볼 · 글자)과 안전 영역을 앱이 지켜야 해서예요.

### 잘리지 않고 화면을 꽉 채우는 법

폰마다 화면 비율이 달라서 그림 한 장을 늘 꽉 채우면 어딘가 잘려요. 그래서 **비율별로 3장**을 받고, 앱이 기기에 맞는 한 장을 골라 **가로 폭에 딱 맞춰** 그려요. 잘리는 곳은 없어요.

| 그림 | 크기 (px) | 비율 (세로 ÷ 가로) | 맞는 기기 |
|---|---|---|---|
| 짧은 화면 | 1242 × 2208 | 1.78 (9:16) | 아이폰 SE · 8 · 8 Plus, 옛 안드로이드 |
| 기본 | 1290 × 2780 | 2.155 (약 9:19.4) | 아이폰 X 이후 전부(2.16~2.17), 갤럭시 S 일반(9:19.5) |
| 긴 화면 | 1290 × 2866 | 2.22 (9:20) | 20:9 안드로이드, 그보다 긴 21:9 · 플립 |

**앱이 고르고 그리는 순서**

1. 화면 비율(세로 ÷ 가로)을 구해요.
2. 세 장 중 **화면보다 길지 않은 것** 가운데 가장 긴 것을 골라요. (기본 그림을 2.155로 살짝 짧게 잡은 이유: 아이폰 14 Plus(2.163)처럼 9:19.5보다 아주 조금 짧은 기기도 '기본'을 쓰게)
3. 그림을 **화면 가로 폭에 맞춰** 맨 위부터 그려요. 좌우 · 위아래 어디도 잘리지 않아요.
4. 화면이 그림보다 길면 남는 **맨 아래**를 바탕색으로 채워요. 예: 아이폰 15는 3px, 갤럭시 Z 플립(9:22)은 화면 높이의 약 9%.
5. 태블릿 · 폴더블 펼침처럼 9:16보다 넓은 화면은 짧은 화면 그림을 **세로 높이에 맞추고**, 양옆을 바탕색으로 채워요.

남는 곳이 늘 맨 아래 버튼 자리라서, 그림 맨 아래가 바탕색 한 가지로 끝나면 이어 붙인 티가 안 나요.

**그림 만드는 규칙 (관리자 웹 '틀 파일 받기'에 안내선이 있어요)**

- 위 5%: 시계 · 배터리 자리. 글씨 · 얼굴을 두지 않아요.
- 아래 30%(짧은 화면은 33%): **버튼 자리**. 중요한 내용을 두지 않고, 맨 아래 줄은 **바탕색 한 가지**로 끝나게.
- 버튼 자리에 카카오 노랑(`#FEE500`)이나 PALLO 노랑을 넓게 깔지 않아요(카카오 버튼이 묻혀요).
- 문구 · 날짜 같은 글씨는 그림 안에 넣고, 같은 내용을 `그림 설명`에도 써요(화면 읽기 프로그램용). 앱이 글씨를 따로 얹지 않아요.

### 어떤 그림을 보여 주나요

- 관리자 웹에 올린 시작 화면 중 **지금 기간 안에 있는 것**을 보여 줘요. 여러 개가 겹치면 목록에서 위에 있는 것 하나.
- 기간 안에 있는 게 없으면 **기본 화면**.
- 앱은 받은 그림을 기기에 저장해 두고, **다음에 열 때** 바로 띄워요. 화면을 열 때마다 서버를 기다리지 않아요.
- 처음 설치해서 저장된 그림이 없거나 인터넷이 안 되면 **기본 화면**을 띄우고, 뒤에서 그림을 받아 둬요.
- 예약된 다음 시작 화면도 미리 받아 둬요. 시작 날짜가 되면 인터넷 없이도 바뀌어요.
- 받아 둘 때는 세 장을 다 받지 않고, 이 기기에 맞는 한 장만 받아요.

### 버튼 규칙

- 카카오 버튼이 맨 위, 가장 커요. 카카오 공식 노랑 `#FEE500` + 검은 말풍선 심볼 + `카카오로 시작하기`.
- PALLO 노랑(`#FFE200`)과 카카오 노랑이 거의 같아요. **카카오 버튼은 PALLO 노랑 바탕 위에 올리지 않아요.** 그래서 버튼 자리(그림 아래 30%)에 노랑을 넓게 쓰지 않게 관리자 웹이 경고해요.
- iOS는 다른 소셜 로그인이 있으면 Apple 로그인도 있어야 해요. Android에서도 같은 배치로 둬요.
- 구글 · 휴대폰 번호는 `다른 방법`을 누르면 시트로 열려요.
- 카카오 동의 창에서 취소하면 첫 화면으로 돌아오고 토스트 `로그인을 취소했어요`.

## 2. 가입 단계 (처음 로그인한 계정만)

진행 바는 4칸이에요: 닉네임 → 캐릭터 → 회원 확인 → 연동 요청(또는 언어 · 레벨). 약관 · 알림 · 환영은 칸에 넣지 않아요.

| 단계 | 내용 | 규칙 |
|---|---|---|
| 약관 동의 | 시트: 전체 동의 / [필수] 만 14세 이상 · 서비스 이용약관 · 개인정보 수집 · 이용 / [선택] 이벤트 · 번개 소식 받기 | 필수를 다 체크해야 `동의하고 시작하기`가 켜져요. 선택 동의는 동의 날짜를 기록 (설정 › 알림의 광고 동의와 같은 값) |
| 닉네임 | 카카오 이름을 미리 채워 둠 + 주사위(추천 이름) + 추천 칩 3개 | 2~10자, 한글 · 영문 · 숫자. 입력하는 동안 중복 확인. 카카오 이름이 규칙에 안 맞으면 빈칸으로 시작 |
| 캐릭터 | 몸 색 7가지(노랑 · 보라 · 보라 속눈썹 · 핑크 · 하늘 · 초록 · 코랄) | 고른 색이 마이 캐릭터의 기본 몸 색. 옷 · 소품은 마이 › 꾸미기 |
| 지점 회원이에요? | 네, 지점 회원이에요 / 체험해 보고 싶어요 / 앱으로만 공부할래요 / 일단 구경만 할게요 | 고른 답으로 `role` · `userType`이 정해져요 |
| 지점 연동 요청 (회원) | 지점 · 이름 · 휴대폰 · 배우는 언어 + 정보 보내기 동의 → `연동 요청 보내기` | 아래 [3. 지점 연동 요청](#3-지점-연동-요청) |
| 언어 · 레벨 (회원 아님) | 언어 4개 + 지금 실력 3단계(처음이에요 · 짧은 대화는 돼요 · 자유롭게 말해요) | 정확한 레벨은 첫 세션이나 앱 레벨 테스트에서 |
| 알림 허용 | 어떤 알림이 오는지 3개 예시를 먼저 보여 줌 | `알림 받을게요`를 눌렀을 때만 기기 알림 창을 띄워요(iOS는 한 번 거절하면 다시 못 띄워서) |
| 환영 | 캐릭터 + 이름표 + `반가워요, ○○님!` + 스파크 +50 | 버튼 → 사용 가이드 |

닉네임 화면은 시안이 세 가지예요(이름표 붙이기 · PALLO 여권 · 팔로와 대화). 추천은 이름표 붙이기. **아직 정하지 않았어요.**

## 3. 지점 연동 요청

지점 회원 정보(이름 · 번호 · 팀 · 레벨 · 이용권)는 **지점 전산**에 있어요. 앱 계정만으로는 누가 어느 지점 회원인지 몰라요. 그래서 회원이 **연동을 요청**하고, **지점 매니저가 전산 회원과 맞춰 연동**해야 회원처럼 쓸 수 있어요.

### 들어오는 곳

- 가입 단계 '지점 회원이에요?' → `네, 지점 회원이에요`
- 처음에 `일단 구경만` · `체험` · `앱으로만`을 고른 사람: 마이 › 설정 › 계정 › 내 지점 › `지점 연동 요청`, 홈 맨 위 띠 `지점 회원이라면 연동을 요청해요`
- 두 번째 지점(최대 2곳)도 같은 화면으로 요청해요.

### 요청 화면

| 칸 | 규칙 |
|---|---|
| 지점 | 필수. 지점 목록에서 고르기 (이미 연동된 지점 · 요청 중인 지점은 못 고름) |
| 이름 | 필수. **지점에 등록한 이름** (앱 닉네임 아님). 2~20자 |
| 휴대폰 | 필수. 로그인 때 확인한 번호를 미리 채움. 다른 번호로 바꾸면 인증번호 확인 다시 |
| 배우는 언어 | 선택. 모르면 비워 둬요 (지점이 찾을 때 참고) |
| 동의 | [필수] 고른 지점에 이름 · 휴대폰 번호를 보내는 데 동의 |

`연동 요청 보내기` → 연동 기다리는 화면.

### 상태

| 상태 | 회원 화면 | 앱에서 되는 것 |
|---|---|---|
| 요청 보냄 · 지점 확인 중 (`pending`) | `○○점에 연동을 요청했어요` · 진행 표시(요청 보냄 → 지점 확인 중 → 연동 완료) · `보통 하루 안에 끝나요` · [먼저 둘러볼게요] · `요청 취소` · `○○점에 전화` | 비회원과 같아요(구경 · 좋아요 · 꾸미기 · 레슨 맛보기). 홈 맨 위에 `○○점 연동 확인 중` 띠 |
| 연동 완료 (`linked`) | 푸시 알림 → 앱을 열면 한 번: `연동됐어요! 이제 ○○점 회원이에요` + 회원증(지점 · 언어 · 레벨 · 팀 · 남은 세션) + 다음 세션 → [홈으로] | 회원 기능 전부: 출석 · 내 팀 · 이용권 · 프로 노트 · 라운지 참여 · 글쓰기 |
| 연동 안 됨 (`rejected`) | 푸시 알림 → `○○점에서 회원 정보를 찾지 못했어요` + 지점이 남긴 말 + 보낸 정보 → [고쳐서 다시 요청하기] [○○점에 전화하기] `지금은 둘러볼게요` | 비회원과 같아요 |
| 취소 (`canceled`) | 회원이 기다리는 중에 `요청 취소` | 비회원과 같아요 |

- 지점마다 기다리는 요청은 하나만. 연동 안 됨 · 취소 뒤에는 다시 보낼 수 있어요.
- 24시간 안에 처리되지 않으면 지점 매니저에게 알림을 한 번 더 보내고, 회원 화면 문구를 `조금 늦어지고 있어요. 급하면 지점에 전화해 주세요`로 바꿔요.
- 연동 완료 화면의 `제 정보가 아니에요` → 지점 문의(전화) 안내. 잘못 연동된 건 지점이 관리자 웹에서 풀어요.
- 연동되면 `role`은 `member`, `userType`은 `member`(스터디 회원), `branchIds`에 지점이 들어가고, 지점 전산의 팀 · 레벨 · 이용권을 읽어 와요.

## 4. 사용 가이드 (5장)

### 언제 보여 주나요

- **로그인에 성공하면 홈 전에** 보여요. 처음 가입한 계정은 가입 단계(환영)가 끝난 뒤에 보여요.
- **계정마다 한 번.** 끝까지 봤든 건너뛰었든 그 판(버전)은 다시 안 보여요. 기기를 바꿔도 마찬가지예요(서버에 기록).
- 관리자가 새 판을 게시하면서 `이미 본 회원에게도 한 번 더 보여 주기`를 켜면, 다음 로그인 · 앱 열기 때 한 번 더 보여요.
- 비회원 구경 모드(`먼저 둘러볼게요`)에서는 보여 주지 않아요. 나중에 로그인하면 보여요.
- **다시 보기:** 마이 › 설정 › 도움 › 사용 가이드. 여기서 볼 때는 기록하지 않아요.

### 화면

| 자리 | 내용 |
|---|---|
| 맨 위 | 왼쪽 `1 / 5`, 오른쪽 `건너뛰기` (마지막 장에서는 숨김) |
| 그림 칸 | 정사각형, 잉크 2px 테두리, 모서리 24px. 관리자가 고른 배경색 위에 올린 그림 |
| 제목 | 최대 20자, 21px 900 |
| 설명 | 최대 60자(약 2줄), 13.5px |
| 아래 | 점 5개(지금 장은 긴 막대) + 노랑 버튼 `다음`, 마지막 장은 `PALLO 시작하기` |

### 동작

- 옆으로 밀거나 `다음`을 누르면 다음 장. 반대로 밀면 이전 장.
- `건너뛰기` · `PALLO 시작하기` → 홈. Android 뒤로 가기는 이전 장, 첫 장에서는 건너뛰기와 같아요.
- 가이드를 서버에서 못 받으면 **막지 않고 바로 홈**으로 가요. 그림 한 장만 못 받으면 그 칸은 배경색만 보여요.
- 동작 줄이기가 켜져 있으면 넘길 때 미끄러지는 움직임 없이 바로 바뀌어요.
- 글씨를 크게 쓰는 기기에서는 설명이 잘리지 않고 아래로 늘어나요(버튼은 아래 고정).
- 그림에는 관리자가 쓴 `그림 설명`을 붙여요(화면 읽기 프로그램용).
- 끝까지 봤는지, 몇 장째에서 건너뛰었는지 서버에 남겨요(어느 장에서 많이 나가는지 보려고).

### 기본 내용 (예시, 관리자 웹에서 바꿈)

| 장 | 제목 | 설명 |
|---|---|---|
| 1 | 세션 날엔 QR로 출석 | 지점에 도착하면 홈 스터디 카드에서 QR을 찍어요. 전날 미리 '사전 출석'도 돼요. |
| 2 | 세션 전 5분, 미리 말해 봐요 | 라이브러리에서 오늘 배울 과의 예습을 풀어요. 세션이 끝나면 복습으로 한 번 더. |
| 3 | 세션 밖에서도 같이 떠들어요 | 라운지에서 번개 · 동아리 · 챌린지로 다른 회원과 이어져요. |
| 4 | 하루 하나면 연속 학습 | 학습 단계를 하루 1개 이상 하면 이어져요. 모은 스파크로 캐릭터를 꾸며요. |
| 5 | 내 스터디는 마이에서 | 이용권 · 연기 · 팀 변경 · 프로 노트를 한곳에서 봐요. |

1장(출석) · 5장(이용권)은 지점 회원 이야기예요. 체험 · 앱 구독자에게 다른 내용을 보여 주려면 관리자 웹에서 대상별 가이드를 따로 올려요.

## 5. 관리자 웹

관리자 웹 '홈 운영' 묶음([api-additions 2장](../frontend/api-additions.md#2-관리자-웹-api-개요-7묶음))에 메뉴 두 개를 더해요: **시작 화면**, **사용 가이드**. 둘 다 본사 운영 담당이 게시하고, 지점 매니저는 보기만 해요(제안).

### 공통 흐름

```
올리기 · 고치기 → [임시 저장] → [미리보기] (폰 틀, 기기 크기 2~3개) → [게시하기] 또는 [예약]
게시한 것은 '판'으로 쌓여요 → 이전 판 [되돌리기]
```

- 저장할 때 막는 것: 필수 칸 비어 있음, 글자 수 넘음, 그림 규격 · 용량 안 맞음, 기간이 거꾸로.
- 누가 언제 게시했는지 남겨요(목록에 `3번째 판 · 11.20 · 김매니저`).

### 시작 화면 메뉴

| 칸 | 규칙 |
|---|---|
| 그림 3장 | 모두 필수. 짧은 화면 1242 × 2208 · 기본 1290 × 2780 · 긴 화면 1290 × 2866. 크기가 정확히 같아야 올라가요. JPG · PNG · WebP, 한 장에 5MB 이하. `틀 파일 받기`로 안내선(위 5% · 버튼 자리 30%)이 그려진 틀을 받아요 |
| 바탕색 | 세 장 맨 아래 줄에서 자동으로 뽑아요. 바꿀 수 있어요. 화면이 그림보다 길 때 남는 곳을 이 색으로 채워요 |
| 그림 설명 | 필수. 그림 속 글씨를 그대로 (화면 읽기 프로그램용) |
| 저절로 확인 | 크기 · 용량, 세 장 맨 아래 줄이 바탕색 한 가지인지, 버튼 자리에 카카오 노랑과 비슷한 색이 넓게 있는지(경고). 위 5%의 글씨는 미리보기로 사람이 확인 |
| 미리보기 | 아이폰 SE · 아이폰 15 · 갤럭시 Z 플립 세 기기에 버튼을 얹은 모습 |
| 기간 | 시작일 필수, 끝나는 날은 비우면 `계속` |
| 순서 | 목록에서 끌어서. 기간이 겹치면 위가 이겨요 |
| 상태 | 임시 저장 · 예약 · 게시 중 · 끝남 (끝난 것은 `다시 쓰기`로 복사) |

### 사용 가이드 메뉴

| 칸 | 규칙 |
|---|---|
| 대상 | 전체 · 지점 회원 · 체험 · 비회원 · 앱 구독자. 대상별 가이드가 없으면 `전체`를 보여 줘요 |
| 장 수 | 5장 고정. 끌어서 순서 바꾸기 |
| 그림 (장마다) | 필수. 정사각형 1080px 이상, PNG · JPG · WebP, 2MB 이하. **글씨는 그림에 넣지 않아요**(글씨 크기 조절 · 화면 읽기가 안 돼서). 글은 제목 · 설명 칸에 |
| 배경색 | 노랑 · 라벤더 · 연핑크 · 하늘 안개 · 베이지 · 흰색 중 하나 (DESIGN.md 팔레트) |
| 제목 | 필수, 최대 20자 |
| 설명 | 선택, 최대 60자 |
| 그림 설명 | 필수 |
| 한 번 더 보여 주기 | 게시할 때 켜면 이미 본 회원도 다음에 한 번 더 봐요. 큰 기능이 바뀌었을 때만 |

### 연동 요청 메뉴 ('지점 · 수강' 묶음)

- 지점 매니저는 **자기 지점 요청만** 봐요. 본사는 모두.
- 탭: 기다리는 중 · 연동됨 · 못 찾음. 기다리는 중은 오래된 것부터, `○시간 남음`(24시간 기준).
- 줄마다: 요청 시각 · 앱에서 보낸 정보(이름 · 번호 · 앱 닉네임 · 언어) · **지점 전산 회원 후보**(번호가 같은 회원을 자동으로 찾아 둠, `이름 · 번호 같음` / `번호 같음 · 이름 다름` / `찾지 못했어요`).
- [연동하기]: 후보(또는 `지점 전산에서 찾기`로 직접 고른 회원)와 앱 계정을 이어요 → 회원에게 푸시.
- [못 찾음으로 보내기]: 이유 고르기(등록된 번호가 달라요 · 등록된 이름이 달라요 · 우리 지점 회원이 아니에요 · 이미 다른 계정과 연동됐어요 · 직접 쓰기) → 회원에게 그대로 보여요.
- 연동됨 탭에서 [연동 풀기] (잘못 이었을 때). 누가 언제 처리했는지 남겨요.

## 수용 기준

- [ ] 첫 화면 그림을 관리자 웹에서 바꾸면, 앱 업데이트 없이 다음에 앱을 열 때 바뀐다.
- [ ] 첫 화면 그림이 아이폰 SE · 아이폰 15 · 갤럭시 Z 플립 · 태블릿 어디서도 잘리지 않고 화면을 다 채운다(남는 곳은 바탕색).
- [ ] 관리자 웹에서 그림 3장 중 하나라도 없거나 크기가 다르면 게시되지 않는다.
- [ ] 처음 설치 · 인터넷 없음 · 올린 그림 없음일 때 기본 화면이 뜨고, 로그인 버튼은 늘 누를 수 있다.
- [ ] 카카오 버튼은 맨 위, `#FEE500` + 말풍선 심볼이고, PALLO 노랑 바탕 위에 놓이지 않는다. iOS에 Apple 로그인이 있다.
- [ ] 처음 가입한 계정만 가입 단계를 거치고, 이미 가입한 계정은 로그인 뒤 바로 (가이드 →) 홈으로 간다.
- [ ] 약관 필수 항목을 다 체크하기 전에는 `동의하고 시작하기`가 꺼져 있다.
- [ ] 닉네임은 2~10자 · 한글 · 영문 · 숫자만 되고, 이미 쓰는 이름이면 `다음`이 꺼진다.
- [ ] 지점 회원은 연동 요청을 보낼 수 있고, 지점이 연동하기 전까지는 비회원 권한이다. 연동되면 푸시 알림과 연동 완료 화면이 뜨고 출석 · 내 팀 · 이용권이 열린다.
- [ ] 지점이 못 찾음으로 보내면 회원은 이유를 보고 고쳐서 다시 요청할 수 있다. 기다리는 요청은 지점마다 하나다.
- [ ] 지점 매니저는 자기 지점 연동 요청만 보고 처리한다.
- [ ] 사용 가이드는 로그인 성공 뒤 홈 전에 5장이 보이고, 넘기기 · `다음` · `건너뛰기` · `PALLO 시작하기`가 된다.
- [ ] 한 번 본(또는 건너뛴) 가이드 판은 다른 기기에서 로그인해도 다시 안 뜬다. `한 번 더 보여 주기`로 게시한 새 판은 한 번 더 뜬다.
- [ ] 가이드를 못 받아도 홈으로 들어갈 수 있다.
- [ ] 마이 › 설정 › 도움 › 사용 가이드에서 언제든 다시 볼 수 있다.
- [ ] 관리자 웹에서 필수 칸 · 글자 수 · 그림 규격이 안 맞으면 저장되지 않는다.
