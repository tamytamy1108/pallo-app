# 시작 · 가입 · 사용 가이드

> **제안 경로:** `/start`, `/signup/:step`, `/branch-link`, `/guide`
> **모듈:** 시작 · 가입 · **기준:** 시안 [`prototype/onboarding-options.html`](../../prototype/onboarding-options.html) (2026-11-23)
> `prototype/index.html`에는 아직 없어요. 시안이 정해지면 옮겨요.

## 개요

앱을 처음 열었을 때부터 홈에 들어가기까지예요. 세 덩어리로 나뉘어요.

1. **첫 화면**: 그림 + 로그인 버튼. 그림과 문구는 운영팀이 **관리자 웹에서 올려요**.
2. **가입 단계**: 처음 로그인한 계정만 거쳐요. 약관 → 닉네임 → 캐릭터 → 지점 회원 확인 → 길마다 다른 단계 → 홈. 회원은 **지점 연동 요청**, 체험은 **체험 예약**, 앱으로만은 **언어 · 이유**.
   지점 회원은 연동 요청을 보내고 **지점이 전산과 맞춰 연동해야** 회원 기능이 열려요.
3. **사용 가이드 5장**: 로그인에 성공하면 홈 전에 슬라이드로 보여요. 5장 모두 **관리자 웹에서 올려요**.

첫 화면과 사용 가이드는 앱 업데이트 없이 바꿀 수 있어야 해요. 연동 요청은 지점 매니저가 관리자 웹에서 처리해요. 앱은 틀(배치 · 버튼 · 넘기는 동작)만 갖고, 그림 · 글은 서버에서 받아요.

## 1. 첫 화면

> **정한 것 (2026-11-23):** 첫 화면은 포스터 'YOUR FIRST STAGE'를 움직이게 만든 시안으로 해요 → [`prototype/start-screen-motion.html`](../../prototype/start-screen-motion.html). 조명이 깜빡이며 켜지고 → 무대가 펼쳐지고 → 팔로로가 떨어져 착지하고 → 문구가 올라온 뒤, 조명이 좌우로 흔들리고(한쪽 2.8초) 팔로로가 숨 쉬듯 움직여요. 로고 줄은 상태 바 바로 아래, 한국어 문구는 카카오 버튼 위 28px. 로고는 브랜드 원본 스파크 심볼 + PALLO! 워드마크. 앱에 넣는 방식(소리 없는 반복 영상 vs Lottie)은 아직 안 정했어요.

### 무엇을 누가 바꾸나요

| 칸 | 내용 | 누가 |
|---|---|---|
| 화면 전체 그림 | 같은 그림을 화면 비율 3가지로 만든 3장 + 바탕색 + 그림 설명. 글씨는 그림 안에 | **관리자 웹** |
| 로그인 버튼 | 그림 위 아래쪽(버튼 자리)에 떠 있는 `카카오로 시작하기` **하나** | **앱 고정** |
| 버튼 · 링크 색 | 바탕색이 어두우면 흰 테두리 · 흰 글씨, 밝으면 잉크 | **앱이 자동으로** |
| 기본 화면 | PALLO 글자 + 보라 캐릭터 (크림 바탕) | **앱에 넣어 둠** |

로그인 버튼은 관리자 웹에서 못 바꿔요. 카카오 버튼 사용 규칙(색 · 심볼 · 글자)과 안전 영역을 앱이 지켜야 해서예요.

### 잘리지 않고 화면을 꽉 채우는 법

폰마다 화면 비율이 달라서 그림 한 장을 늘 꽉 채우면 어딘가 잘려요. 그래서 **비율별로 3장**을 받고, 앱이 기기에 맞는 한 장을 골라 **가로 폭에 딱 맞춰** 그려요. 잘리는 곳은 없어요.

| 그림 | 크기 (px) | 비율 (세로 ÷ 가로) | 맞는 기기 |
|---|---|---|---|
| 짧은 화면 | 1242 × 2208 | 1.78 (9:16) | 아이폰 SE · 8 · 8 Plus, 옛 안드로이드 |
| 기본 | 1290 × 2780 | 2.155 (약 9:19.4) | 아이폰 X 이후 전부(2.16~2.17), 갤럭시 S 일반(9:19.5) |
| 긴 화면 | 1290 × 2866 | 2.22 (9:20) | 20:9 안드로이드, 그보다 긴 21:9 · 플립 |

**앱이 고르고 그리는 순서**

1. 화면 비율(세로 ÷ 가로)을 구해요.
2. 세 장 중 **화면보다 길지 않은 것** 가운데 가장 긴 것을 골라요. (기본 그림을 2.155로 살짝 짧게 잡은 이유: 아이폰 14 Plus(2.163)처럼 9:19.5보다 아주 조금 짧은 기기도 '기본'을 쓰게)
3. 그림을 **화면 가로 폭에 맞춰** 맨 위부터 그려요. 좌우 · 위아래 어디도 잘리지 않아요.
4. 화면이 그림보다 길면 남는 **맨 아래**를 바탕색으로 채워요. 예: 아이폰 15는 3px, 갤럭시 Z 플립(9:22)은 화면 높이의 약 9%.
5. 태블릿 · 폴더블 펼침처럼 9:16보다 넓은 화면은 짧은 화면 그림을 **세로 높이에 맞추고**, 양옆을 바탕색으로 채워요.

남는 곳이 늘 맨 아래 버튼 자리라서, 그림 맨 아래가 바탕색 한 가지로 끝나면 이어 붙인 티가 안 나요.

**그림 만드는 규칙 (관리자 웹 '틀 파일 받기'에 안내선이 있어요)**

- 위 5%: 시계 · 배터리 자리. 글씨 · 얼굴을 두지 않아요.
- 아래 30%(짧은 화면은 33%): **버튼 자리**. 중요한 내용을 두지 않고, 맨 아래 줄은 **바탕색 한 가지**로 끝나게.
- 버튼 자리에 카카오 노랑(`#FEE500`)이나 PALLO 노랑을 넓게 깔지 않아요(카카오 버튼이 묻혀요).
- 문구 · 날짜 같은 글씨는 그림 안에 넣고, 같은 내용을 `그림 설명`에도 써요(화면 읽기 프로그램용). 앱이 글씨를 따로 얹지 않아요.

### 어떤 그림을 보여 주나요

- 관리자 웹에 올린 시작 화면 중 **지금 기간 안에 있는 것**을 보여 줘요. 여러 개가 겹치면 목록에서 위에 있는 것 하나.
- 기간 안에 있는 게 없으면 **기본 화면**.
- 앱은 받은 그림을 기기에 저장해 두고, **다음에 열 때** 바로 띄워요. 화면을 열 때마다 서버를 기다리지 않아요.
- 처음 설치해서 저장된 그림이 없거나 인터넷이 안 되면 **기본 화면**을 띄우고, 뒤에서 그림을 받아 둬요.
- 예약된 다음 시작 화면도 미리 받아 둬요. 시작 날짜가 되면 인터넷 없이도 바뀌어요.
- 받아 둘 때는 세 장을 다 받지 않고, 이 기기에 맞는 한 장만 받아요.

### 버튼 규칙

- **정한 것 (2026-11-24): 로그인 버튼은 `카카오로 시작하기` 하나만** 둬요. Apple · 구글 · 휴대폰 번호 · 먼저 둘러볼게요는 없어요.
- 카카오 버튼은 카카오 공식 노랑 `#FEE500` + 검은 말풍선 심볼 + `카카오로 시작하기`.
- PALLO 노랑(`#FFE200`)과 카카오 노랑이 거의 같아요. **카카오 버튼은 PALLO 노랑 바탕 위에 올리지 않아요.** 그래서 버튼 자리(그림 아래 30%)에 노랑을 넓게 쓰지 않게 관리자 웹이 경고해요.
- ⚠ App Store 심사 규칙(4.8): 카카오 같은 외부 로그인만 있으면 Apple 로그인(또는 같은 수준의 개인정보 보호 로그인)도 있어야 해요. iOS 출시 전에 다시 정해야 해요 (Q-O11).
- 카카오 동의 창에서 취소하면 첫 화면으로 돌아오고 토스트 `로그인을 취소했어요`.

## 2. 가입 단계 (처음 로그인한 계정만)

가입 단계 모든 화면의 뒤로 버튼은 앱 공통 뒤로 버튼(`mobile/src/components/ui/back-button.tsx`: 44 칸 · 상자 없음 · ‹ 22px · 선 2.1)을 그대로 써요.

진행 바 칸 수는 고른 길에 따라 달라요: 회원 4칸(… → 회원 확인 → 연동 요청), 체험 4칸(… → 회원 확인 → 체험 예약 한 장), 앱으로만 5칸(… → 언어 → 이유). 지점 목록 시트 · 확인 중 · 예약 확정 · 약관 · 알림 · 환영은 칸에 넣지 않아요.

| 단계 | 내용 | 규칙 |
|---|---|---|
| 약관 동의 | 시트: 전체 동의 / [필수] 만 14세 이상 · 서비스 이용약관 · 개인정보 수집 · 이용 / [선택] 이벤트 · 번개 소식 받기 | 필수를 다 체크해야 `동의하고 시작하기`가 켜져요. 선택 동의는 동의 날짜를 기록 (설정 › 알림의 광고 동의와 같은 값) |
| 닉네임 | 카카오 이름을 미리 채워 둠. 추천 닉네임 버튼은 두지 않아요 | 2~10자, 한글 · 영문 · 숫자. 입력하는 동안 중복 확인. 카카오 이름이 규칙에 안 맞으면 빈칸으로 시작. 화면 글은 모두 '닉네임'. 무대 위 큰 닉네임 글씨는 카드 안(B · D)이면 1~4자 한 줄 · 5~10자 5자씩 두 줄, 화면 가로 전체(E)면 1~7자 한 줄 · 8~10자 조금 작게. 화면 밖으로 넘치거나 잘리지 않아요 |
| 캐릭터 | 몸 색 7가지(노랑 · 보라 · 보라 속눈썹 · 핑크 · 하늘 · 초록 · 코랄) | 고른 색이 마이 캐릭터의 기본 몸 색. 옷 · 소품은 마이 › 꾸미기 |
| 지점 회원이에요? | 네, 지점 회원이에요 / 체험해 보고 싶어요 / 앱 구경할래요 (칸마다 오른쪽 ›). 흰 카드에 오른쪽 끝에 걸친 팔로로(회원 보라 · 체험 분홍 · 앱으로만 노랑), **`네, 지점 회원이에요` 칸만 분홍(#DE7593) 바탕으로 강조**. '일단 구경만' 링크는 없어요(2026-11-24). **칸을 누르면 바로 다음 화면으로 넘어가요**('다음' 버튼 없음): 회원 → 지점 연동 요청, 체험 → 체험할 지점, 앱으로만 → 희망 언어 | 고른 답으로 `role` · `userType`이 정해져요. 뒤로 가면 이 화면으로 돌아와 다시 고를 수 있어요 |
| 지점 연동 요청 (회원) | 지점 · 이름 · 휴대폰 + 정보 보내기 동의 → `연동 요청 보내기` | 아래 [3. 지점 연동 요청](#3-지점-연동-요청) |
| 체험 예약 (체험) | **한 화면**에 지점 · 이름 · 번호 · 희망 언어 · 상담 시간 · 배우고 싶은 이유 → 예약 확정 → `앱 둘러보기` | 아래 [3-2. 체험 예약](#3-2-체험-예약) |
| 희망 언어 (앱으로만) | 영어 · 일본어 · 중국어 · 스페인어 카드, **여러 개 고를 수 있어요** | 실력은 묻지 않아요. 첫 AI 대화에서 맞춰요. 고른 언어마다 오늘의 목표 · 레슨이 나와요 |
| 배우고 싶은 이유 (체험 · 앱으로만) | 여행 가서 말하기 · 일 · 이직 · 유학 · 워홀 · 이민 · 시험 · 자격증 · 외국인 친구 · 새 취미 · 말하기 자신감 · 기타, **여러 개** | 체험은 상담 때 프로님이 참고, 앱으로만은 첫 주제를 고를 때 써요. 마이에서 바꿀 수 있어요. 버튼: 체험 `체험 예약하기`, 앱으로만 `앱 둘러보기` → 홈 |
| 알림 허용 | 어떤 알림이 오는지 3개 예시를 먼저 보여 줌 | `알림 받을게요`를 눌렀을 때만 기기 알림 창을 띄워요(iOS는 한 번 거절하면 다시 못 띄워서) |
| 환영 | 캐릭터 + 이름표 + `반가워요, ○○님!` + 스파크 +50 | 버튼 → 사용 가이드 |

> **정한 것 (2026-11-24):** 닉네임 화면은 **B · 작은 무대**. 위에 첫 화면 무대를 줄인 어두운 카드(흔들리는 조명 · 분홍 무대 · 팔로로 + 분홍 'HELLO,' + 흰 닉네임, 입력하는 대로 바뀜), 그 아래 크림 바탕에 질문 '무대에 오를 닉네임은요?' · '닉네임' 라벨 · 입력칸 · 도움말(오른쪽에 글자 수), '다음'은 키보드 바로 위. 카드 속 닉네임은 1~4자 한 줄로 크게, 5~10자 5자씩 두 줄로 작게 — 조명 · 무대와 겹치지 않아요. 노란 글씨는 노란 조명 위에 두지 않아요. 시안: [`prototype/onboarding-options.html`](../../prototype/onboarding-options.html) 2장.
> **정한 것 (2026-11-24):** 닉네임은 **2~10자, 한글 · 영문 · 숫자만**. 일본어 등 다른 글자와 20자는 받지 않아요. 영문은 한글보다 폭이 좁아서, 무대 카드 글씨 크기는 글자 수가 아니라 글자 폭(한글 1칸 · 영문 · 숫자 0.6칸)으로 정해요.
>
> **정한 것 (2026-11-24):** 홈 인사말 `Hey 닉네임,`은 늘 한 줄. 이름 글꼴은 영문 Unbounded, 한글 **Black Han Sans**, 일본어(받게 되면) **Dela Gothic One** 이고, 한 줄이 넘치면 이름만 30px에서 0.5px씩 줄여요(최소 20px). 한글 10자는 29.5px쯤, 일본어 10자는 27.5px쯤이 돼요. 이름이 둘째 줄 `let’s talk!`로 넘어가 겹치는 일은 없어요.

## 3. 지점 연동 요청

지점 회원 정보(이름 · 번호 · 팀 · 레벨 · 이용권)는 **지점 전산**에 있어요. 앱 계정만으로는 누가 어느 지점 회원인지 몰라요. 그래서 회원이 **연동을 요청**하고, **지점 매니저가 전산 회원과 맞춰 연동**해야 회원처럼 쓸 수 있어요.

### 들어오는 곳

- 가입 단계 '지점 회원이에요?' → `네, 지점 회원이에요`
- 처음에 `체험` · `앱으로만`을 고른 사람: 마이 › 설정 › 계정 › 내 지점 › `지점 연동 요청`, 홈 맨 위 띠 `지점 회원이라면 연동을 요청해요`
- 두 번째 지점(최대 2곳)도 같은 화면으로 요청해요.

### 요청 화면

| 칸 | 규칙 |
|---|---|
| 지점 | 필수. 칸을 누르면 **지점 목록 시트**가 올라와요: 이름으로 찾기 · 권역 칩(전체 · 서울 · 경기 · 충청 · 경상) · 권역별 25곳. 하나를 누르면 시트가 닫히고 칸에 들어가요 (이미 연동된 지점 · 요청 중인 지점은 못 고름) |
| 이름 | 필수. **지점에 등록한 이름** (앱 닉네임 아님). 2~20자 |
| 휴대폰 | 필수. 로그인 때 받은 번호를 미리 채움. '확인됨' 표시는 두지 않아요 |
| 동의 | [필수] 고른 지점에 이름 · 휴대폰 번호를 보내는 데 동의 |

`연동 요청 보내기` → 연동 기다리는 화면.

### 상태

| 상태 | 회원 화면 | 앱에서 되는 것 |
|---|---|---|
| 요청 보냄 · 지점 확인 중 (`pending`) | `○○점에 연동을 요청했어요!` · `끝나면 알림으로 알려 드려요` · 진행 표시(요청 보냄 → 지점에서 확인 중 → 연동 완료 · 회원 기능이 열려요) · [시작하기] → **앱 홈**. 기다리는 동안 안내 문구 · 요청 취소 · 지점 전화 링크는 두지 않아요 | 비회원과 같아요. **홈은 기존 홈 그대로**, 오늘 스터디(출석) 카드 자리만 연동 전 내용으로 바뀌어요 (아래). 마이 프로필 카드 이름 아래 줄은 `회원` 없이 `○○점 · 언어 Lv.n`, 그 끝에 작은 라벤더 `● 연동 확인 중` |
| 연동 완료 (`linked`) | 푸시 + **알림함 맨 위 알림** `○○점 연동이 끝났어요. 이제 회원 기능을 쓸 수 있어요`(안 읽음: 노랑 바탕 · 분홍 점, 홈 종에도 분홍 점) → 누르면 **마이**(기존 마이 그대로): 프로필 카드 이름 아래 줄 `○○점 · 언어 Lv.n · 회원` 끝에 작은 초록 `✓ 연동됨` | 회원 기능 전부: 출석 · 내 팀 · 이용권 · 프로 노트 · 라운지 참여 · 글쓰기 |
| 연동 안 됨 (`rejected`) | 푸시 + 알림함 알림 → 누르면 `○○점에서 회원 정보를 찾지 못했어요` + 지점이 남긴 말 + 보낸 정보 → [고쳐서 다시 요청하기] [○○점에 전화하기] `지금은 둘러볼게요` | 비회원과 같아요 |

- 지점마다 기다리는 요청은 하나만. 연동 안 됨 뒤에는 다시 보낼 수 있어요.
- 24시간 안에 처리되지 않으면 지점 매니저에게 알림을 한 번 더 보내고, 회원 화면 문구를 `조금 늦어지고 있어요. 급하면 지점에 전화해 주세요`로 바꿔요.
- 마이 › 설정 › 계정 › 내 지점의 `제 정보가 아니에요` → 지점 문의(전화) 안내. 잘못 연동된 건 지점이 관리자 웹에서 풀어요.
- 연동되면 `role`은 `member`, `userType`은 `member`(스터디 회원), `branchIds`에 지점이 들어가고, 지점 전산의 팀 · 레벨 · 이용권을 읽어 와요.

### 연동 전 홈의 출석 카드 (A · 잠긴 출석 카드로 정함)

홈의 다른 칸(로고 · 알림 · 인사 · 공지 띠 · 스터디 맵 · 라운지 · 탭 바)은 지금 앱과 같아요. 오늘 스터디 카드(클래퍼보드)만 바꿔요. 연동되면 원래 카드(시간 · 시작까지 · 출석체크 하기)로 돌아와요.

- 같은 클래퍼보드를 라벤더로 칠해요.
- 칸: 스터디 `미정` · 연동 `확인 중`(점이 깜빡여요) · DATE
- `STANDBY` · `Almost on stage.` · `하남점이 회원 정보를 확인하고 있어요` 한 줄
- 버튼은 점선으로 꺼 둔 `연동되면 출석이 열려요` (누를 수 없어요)

(진행 단계 카드 · 데스크 출석 안내 · 빈자리 미리보기 안은 빼기로 했어요.)

## 3-2. 체험 예약

**한 화면**(`체험을 예약해요`)에서 위에서 아래로 채워요. 화면은 스크롤되고 `체험 예약하기` 버튼은 아래에 붙어 있어요.

| 칸 | 내용 | 규칙 |
|---|---|---|
| 지점 (필수) | `지점 선택하기` 칸 | 누르면 연동 요청과 같은 **지점 목록 시트**. 지점마다 붙는 표시는 없고, `전체` 탭 옆에 지점 수(예: `전체 25`) |
| 이름 · 휴대폰 번호 (필수) | 두 칸 | 카카오에서 받은 값으로 채워 두고 고칠 수 있어요. 지점이 상담 전에 이 번호로 연락해요 |
| 희망 언어 (필수) | 영어 · 일본어 · 중국어 · 스페인어 중 하나 | 바꾸면 아래 상담 시간표가 바뀌어요 |
| 상담 시간 (필수) | 날짜(5일) → 그날 시간 칸 | 지점을 고르기 전에는 `지점을 고르면 상담할 수 있는 날짜 · 시간이 보여요` 안내만. **언어마다 상담 가능한 시간이 달라요**: 고른 지점 · 언어 프로님 일정만 보여 줘요. 마감된 시간은 흐리게 · 줄 긋기 |
| 배우고 싶은 이유 (선택) | 여러 개 고르기 | 골라 주면 상담 때 프로님이 참고해요 |
| 전달 사항 (선택) | 여러 줄 입력칸 · 최대 200자 · 글자 수 표시 | 지점에 전할 말(예: 시간 · 상담 내용 바람). 적으면 예약 확정 카드에도 보여요 |

| 다음 | 화면 | 규칙 |
|---|---|---|
| 예약 확정 | 체험 카드(지점 · 날짜 · 시간 · 상담 언어 · 예약자) | `앱 둘러보기` → 홈. 홈 맨 위에 D-n 체험 카드. 예약 변경은 마이에서 |

## 3-3. 회원 · 비회원 권한

지점이 연동해 주기 전까지는 **모두 비회원 권한**이에요(`role: guest`). 가입 단계의 어떤 길(지점 회원 · 체험 · 앱 구경 · 일단 구경만)을 골라도 그래요. 지점이 연동하면 `role: member`가 되고 아래 '회원' 칸이 열려요. 앱 구독(결제)은 지점 회원이 아니라서 비회원과 같은 권한에 **오늘의 목표** 홈 카드만 따로 있어요.

누구인지는 앱이 `role` · `link` · `trial` · `plan`으로 정해요 (`mobile/src/state/access.ts` `userKind` · `canUse`).

| 기능 | 회원 | 연동 대기 · 연동 안 됨 | 체험 예약 | 앱 구경(비회원) | 앱 구독(결제) |
|---|---|---|---|---|---|
| 홈 오늘 스터디 자리 | 출석 카드 (사전 출석 · QR 출석) | 잠긴 라벤더 카드 (연동 안 됨은 `다시 요청하기`만 열림) | 체험 카드: 체험 D-n · 날짜 · 시각, `예약 내용 보기`. 당일 `D-DAY · 오늘 ○○:○○ 상담이에요`, 지난 뒤 `체험은 어땠어요?` + `회원 등록 안내` | 둘러보기 카드 `Welcome backstage.`: `첫 레슨 해 보기` · `체험 신청하기` · `지점 회원이라면 연동 요청` | 오늘의 목표 카드 |
| 출석 · 사전 출석 · QR | ✓ | ✗ | ✗ | ✗ | ✗ |
| 내 스터디 · 팀 · 연기 · 변경 신청 | ✓ | ✗ | ✗ | ✗ | ✗ |
| 이용권 | ✓ | ✗ | ✗ | ✗ | ✗ (결제 내역만) |
| PRO'S NOTE | ✓ | ✗ | ✗ | ✗ | ✗ |
| 마이 지점 안내 게시판 | ✓ | ✗ | ✗ | ✗ | ✗ |
| 라운지 글쓰기 · 댓글 · 모임(번개 · 동아리 · 동행) 참여 | ✓ | ✗ | ✗ | ✗ | ✗ |
| 이벤트 참여 · 제안 | ✓ | ✗ | ✗ | ✗ | ✗ |
| 챌린지 만들기 · 인증 | ✓ | ✗ | ✗ | ✗ | ✗ |
| 스터디 맵 · 상황 맵 **첫 챕터** (스터디 맵 1과 · 교재마다 첫 과 · 상황 맵마다 장면 1) | ✓ | ✓ | ✓ | ✓ | ✓ |
| 둘째 챕터부터 (과 칩 · 다음 챕터 · 과 목록 · 장면 목록 · 3D 섬) | ✓ | ✗ 흐리게 + 자물쇠 | ✗ | ✗ | ✓ |
| 라운지(모든 탭) · 이벤트 · 마이 끝까지 스크롤 | ✓ | ✗ 위쪽만 (아래 잠김 칸) | ✗ 위쪽만 | ✗ 위쪽만 | ✓ |
| 설정 (마이 톱니 · 알림함 설정 아이콘) | ✓ | ✗ 흐리게 | ✗ 흐리게 | ✗ 흐리게 | ✓ |
| 좋아요 · 캐릭터 꾸미기 · 랭킹 보기 | ✓ | ✓ | ✓ | ✓ | ✓ |

**첫 챕터만 (맵 잠금)**: 비회원은 맵마다 첫 챕터를 끝까지 해 볼 수 있어요. 둘째 챕터부터는 흐리게 + 자물쇠(`회원 전용`)로 보이고, 누르면 열리지 않고 **체험 안내 시트**(`2과를 하려면` · `장면 2를 하려면`)가 떠요. 주소 · 알림으로 둘째 챕터(과 · 레슨 단계 · 장면)를 바로 열어도 `○○는 지점 회원이 되면 열려요` 칸 + 같은 안내 시트. 앱 구독(결제)은 맵이 다 열려요.

**스크롤 잠금**: 라운지(전체 · 커뮤니티 · 챌린지 · 모임 · 해외 탭 모두) · 이벤트 · 마이는 위쪽(카드 1~2개 · 마이는 랭킹 윗부분)까지만 보이고, 그 아래는 크림색으로 흐려진 뒤 `지점 회원이 되면 다 볼 수 있어요` 칸(마이는 `지점 회원이 되면 열려요`)이 붙어요. 흐린 곳을 누르면 늘 체험 안내 시트(`끝까지 보려면`). 잠긴 칸까지 **스크롤만 해도** 잠김 보기 1번으로 세요 — 화면에 들어올 때마다 한 번만.

**설정**: 회원 · 앱 구독(결제)만. 그 밖은 톱니(마이 · 알림함)가 흐리게 보이고, 누르면 체험 안내 시트(`설정을 쓰려면`). (열린 질문: 비회원 로그아웃 · 탈퇴 입구)

**잠김 보기 → 체험 권유 시트**: 누름(탭)은 세지 않아요 — 누를 때마다 체험 안내 시트가 뜨니까요. **스크롤로 잠긴 칸을 본 수**만 세서 3 · 6 · 9 …번째면 `체험해 보시겠어요?` 시트(팔로 그림 · 짧은 설명 · `상담 예약하기` → 체험 예약 화면 · `다음에 할게요`), 그 밖에는 짧은 토스트. **시트는 한 번에 하나**: 안내 시트나 권유 시트가 떠 있으면 새로 띄우지 않아요. 연동 대기는 세지 않고 토스트만, 연동 안 됨은 `[다시 요청]` 토스트.

**첫 챕터 끝 → 다음 챕터 권유**: 비회원(연동 대기 빼고)이 무료 첫 챕터를 다 끝내고 다음 챕터(칩 · 다음 챕터 버튼 · 보상 상자의 다음 코너로 · 과/장면 목록)로 가려 하면 바로 `더 다양한 사람들과 실제 대화 함께 해 보기!` 시트(지점에서 다른 회원들 · 프로와 라이브 세션 + `상담 예약하기` · `나중에`). 연동 대기는 `다음 챕터는 지점 연동이 끝나면 열려요` 토스트.

**마이**: 회원이 아니면 PRO'S NOTE · 내 스터디 · 지점 안내를 빼고, 프로필 · 숫자 4칸 · 랭킹 윗부분 아래에 **`지점 회원이 되면 열려요`** 칸 하나가 붙어요(스크롤 잠금 칸 · 열리는 것: 출석 · 내 팀 · 이용권 · 프로 노트). 아래 버튼은 연동 대기 `연동 확인 중이에요`(버튼 없음) · 연동 안 됨 `다시 요청하기` · 체험 예약 `체험 예약 보기` · 그 밖 `체험 신청하기` + `이미 회원이에요 · 연동 요청`. 랭킹 아래(배지 · 내 활동 · 설정 메뉴)는 잠김 칸 밑으로 가려져요. 메뉴의 `이용권 · 결제 내역`은 회원만(앱 구독자는 `결제 내역`).

**막혔을 때 (규칙)**: 회원만 되는 것을 누르면 **누를 때마다** — 비회원 · 앱 구경 · 앱 구독(결제, 회원 전용 기능일 때)은 **체험 안내 시트** `{이유}\n지점 회원이 되어야 해요` (`나중에 할게요` · `체험 상담 신청`), 체험 예약은 같은 이유를 제목에 단 `예약한 체험` 시트(다시 예약 없이 `예약 내용 보기`), 연동 대기는 `…지점 연동이 끝나야 해요` 토스트, 연동 안 됨은 `…지점 연동이 필요해요` + `[다시 요청]` 토스트. 앱 코드는 모두 `guardMember(실행, 이유)` · 보여 주기만 하는 잠금은 `memberGate(이유)` 한 곳으로 가요 (`mobile/src/components/common/trial-guide.tsx`).

## 4. 사용 가이드 (5장)

### 언제 보여 주나요

- **로그인에 성공하면 홈 전에** 보여요. 처음 가입한 계정은 가입 단계(환영)가 끝난 뒤에 보여요.
- **계정마다 한 번.** 끝까지 봤든 건너뛰었든 그 판(버전)은 다시 안 보여요. 기기를 바꿔도 마찬가지예요(서버에 기록).
- 관리자가 새 판을 게시하면서 `이미 본 회원에게도 한 번 더 보여 주기`를 켜면, 다음 로그인 · 앱 열기 때 한 번 더 보여요.
- **다시 보기:** 마이 › 설정 › 도움 › 사용 가이드. 여기서 볼 때는 기록하지 않아요.

### 화면

| 자리 | 내용 |
|---|---|
| 맨 위 | 왼쪽 `1 / 5`, 오른쪽 `건너뛰기` (마지막 장에서는 숨김) |
| 그림 칸 | 정사각형, 잉크 2px 테두리, 모서리 24px. 관리자가 고른 배경색 위에 올린 그림 |
| 제목 | 최대 20자, 21px 900 |
| 설명 | 최대 60자(약 2줄), 13.5px |
| 아래 | 점 5개(지금 장은 긴 막대) + 노랑 버튼 `다음`, 마지막 장은 `PALLO 시작하기` |

### 동작

- 옆으로 밀거나 `다음`을 누르면 다음 장. 반대로 밀면 이전 장.
- `건너뛰기` · `PALLO 시작하기` → 홈. Android 뒤로 가기는 이전 장, 첫 장에서는 건너뛰기와 같아요.
- 가이드를 서버에서 못 받으면 **막지 않고 바로 홈**으로 가요. 그림 한 장만 못 받으면 그 칸은 배경색만 보여요.
- 동작 줄이기가 켜져 있으면 넘길 때 미끄러지는 움직임 없이 바로 바뀌어요.
- 글씨를 크게 쓰는 기기에서는 설명이 잘리지 않고 아래로 늘어나요(버튼은 아래 고정).
- 그림에는 관리자가 쓴 `그림 설명`을 붙여요(화면 읽기 프로그램용).
- 끝까지 봤는지, 몇 장째에서 건너뛰었는지 서버에 남겨요(어느 장에서 많이 나가는지 보려고).

### 기본 내용 (예시, 관리자 웹에서 바꿈)

| 장 | 제목 | 설명 |
|---|---|---|
| 1 | 세션 날엔 QR로 출석 | 지점에 도착하면 홈 스터디 카드에서 QR을 찍어요. 전날 미리 '사전 출석'도 돼요. |
| 2 | 세션 전 5분, 미리 말해 봐요 | 라이브러리에서 오늘 배울 과의 예습을 풀어요. 세션이 끝나면 복습으로 한 번 더. |
| 3 | 세션 밖에서도 같이 떠들어요 | 라운지에서 번개 · 동아리 · 챌린지로 다른 회원과 이어져요. |
| 4 | 하루 하나면 연속 학습 | 학습 단계를 하루 1개 이상 하면 이어져요. 모은 스파크로 캐릭터를 꾸며요. |
| 5 | 내 스터디는 마이에서 | 이용권 · 연기 · 팀 변경 · 프로 노트를 한곳에서 봐요. |

1장(출석) · 5장(이용권)은 지점 회원 이야기예요. 체험 · 앱 구독자에게 다른 내용을 보여 주려면 관리자 웹에서 대상별 가이드를 따로 올려요.

## 5. 관리자 웹

관리자 웹 '홈 운영' 묶음([api-additions 2장](../frontend/api-additions.md#2-관리자-웹-api-개요-7묶음))에 메뉴 두 개를 더해요: **시작 화면**, **사용 가이드**. 둘 다 본사 운영 담당이 게시하고, 지점 매니저는 보기만 해요(제안).

### 공통 흐름

```
올리기 · 고치기 → [임시 저장] → [미리보기] (폰 틀, 기기 크기 2~3개) → [게시하기] 또는 [예약]
게시한 것은 '판'으로 쌓여요 → 이전 판 [되돌리기]
```

- 저장할 때 막는 것: 필수 칸 비어 있음, 글자 수 넘음, 그림 규격 · 용량 안 맞음, 기간이 거꾸로.
- 누가 언제 게시했는지 남겨요(목록에 `3번째 판 · 11.20 · 김매니저`).

### 시작 화면 메뉴

| 칸 | 규칙 |
|---|---|
| 그림 3장 | 모두 필수. 짧은 화면 1242 × 2208 · 기본 1290 × 2780 · 긴 화면 1290 × 2866. 크기가 정확히 같아야 올라가요. JPG · PNG · WebP, 한 장에 5MB 이하. `틀 파일 받기`로 안내선(위 5% · 버튼 자리 30%)이 그려진 틀을 받아요 |
| 바탕색 | 세 장 맨 아래 줄에서 자동으로 뽑아요. 바꿀 수 있어요. 화면이 그림보다 길 때 남는 곳을 이 색으로 채워요 |
| 그림 설명 | 필수. 그림 속 글씨를 그대로 (화면 읽기 프로그램용) |
| 저절로 확인 | 크기 · 용량, 세 장 맨 아래 줄이 바탕색 한 가지인지, 버튼 자리에 카카오 노랑과 비슷한 색이 넓게 있는지(경고). 위 5%의 글씨는 미리보기로 사람이 확인 |
| 미리보기 | 아이폰 SE · 아이폰 15 · 갤럭시 Z 플립 세 기기에 버튼을 얹은 모습 |
| 기간 | 시작일 필수, 끝나는 날은 비우면 `계속` |
| 순서 | 목록에서 끌어서. 기간이 겹치면 위가 이겨요 |
| 상태 | 임시 저장 · 예약 · 게시 중 · 끝남 (끝난 것은 `다시 쓰기`로 복사) |

### 사용 가이드 메뉴

| 칸 | 규칙 |
|---|---|
| 대상 | 전체 · 지점 회원 · 체험 · 비회원 · 앱 구독자. 대상별 가이드가 없으면 `전체`를 보여 줘요 |
| 장 수 | 5장 고정. 끌어서 순서 바꾸기 |
| 그림 (장마다) | 필수. 정사각형 1080px 이상, PNG · JPG · WebP, 2MB 이하. **글씨는 그림에 넣지 않아요**(글씨 크기 조절 · 화면 읽기가 안 돼서). 글은 제목 · 설명 칸에 |
| 배경색 | 노랑 · 라벤더 · 연핑크 · 하늘 안개 · 베이지 · 흰색 중 하나 (DESIGN.md 팔레트) |
| 제목 | 필수, 최대 20자 |
| 설명 | 선택, 최대 60자 |
| 그림 설명 | 필수 |
| 한 번 더 보여 주기 | 게시할 때 켜면 이미 본 회원도 다음에 한 번 더 봐요. 큰 기능이 바뀌었을 때만 |

### 연동 요청 메뉴 ('지점 · 수강' 묶음)

- 지점 매니저는 **자기 지점 요청만** 봐요. 본사는 모두.
- 탭: 기다리는 중 · 연동됨 · 못 찾음. 기다리는 중은 오래된 것부터, `○시간 남음`(24시간 기준).
- 줄마다: 요청 시각 · 앱에서 보낸 정보(이름 · 번호 · 앱 닉네임) · **지점 전산 회원 후보**(번호가 같은 회원을 자동으로 찾아 둠, `이름 · 번호 같음` / `번호 같음 · 이름 다름` / `찾지 못했어요`).
- [연동하기]: 후보(또는 `지점 전산에서 찾기`로 직접 고른 회원)와 앱 계정을 이어요 → 회원에게 푸시.
- [못 찾음으로 보내기]: 이유 고르기(등록된 번호가 달라요 · 등록된 이름이 달라요 · 우리 지점 회원이 아니에요 · 이미 다른 계정과 연동됐어요 · 직접 쓰기) → 회원에게 그대로 보여요.
- 연동됨 탭에서 [연동 풀기] (잘못 이었을 때). 누가 언제 처리했는지 남겨요.

## 수용 기준

- [ ] 첫 화면 그림을 관리자 웹에서 바꾸면, 앱 업데이트 없이 다음에 앱을 열 때 바뀐다.
- [ ] 첫 화면 그림이 아이폰 SE · 아이폰 15 · 갤럭시 Z 플립 · 태블릿 어디서도 잘리지 않고 화면을 다 채운다(남는 곳은 바탕색).
- [ ] 관리자 웹에서 그림 3장 중 하나라도 없거나 크기가 다르면 게시되지 않는다.
- [ ] 처음 설치 · 인터넷 없음 · 올린 그림 없음일 때 기본 화면이 뜨고, 로그인 버튼은 늘 누를 수 있다.
- [ ] 첫 화면 로그인 버튼은 `카카오로 시작하기` 하나, `#FEE500` + 말풍선 심볼이고, PALLO 노랑 바탕 위에 놓이지 않는다.
- [ ] 처음 가입한 계정만 가입 단계를 거치고, 이미 가입한 계정은 로그인 뒤 바로 (가이드 →) 홈으로 간다.
- [ ] 약관 필수 항목을 다 체크하기 전에는 `동의하고 시작하기`가 꺼져 있다.
- [ ] 닉네임은 2~10자 · 한글 · 영문 · 숫자만 되고, 이미 쓰는 이름이면 `다음`이 꺼진다.
- [ ] 지점 회원은 지점 목록 시트에서 지점을 골라 연동 요청을 보내고, `시작하기`로 바로 홈에 간다. 지점이 연동하기 전까지는 비회원 권한이다.
- [ ] 연동되면 푸시와 알림함 알림이 오고, 알림을 누르면 마이 프로필 카드 `… · 회원` 옆에 `✓ 연동됨` 표시가 보이며 출석 · 내 팀 · 이용권이 열린다.
- [ ] 체험은 한 화면에서 지점 · 이름 · 번호 · 희망 언어 · 상담 시간 · 이유를 채우고 예약 확정으로 가며, 상담 시간은 지점을 고른 뒤 고른 언어로 가능한 시간만 보인다.
- [ ] 앱으로만은 희망 언어를 여러 개 고를 수 있고, 이유까지 고르면 `앱 둘러보기`로 홈에 간다.
- [ ] 지점이 못 찾음으로 보내면 회원은 이유를 보고 고쳐서 다시 요청할 수 있다. 기다리는 요청은 지점마다 하나다.
- [ ] 지점 매니저는 자기 지점 연동 요청만 보고 처리한다.
- [ ] 사용 가이드는 로그인 성공 뒤 홈 전에 5장이 보이고, 넘기기 · `다음` · `건너뛰기` · `PALLO 시작하기`가 된다.
- [ ] 한 번 본(또는 건너뛴) 가이드 판은 다른 기기에서 로그인해도 다시 안 뜬다. `한 번 더 보여 주기`로 게시한 새 판은 한 번 더 뜬다.
- [ ] 가이드를 못 받아도 홈으로 들어갈 수 있다.
- [ ] 마이 › 설정 › 도움 › 사용 가이드에서 언제든 다시 볼 수 있다.
- [ ] 관리자 웹에서 필수 칸 · 글자 수 · 그림 규격이 안 맞으면 저장되지 않는다.
