# 레슨 (문제 풀기 · 완료 화면)

> **제안 경로:** `/lesson/:lesson/:step` · **모듈:** 레슨 · **기준:** v342
> 관련 코드: `#lesson`(레슨 진행기 `openTasks`, `RUN34`, `TKV.*`), `#study`(단계 화면 `STEP_VIEW`), `talkView`, `wcTalk`, `celebrate`, `setNoListen`, `noSpeak`, `SFX`

## 개요

라이브러리 · 스터디 맵에서 단계를 열면 화면 전체로 펼쳐지는 학습 화면이에요. **한 화면에 문제 하나**(듀오링고식 구조)이고, 다 풀면 완료(축하) 화면이 떠요. 학습의 중심은 **말하기**이고, 말하기 · 듣기가 어려운 사람도 같은 단계를 끝낼 수 있어야 해요.

## 화면 구성

| 영역 | 레슨 진행기 (`#lesson`) | 단계 화면 (`#study`: AI 프리토킹 · My Story · 역할극 등) |
|---|---|---|
| 위 줄 | 왼쪽 위 `X` · 진행 막대(노랑) · `1/9` · 오른쪽 소리 버튼 | 제목 · 오른쪽 소리 버튼 · `X` |
| 가운데 | 작은 회색 안내 → 굵은 한국어(20px) → 큰 영어(디스플레이 글꼴) | 대화 · 문단 등 |
| 아래 | 답하는 방식 · 버튼(확인 · 다음 · 한 번 더 등) · '말하기가 어려워요'(말하기 문제에서만) | 말하기 · 쓰기 탭 등 |
| 피드백 | 아래에서 차례로 떠오르는 띠: 팔로(정답 노랑 · 오답 보라) + 큰 글씨 리액션 + 한국어 뜻 + 듣기 | 같음 |

- 숫자는 위 `1/9` 하나만 보여요 (단어 수 `0/7` 같은 다른 숫자는 안 보여 줌).
- 버튼은 모두 둥근 알약(54px), 마이크 · 말하기 버튼 48px.
- 보라 팔로는 늘 있지 않고 가끔 나왔다 2.8초 뒤 들어가요: 순서 맞추기에서 틀린 카드(처음 + 세 번째마다), 두 번 연속 정답(응원). 문제 아래 ~ 버튼 위 빈 곳에, 좁으면 작아져요.

## 문제 방식 (블록)

| 블록 | 이름 | 동작 |
|---|---|---|
| `shadow` | 따라 말하기 = 카드 순서 맞추기 | 문장 단어가 섞인 카드. **말하면** 들린 순서대로 카드가 위 줄로 올라가고(노랑), **눌러서** 하나씩 올릴 수도 있어요(연보라). 순서에 안 맞는 카드는 분홍 점선 + X 배지로 흔들리고 0.9초 뒤 원래대로. 다 이으면 '완성 문장 카드'(영어 + 뜻 + 듣기 + 표현 저장)가 올라와요. **답 문장을 미리 읽어 주지 않아요** |
| `match` | 짝 맞추기 | 표현 ↔ 뜻, 30초 타임어택 · 콤보 · 최고 기록. 맞은 짝 초록, 틀린 짝 양쪽 빨강 흔들림. 결과: 걸린 시간 · 최고 콤보 · 틀린 짝 타일 |
| `order` | 줄 순서 맞추기 | 아래 줄을 순서대로 눌러 쌓기(앱에서는 끌어서 놓기). 맞은 줄 초록 · 틀린 줄 빨강 → [정답 확인하기 / 다시 도전하기]. 쌓일 때마다 다음 빈칸이 보이게 자동 스크롤 |
| `build` | 단어 카드 문장 만들기 | 정답 단어 + 헷갈리는 단어 2~3개. 누르면 위 줄에 쌓이고 쌓인 카드를 누르면 빠짐, 오른쪽 아래 작은 '모두 지우기' |
| `answer` | 질문에 답하기 | 질문 듣기 · 예시 답. 답은 '처음 답변'으로 저장 → 복습 Before / After |
| `role` | 역할 고르기 | '내 역할을 골라요' · 인물마다 색이 다른 팔로 + 역할 |
| `say` | 시간 제한 말하기 (Lv.3 · 4) | 준비 시간 · 말 시작 제한 · 말하는 시간 · 체크 항목 · 칸 나누기 · 콤보 · 모범 답. 원형 시계(3초 남으면 분홍). 1분짜리는 이어서 듣기 |
| `pick` | 고르기 | O/X · 듣고 고르기 · 빈칸 · 제한 시간 |
| `explain` · `choose` | 설명 카드 · N개 중 고르기 | — |
| `blind` | 글 가리고 듣기 | 2번까지 |
| `duo` | AI 짝과 주고받기 | — |
| `score` | 디베이트 점수 | 논리 · 근거 · 표현 · 유창성 각 5점 + MVP 문장 |

**칸 나누기** (`splitAnswer`): 말한 답을 선택 · 이유(because …) · 예시(For example …) · 사회적 관점(people · society …)으로 나눠요. 빈 칸은 분홍 점선 → [빠진 칸 채우기]로 그 칸만 다시 말해요. 앱에서는 AI가 녹음을 듣고 나눠야 해요.

## Lv.1 · 2 코너별 진행

| 코너 | 진행 |
|---|---|
| 예습 · 오늘의 패턴 | 패턴마다 예문 3개 따라 말하기 (패턴 부분 노랑 형광펜, 위 줄 '오늘의 패턴 1 · 예문 1/3') |
| 예습 · 대화문 | 8줄 순서 맞추기 → 역할(Lily / Sonya) 고르기 → 내 대사만 따라 말하기(상대 대사는 왼쪽 흰 말풍선, 내 대사는 오른쪽 노랑 + 내 인물 얼굴) → 마지막 대사 단어 카드 |
| 예습 · Word/Speaking Bank | 표현 ↔ 뜻 10쌍 짝 맞추기 |
| 본학습 · 상황 활동 (Lv.1 호텔 로비) | 교재 9쪽 그림 위 인물 이름표 → 인물을 누르면 그 사람 목소리로 먼저 말함 → [응대하기] → **응대 대화**: 손님 말(영어 + 뜻) → 나는 뜻을 보고 단어 카드로 답(카드마다 바로 채점) → 3번 주고받아 6마디. 한 칸에서 3번 틀리면 맞는 카드가 노랗게 반짝(정답을 대신 보여 주지 않음). 끝나면 주고받은 말 · 한 번에 맞힘 n/3 + [다른 캐릭터 도전하기]. 응대한 인물은 이름표가 회색, 다시 누르면 '해결했어요' + [한 번 더 하기]. 위 '도움이 필요한 손님을 눌러 보세요', 아래 '응대한 손님 0/4' |
| 본학습 · My Story | 주제 칩 고르기 → 질문 6개 키워드 칸(예시 키워드 2개 점선 칩) → [키워드로 문단 만들기](다 채우기 전엔 흐림, 누르면 첫 빈칸으로 이동 · 강조) → 완성 문단(제목 옆 스피커로 전체 듣기) → 문장 순서 맞추기 → **한 문장씩** 따라 읽기('문장 n/전체', 맞춘 문장만 글자로, 남은 문장은 회색 점선) |
| 본학습 · AI 프리토킹 | 아래 'AI 프리토킹' |
| 복습 · 스피킹 퀴즈 | 한국어 보고 영어로. 탭: 단어 카드(기본) · 말하기 · 직접 쓰기. 단어별 채점(축약형은 펼쳐서 비교, 빠진 단어는 분홍 칸). 힌트: 카드 · 말하기 2단계, 쓰기 3단계(패턴 → 시작 부분 → 단어 조각). **힌트 · 듣기 힌트를 쓰면 맞혀도 정답 수에 안 들어가요** |
| 복습 · 1분 챌린지 | 상황 카드 → 1:00 타이머 → 오늘 패턴 사용 체크 + 모범 답 → 모범 답 따라 말하고 완료 |

**My Story 키워드 검사**: 입력을 멈추고 0.8초 뒤(또는 칸을 벗어날 때) 검사. 아는 단어(예시 + 자주 쓰는 단어 `KW_COMMON`)와 한두 글자 다르면 연보라 띠 '오타 같아요 · hom' + '혹시 이 단어인가요?' 후보 2개 + [그대로 둘게요]. 'hh' 같은 단어 아님 · 한글도 알려 줘요. 고치지 않으면 문단을 만들지 않아요.

## 대체 흐름 (필수)

| 옵션 | 어디서 켜요 | 지속 | 바뀌는 것 |
|---|---|---|---|
| **말하기가 어려워요** (`noSpeak`) | 레슨 아래 버튼(말하기 필요한 문제만) · 설정 › 학습 | 15분 | Lv.1 · 2: 따라 말하기 → 같은 문장 단어 카드, 대화 추천 답은 고르면 바로 보내기. Lv.3 · 4: 시계 모두 끄고 글로 쓰기, 5초 즉답 · 변환 · 요약처럼 쓰기로 바꾸기 어려운 문제는 고르기(`alt`). AI 프리토킹은 쓰기 탭으로 시작 |
| **소리 끄기** (`noListen`) | 학습 화면 위 줄 스피커 아이콘 하나 · 설정 › 학습 | 15분, 지나면 저절로 켜짐 | 소리 안 남, 듣기 · 0.7x 버튼 숨김(소리 버튼 자신은 보임). 글 가리고 듣기 → 글 보며 읽기, 발음 듣고 고르기 → 글자 보고 혀 위치 고르기, 듣고 바로 말하는 5초 문제 → 글 보여 주고 시작 +3초, 따라 말하기 → '글을 보고 소리 내어 읽어요', 리스닝 룸 → 영어 가리기 꺼짐. 토스트 '15분 동안 소리를 꺼요' |

- 두 옵션은 같이 켤 수 있고, 다른 문제 · 코너 · 과로 가도 유지돼요.
- **소리를 꺼도 정답이 될 문장을 글로 미리 보여 주면 안 돼요.**
- 따라 말하기(카드 순서)는 늘 말하기 · 카드 누르기 두 방법이 다 되므로 '말하기가 어려워요'가 필요 없어요. 단어 카드 대화도 같아요.

## 정답 · 오답 흐름

- **틀리면 한 번 더** (정답이 정해진 문제: `pick` · 고르기 퀴즈 · `build` · 스피킹 퀴즈 · 바꿔/고쳐 말하기): 처음 틀리면 분홍 띠 'Not quite! 한 번 더'. 고르기는 틀린 보기만 지워지고, 단어 카드는 맞은 앞부분을 남기고, 말하기는 첫 단어 힌트. 두 번째도 틀리면 정답 문장이 단어 카드로 하나씩 날아와 맞춰지고 읽어 줘요.
- **따라 말하기 · 응대 대화 힌트**: 칸마다 틀린 수를 따로 세서, 그 칸에서 3번 틀리면 맞는 카드가 노랗게 반짝여요. 3번 이상 틀린 문제는 오답으로 기록돼요. 정답 공개 버튼은 없어요.
- **리액션**: 정답이면 노랑 팔로가 튀어 오르고 교재 언어 칭찬(예: Nailed it! · すごい！ · 太棒了！ · ¡Muy bien!) + 한국어 뜻. 오답이면 교재 언어 응원 + 뜻(예: おしい！ / 아깝다!).
- **같은 문장을 읽는 스피커는 한 화면에 하나만** (`dedupeSay`): 정답 카드 · 완성 문장 카드 → 리액션 → 본문 → 아래 띠 순서로 남겨요.

## 그만두기 · 이어서 하기

- `X` → '정말 그만할까요? · n문제만 더 하면 끝나요' [계속하기 / 그만하기]. 그만하면 슬픈 소리 + 멈춘 곳 저장(단계별 `ST.pos[과:단계]`).
- 다시 열면 '이어서 할까요?' [이어서 하기 / 처음부터 시작하기]. 과 화면 단계 카드엔 '이어서'.
- 실서비스: 서버에 저장해서 앱을 껐다 켜도, 다른 기기에서도 이어져야 해요.

## 완료(축하) 화면

| 요소 | 내용 |
|---|---|
| 캐릭터 | 노랑 팔로가 0.5초마다 30px 통통 점프 + 0.95초마다 춤 동작(점프 · 빙글 · 통통 · 엉덩이 · 공중제비 · 기울이기), 뒤에 빛줄기(세 색), 컨페티(브랜드 6색) |
| 제목 | 결과에 따라 (`CEL_TITLE`): 만점 '완벽해요!' 등 · 절반 이상 '훌륭해요!' · '감 잡았어요!' 등 · 절반 미만 '끝까지 해냈어요!' · '틀린 만큼 배웠어요!' 등 |
| 숫자 카드 | 한 장 3칸: 포인트(노랑) · 정확도(보라) · 오늘 목표(하늘). 아이콘 → 숫자(0부터 차오름) → 이름, 게이지 0.9초 |
| 버튼 | 왼쪽 집 아이콘 54px(홈으로 → 라이브러리 화면) + 노랑 [이어서 하기](다음 단계 열기). 마지막 단계면 노랑 버튼만 꽉 차게. 과를 다 끝내면 노랑 배경 큰 축하 |
| 소리 | 도미솔도 팡파르 |

- **최종 점수**: 문제마다 마지막 결과를 모아 '최종 점수 n / 전체'. 디베이트는 20점 → 5점 환산.
- **포인트**: 단계를 **처음** 끝낼 때만 +5 / +10 / +15P → 이번 주 포인트.
- **오늘 목표**: 학습 2개(기본). 채우면 '오늘 목표 달성! 연속 학습 n일째'.

## 수용 기준

- [ ] 모든 학습 화면 위 줄에 같은 소리 버튼이 있고, 누르면 15분 동안 소리가 꺼졌다가 저절로 켜진다.
- [ ] 소리가 꺼진 동안 어떤 문제에서도 정답 문장이 글로 미리 보이지 않는다.
- [ ] '말하기가 어려워요'를 켜면 말하기 문제가 카드 · 쓰기 · 고르기로 바뀌고 제한 시간이 꺼지며, 그 상태로도 단계를 끝낼 수 있다.
- [ ] 따라 말하기는 말하기와 카드 누르기 둘 다로 풀 수 있고, 답 문장을 다 잇기 전에는 읽어 주지 않는다.
- [ ] 한 칸에서 3번 틀리면 그 칸에 맞는 카드만 노랗게 반짝인다.
- [ ] 힌트를 쓰면 맞혀도 정답 수에 들어가지 않는다.
- [ ] 중간에 나가면 확인 창이 뜨고, 다시 열면 멈춘 문제부터 이어서 할 수 있다.
- [ ] 단계를 처음 끝낼 때만 포인트가 쌓이고, 완료 화면 숫자(포인트 · 정확도 · 오늘 목표)가 실제 값과 같다.
- [ ] [이어서 하기]는 다음 단계를 열고, 집 아이콘은 라이브러리로 돌아간다.
- [ ] AI 프리토킹에서 약한 답에는 칭찬 없이 다시 물어보고 다음 질문으로 넘어가지 않는다.
- [ ] 한 화면에 같은 문장을 읽는 스피커가 두 개 이상 없다.
