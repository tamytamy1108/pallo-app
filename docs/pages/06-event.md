# 이벤트

> **제안 경로:** `/events?tab=up|past`, `/events/:id`, `/events/new` · **모듈:** 이벤트 (하단 탭) · **기준:** v342
> 관련 코드: `lgEvBanner`, `lgPropEvent`, `lgMkEvent`, `SV_LIB` · `SV_SETS` · `SV_TPL` · `SV_TYPE`, `LG_ACCT`, `LG_DESC`

## 개요

지점 · 본사가 여는 행사(파티 · 클래스 · 여행)를 보고 신청하는 탭이에요. 라운지 화면 틀을 이벤트만 보이게 써요 (라운지 탭 줄 · 스토리 · 지도 · 글쓰기는 숨김). 회원은 이벤트를 **제안**하고, 리더 · 매니저는 바로 **열어요**.

## 화면 구성 (위 → 아래)

| # | 영역 | 내용 |
|---|---|---|
| 1 | 제목 | `이벤트` |
| 2 | 내가 제안한 이벤트 | 보낸 제안이 있을 때만: 제목 · 지점 · 희망 날짜 · 카테고리 · '매니저 검토 중 · 2~3일 안에 문자로 연락드려요' · [취소] |
| 3 | 배너 | 다가오는 이벤트 5개가 2초마다 넘어감 (손으로 넘기면 4초 멈춤, 상세가 열려 있으면 멈춤). 종류 · 지점 · D-day · 제목 · 날짜 · 금액 |
| 4 | 서브 줄 | 지점 선택 · 전체 · 파티 · 클래스 · 여행 |
| 5 | 탭 | `다가오는 이벤트 n | 지난 이벤트` (지난 쪽 개수는 숨김) |
| 6 | 목록 | 왼쪽 포스터 썸네일 96px + 종류 · 지점 · D-day, 제목(2줄), 날짜 · 장소, 금액(할인 전 금액 취소선), 남은 자리 |
| 7 | 오른쪽 아래 | [오픈하기](연필) — 라운지 + 버튼과 같은 자리 · 같은 모양, 목록이 짧아도 같은 위치 |

- 다가오는 이벤트는 **마감 임박한 순**(날짜 가까운 순, 같은 날이면 남은 자리 적은 순). 지난 이벤트는 최근에 끝난 순, 흐리게.
- 이벤트 카드 = **초대장** 모양. 라운지 추천 탭의 큰 카드에도 인원 옆에 금액(무료면 '무료').

## 이벤트 상세

[라운지 상세 공통 틀](./04-lounge.md#상세-화면-번개--동아리--이벤트-공통-틀) + 아래 차이.

| 정보 줄 (순서) | 내용 |
|---|---|
| 날짜 | 일시 |
| 장소 | 장소 이름 · 실제 주소 + 복사 아이콘('주소를 복사했어요') |
| **참가비** | 무료: '참가비 무료 · 신청만 하면 바로 확정돼요' / 유료: 금액(할인 전 금액) · '신청하면 입금 계좌를 알려 드려요' · '입금이 확인되면 확정됩니다.' |
| 인원 | 현재 / 정원 · 남은 자리 |
| **주최 · 문의** | 주최(전 지점이면 본사 이벤트팀) · 전화번호 · 문의 시간 · 담당자 + 오른쪽 **문자 버튼**(말풍선). 누르면 '문자로 문의하기' 시트(번호 · 답하는 시간 · 복사). 주최와 지점 이름이 같으면 '담당 ○○' 반복 안 함 |
| 신청 설문 | 설문이 있으면 '신청 설문 n개' |

- 긴 소개(줄바꿈 유지, 8줄 넘으면 더보기 / 접기). 예시 소개는 일정 · 포함 · 준비물 · 입금 · 취소 · 환불 · FAQ · 함께 지켜요 · 사진 촬영 안내까지 길게 들어 있어요 (모두 예시 문안 → Q-P3, Q-L5).
- 아래 고정 줄: [찜 ♡] [참가비 ~~원래가~~ / 지금가 (무료면 '참가비 무료')] [참여하기]. 내려도 계속 보여요.
- 전화 버튼 · 카톡 버튼은 없앴어요 (문자 버튼만).

### 신청 (참여 확인 시트)

| 요소 | 무료 | 유료 |
|---|---|---|
| 모임 내용 | 날짜 · 장소 · 인원 · 주최 · 비용 | 같음 |
| 신청 설문 | 있으면 답하기 (필수 * 질문은 답해야 함) | 같음 |
| 입금 계좌 | 없음 | 은행 · 계좌번호 · 예금주 + 복사 아이콘('계좌번호를 복사했어요') · '한국어 이름으로 신청해주세요.' + 문의처 한 줄 |
| 확인 체크 | '모임 내용 · 안내를 확인했어요' | '모임 내용 · 안내 · 입금 계좌를 확인했어요' |
| 버튼 | [참여하기] / 설문 있으면 [설문 보내고 … 참여하기] | [15,000원 입금하고 참여하기] |

### 신청 후 '내 신청' 카드 (제목 바로 아래)

- 무료: `내 신청 · 참여 확정`
- 유료: `내 신청 · 입금 기다리는 중` — 24시간 안에 입금 · 계좌 복사
- 내가 보낸 설문 답이 보여요.
- 참여 완료를 누르면 '참여를 취소할까요?'.

### 신청 상태 (제안)

```
(유료) 신청함 ─▶ 입금 대기 ─(입금 확인)─▶ 확정
                    └─(24시간 지남)─▶ 자리 반환 → 대기자에게
(무료) 신청함 ─▶ 확정
확정 ─(취소)─▶ 취소됨 (환불 규정 적용)
```
입금 확인 방법 · 자동 반환 여부는 정해지지 않았어요 (Q-P2).

## 신청 설문 (주최 쪽)

- 이벤트 열기 폼 안에서 만들어요. 질문 **최대 5개**.
- 질문마다: 질문 글 · 형식(하나 고르기 / 여러 개 고르기 / 짧은 답) · 보기 추가 · 빼기(엔터로 추가) · '꼭 답해야 해요' 스위치.
- 자주 쓰는 질문 바로 넣기: 2차 참석 · 음식 알레르기 · 티셔츠 사이즈 · 실력 · 같이 오는 친구 · 룸메이트. 보기가 2개 안 되는 고르기 질문은 저장 전에 알려 줘요.
- **설문 결과**(주최 · 매니저만, 회원에겐 안 보임): 응답 수, 보기별 막대, 짧은 답 목록, [엑셀로 받기].

## 이벤트 열기 (리더 · 매니저)

종류 · 지점 · 제목 · 날짜 · 장소 · 정원 · 참가비(비우면 무료) · 소개 · 포스터(여러 장) · 신청 설문 → 바로 이벤트 탭에 올라가요.

## 이벤트 제안 (회원)

| 필드 | 필수 | 내용 |
|---|---|---|
| 안내 | — | '열고 싶은 이벤트가 있다면 알려 주세요. 지점 매니저가 확인하고 2~3일 안에 문자로 연락드려요.' |
| 이벤트 사진 | * | 1장 이상, 첫 장이 대표, 누르면 대표로 |
| 진행 지점 | * | 권역별 지점 목록, 내 지점 기본 |
| 상세 주소 | 선택 | 예) 3층 세미나실 |
| 희망 날짜 | * | **1주 뒤 ~ 3달 안** 달력(달 넘기기). '매니저와 이야기하며 바뀔 수 있어요' |
| 카테고리 | * | 파티 · 클래스 · 여행 · 액티비티 · 취미 · 자기계발 · 기타 |
| 이벤트 제목 | * | 예) 한강 영어 피크닉 |
| 어떤 이벤트인가요? | — | 소개 |
| 예상 인원 | — | 10명 이하 · 20명 정도(기본) · 30명 정도 · 40명 이상 |
| 참가비 | — | 무료(기본) · 유료(금액은 매니저와 정해요) |

[제안 보내기] → '내가 제안한 이벤트' 카드. 비회원은 체험 안내 시트로 막혀요.

## 필요한 API (제안)

| API | 방법 | 경로 |
|---|---|---|
| 이벤트 목록 · 배너 | GET | `/events?status=upcoming|past&cat=&branches=` |
| 상세 | GET | `/events/:id` |
| 신청 | POST | `/events/:id/applications` (설문 답) |
| 내 신청 · 취소 | GET / DELETE | `/me/event-applications/:id` |
| 입금 확인 (운영) | PATCH | `/event-applications/:id` (status=paid) |
| 이벤트 열기 | POST | `/events` (리더 · 매니저) |
| 설문 결과 · 내보내기 | GET | `/events/:id/survey-results`, `/events/:id/survey-results.xlsx` |
| 제안 · 취소 | POST / DELETE | `/event-proposals`, `/event-proposals/:id` |
| 찜 | POST / DELETE | `/events/:id/save` |

## 수용 기준

- [ ] 다가오는 이벤트는 마감 임박한 순, 지난 이벤트는 최근에 끝난 순이다.
- [ ] 목록 · 카드에서 금액이 상세에 들어가기 전에 보인다 (무료면 '무료').
- [ ] 유료 이벤트는 신청 뒤에만 입금 계좌가 보이고, '내 신청 · 입금 기다리는 중' 카드가 뜬다.
- [ ] 필수 설문에 답하고 확인을 체크해야 신청 버튼이 켜진다.
- [ ] 설문 결과는 주최 · 매니저에게만 보인다.
- [ ] 회원의 [오픈하기]는 제안서, 리더 · 매니저의 [오픈하기]는 바로 열기다.
- [ ] 제안의 희망 날짜는 1주 뒤 ~ 3달 안에서만 고를 수 있다.
- [ ] 문자 버튼을 눌러도 화면이 사라지지 않고 시트로 번호가 보인다.
