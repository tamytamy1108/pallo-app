# 프로토타입 전용 요소

`prototype/index.html`에만 있고 **실제 앱에는 만들지 않는** 것들이에요. 개발할 때 그대로 옮기지 않게 따로 모았어요.

## 1. 화면 틀

| 요소 | 코드 | 실제 앱 |
|---|---|---|
| 폰 미리보기 틀 (390 × 844, 모서리 54px) + 뒤 '무대' 배경 `#E7E0CF` | `.device` · `--stage` | 없음. 520px 이하 화면에서는 프로토타입도 틀 없이 꽉 채워요 |
| 가짜 상태 바 (9:41 · 다이내믹 아일랜드 · 신호 · 와이파이 · 배터리) | `.fake-sb` | 없음 (520px 이하에선 프로토타입도 숨김) |
| 맨 위 고정 여백 58px | `--top` | `env(safe-area-inset-top)` (구형 아이폰 약 47 · 신형 약 59 · 갤럭시 모두 맞음) |

## 4. 흉내 낸 동작

| 동작 | 프로토타입 | 실제 앱 |

| QR 인식 | 1.8초 뒤 자동 성공 | 카메라 + QR 해석 + 서버 기록 |
| 구간 건너뛰기 테스트 | 1.2초 뒤 통과 | 실제 문항 · 기준 |
| 음성 인식 | Web Speech API (`en-US`), Chrome · Safari만. claude.ai 공유 링크 안에선 막힐 수 있음 | 네이티브 / 서버 STT + 발음 점수 |
| 음성 합성 | `speechSynthesis` + 기기 목소리(`CAST_VOICE`: Samantha · Karen · Aaron · Daniel) | 원어민 녹음, 인물별 목소리 |
| 채점 · 교정 | 기기 안 규칙 (키워드 · because · For example · 단어 수 · 몇 가지 문법 · 스펠링 1~2글자) | AI 평가 · 교정 |
| AI 대화 | 대본이 정해진 대화 | AI 응답 |
| 효과음 | Web Audio로 만든 소리 (`SFX`, `tone()`) | 사운드 디자이너 음원 |
| 전화 · 문자 | 시트에 번호만 (tel: 링크는 아티팩트 화면을 하얗게 만들어서 뺌) | 기기 문자 · 전화 앱 연결 [TBC] |
| 엑셀로 받기 | 버튼만 | 실제 파일 |
| 사진 | 브라우저에서 잘라 미리 보기 | 서버 업로드 |

## 5. 저장

| 프로토타입 | 실제 앱 |
|---|---|
| 메모리 상태 `S` · `ST` · `LG` (새로고침하면 대부분 초기화. `ST`는 데모 시각을 바꿔도 남고 '처음부터 다시'에서만 초기화) | 서버 |
| `localStorage`: `pallo-av`(꾸미기) · `pallo-chg`(변경 신청) · `pallo-pn`(프로 노트 읽음) · `pallo-set`(설정) · `pallo-sound`(효과음) · `pallo-stage-line`(카드 제목 순번) | 서버 (제목 순번 · 효과음은 기기 저장도 가능) |

- 회원 · 글 · 댓글 · 스토리 · 번개 · 동아리 · 챌린지 · 이벤트 · 동행 (`LG_FEED`, `LG_STORIES`, `LG_PEOPLE`, `LG_MEMS`, `LG_POOL`, `RANK_PEOPLE`)
