# 화면 연결 지도

## 이동

```
[홈] ─ 스터디 카드 ─▶ 출석 시트 ─▶ QR 스캐너 ─▶ 출석 완료 ─▶ [홈]
  │ ─ 스터디 맵 정류장 ─▶ 팝업 ─▶ [레슨]
  │ ─ 전체 보기 ─▶ [과 화면]
  │ ─ 종 ─▶ 알림함 ─▶ (공지 · 과 화면 · 댓글 창 · 챌린지 · 모임 상세 · 프로 노트 · 해외 동행)
  │ ─ Notice board ─▶ 공지 상세 ─▶ 공지 목록 / 공지별 버튼(이벤트 · 라이브러리)
  └ ─ 라운지 미리보기 ─▶ [라운지]

[라이브러리] ─ 맵 칩 · 섬 ─▶ 과 목록 ─▶ [과 화면] ─▶ [레슨] ─▶ 완료 화면
  │                                         │              ├ 이어서 하기 ─▶ 다음 단계 [레슨]
  │                                         │              └ 집 ─▶ [라이브러리]
  │                                         └ 리스닝 룸
  └ ─ 잠긴 섬 ─▶ 교재 소개 ─▶ 체험 신청

[라운지] ─ 카드 ─▶ 상세(번개 · 동아리) ─▶ 참여 확인 / 가입 ─▶ 가입 인사
  │                └ 동아리 상세 탭(홈 · 게시판 · 사진첩 · 채팅) ─▶ 정기 모임 회차 상세
  │ ─ 스토리 ─▶ 스토리 보기 ─▶ 댓글 창 / 참여하기 ─▶ 상세
  │ ─ + ─▶ 글쓰기 · 스토리 · 번개 열기 · 동아리 만들기 · 동행 구하기 · 해외살이 · 챌린지 열기
  │ ─ 글쓴이 ─▶ 멤버 프로필 ─▶ 동아리 상세 / 인사 / 차단 · 신고
  └ ─ (비회원) 막힌 행동 ─▶ 체험 안내 ─▶ 체험 신청

[이벤트] ─ 배너 · 목록 ─▶ 이벤트 상세 ─▶ 참여 확인(설문 · 입금) ─▶ 내 신청 카드
  └ ─ 오픈하기 ─▶ 제안서(회원) / 이벤트 열기 + 설문(프로 · 지점 관리자)

[마이] ─ 꾸미기 · 내 프로필 · 내 스터디 ─▶ 연기 · 팀 · 지점 변경
  │ ─ 프로 노트 ─▶ 노트 모음 ─▶ 노트 하나
  │ ─ 숫자 칸 · 랭킹 ─▶ 랭킹 · 퀘스트 (뒤로 ─▶ 마이)
  │ ─ 내 활동 ─▶ 내 모임 · 찜 · 내 글 · 내 표현함 ─▶ 챌린지
  │ ─ 다음 세션 · 예습하기 ─▶ [과 화면]
  └ ─ 설정 ─▶ 계정 · 알림 · 학습 · 공개 범위 · 이용권 · 결제 · 공지 · FAQ · 1:1 문의 · 약관 · 버전
```

## 들어올 때 넘기는 값

| 화면 | 필요한 값 |
|---|---|
| 출석 시트 | mode(`rsvp` · `checkin`), 고른 slot · lang |
| 과 화면 | 레벨(교재) id, 과 id, (선택) 탭 |
| 레슨 | 과 id, 단계 id, 이어서(pos) / 처음부터 |
| 리스닝 룸 | 범위(과 / 레벨 / 상황 맵), 재생 목록 |
| 모임 상세 | 모임 id, (선택) 탭(home · board · photos · chat) |
| 정기 모임 회차 | 동아리 id, 회차 id |
| 챌린지 상세 | 챌린지 id, (선택) 바로 인증 |
| 공지 상세 | 공지 id, 어디서 왔는지(목록 · 알림 · 홈) |
| 체험 신청 | (선택) 미리 고른 언어 · 지점 |
| 설정 › 알림 | 알림 칸으로 바로 스크롤 |

## 데이터 연결 (한쪽을 바꾸면 다른 쪽도 바뀜)

| 바뀌는 것 | 같이 바뀌는 곳 |
|---|---|
| 학습 단계 완료 | 홈 스터디 맵 · 과 화면 · 라이브러리 진도 점 · 섬 이름표 · 마이 다음 세션 · 연속 학습 · 오늘 목표 · 포인트 · 랭킹 |
| 출석 | 스터디 카드 상태 · 포인트 · 랭킹 · 이번 주 출석 · 이용권 사용 내역 |
| 표현 저장 | 내 표현함 · 리스닝 룸 '저장한 문장' · 챌린지 열기 표현 목록 |
| 꾸미기 저장 | 마이 캐릭터 룸 · 프로필 · 홈 스터디 맵 팔로 · 라운지에서 남에게 보이는 내 캐릭터 |
| 지점 선택 (라운지) | 피드 · 스토리 하이라이트 · 번개 · 동아리 · 지도 · 이벤트 |
| 동아리 가입 · 나가기 | 내 모임 · 채팅 입장 알림 · 게시판 가입 인사 · 멤버 목록 · 정기 모임 참석(나가면 취소) |
| 번개 열기 | 지도 숫자 · 번개 카드 줄 |
| 소리 끄기 · 말하기가 어려워요 | 모든 학습 화면 · 설정 › 학습 (같은 값) |
| 차단 | 피드 · 스토리 · 댓글에서 그 사람 글 숨김 · 설정 › 차단한 멤버 |
| 알림 읽음 | 홈 종의 빨간 점 |
| 랭킹 이름 숨김 | 남이 보는 랭킹 · 순위 |
