# 값 목록 (Enum Dictionary)

코드에 들어 있는 상태 값 · 카테고리 · 코드 목록이에요. 출처는 `prototype/index.html`의 상수 이름이에요. 예시 데이터에서만 보이는 값은 `[예시]`로 표시했어요.

## 역할

**출처:** `LG_ROLES`

| 값 | 이름 | 설명 |
|---|---|---|
| 0 | 회원 | 기본 |
| 1 | 비회원 | 체험 고객 · 게스트. 구경 · 좋아요만 |
| 2 | 프로 (예전 리더 · `pro`) | 공지 고정 · 글 숨기기 · 이벤트 열기 · 스토리 이벤트 카테고리 · 프로 출석 체크 · 프로스 노트 |
| 3 | 지점 관리자 (`manager`) | 프로 + 신고함 · 스토리 고정 · 승인 · 설문 결과 · 연동 · 체험 · 회원 요청 처리 |
| 4 | 본사 운영자 (`hq`) | 세션을 맡을 땐 프로와 같아요 |

화면 표시 무리: 멤버(`guest` · `member`) · 프로(`pro`) · 직원(`manager` · `hq`, 이름 옆 `STAFF`).

모임 안 역할: `호스트`(노랑 왕관) · `코호스트`(흰 왕관, 인원 제한 없음, 예전 이름 '서브 호스트'). 이름 옆 글자는 `HOST` · `CO-HOST`.
