# 배지 그림 (콘솔 업로드용)

app-hub › 에셋 관리 › 배지에 올리는 그림이에요. 앱 배지 칸의 입체 모양(바깥 색 고리 · 밝은 안쪽 원 · 왼쪽 위 흰 반짝임)과 같아요.

- 규격: PNG · 정확히 256 × 256 · 배경 투명(네 모서리 투명) · 1MB 이하 — 모두 맞춰 두었어요 (각 11~21KB)
- 그림이 배지 전체예요. 앱 · 콘솔 모두 그림 둘레에 동그라미를 따로 그리지 않아요
- 못 받은 배지는 앱 · 콘솔이 그림을 흐리게 그려요 — 회색 그림을 따로 만들 필요 없어요
- `.svg` 는 원본이에요. 색 · 아이콘을 바꿀 땐 svg 를 고쳐 256 × 256 PNG 로 다시 뽑아요

| 파일 | 배지 | 색 · 아이콘 |
|---|---|---|
| `streak-7` | 7일 연속 | 노랑 · 불꽃 |
| `first-hangout` | 첫 번개 | 분홍 · 번개 |
| `hangout-5` | 번개 단골 (5번) | 노랑 · 번개 — 첫 번개와 단계 구별 |
| `first-club` | 동아리 멤버 | 하늘 · 사람들 |
| `speak-100` | 말하기 100 | 민트 · 마이크 |
| `weekly-top-3` | 주간 TOP 3 | 노랑 · 왕관 |
| `popular-post` | 인기 글 | 하늘 · 하트 |
| `speak-1000` | 말하기 1000 | 은빛 왕관 방패 (높은 단계) |

파일 이름은 배지 코드 예시예요. 콘솔에서 만든 배지 코드가 다르면 그 배지에 맞는 그림을 골라 올리면 돼요.
