# 말하기(음성 인식) 시험 계획

말하기 문제에서 생길 수 있는 문제를 미리 모아, **자동 테스트**와 **폰에서 직접 하는 시험**으로 나눴어요.
코드: `mobile/src/lib/speech.ts`(듣기) · `mobile/src/lib/words.ts`(채점) · `mobile/src/components/lesson/shadow-task.tsx`(화면)

## 1. 알려진 문제와 대응

| # | 문제 | 어디서 | 대응 | 확인 |
|---|---|---|---|---|
| 1 | 말을 조각으로 보내서 앞부분이 사라짐 | 사파리 | 끝난 조각을 모아 이어 붙여요 | 자동 |
| 2 | 같은 조각을 되풀이해 보내거나, 처음부터 다시 보냄 | 사파리 | 되풀이는 버리고, 처음부터 온 건 그대로 써요 | 자동 |
| 3 | '계속 듣기(continuous)'가 첫 문장 뒤에 결과를 안 보내거나 멈추지 않음 | 사파리 | 웹은 한 문장씩 듣고, 끝나면 우리가 조용히 다시 켜요 | 자동 + 폰 |
| 4 | 끝나지 않은 듣기 위에 또 켜면 더 이상 안 들음 (3~4번 뒤 먹통) | 사파리 · 폰 | 새로 켜기 전에 이전 듣기를 완전히 끝내요 | 자동 + 폰 |
| 5 | 소리 없이 멈춤 (오류도 끝 소식도 없음) | 사파리 | 10초 동안 소식이 없으면 다시 켜요 | 자동 |
| 6 | 조용하면 저절로 끝남 | 사파리 · 아이폰(약 1분) | 사용자가 누를 때까지 다시 켜며 계속 들어요 | 자동 + 폰 |
| 7 | 끊김이 너무 잦으면 무한 반복 | 모두 | 10초 안에 8번 넘게 끊기면 멈추고 "다시 눌러요" | 자동 |
| 8 | 읽어 주는 소리(TTS) 다음에 인식이 깨지거나 TTS 소리를 마이크가 들음 | 사파리 · 아이폰 | 듣기 전에 TTS 를 끄고, 다 이으면 듣기를 끈 뒤 읽어요 | 폰 |
| 9 | 마이크 · 음성 인식 권한 거부 | 모두 | 다시 켜지 않고 "마이크를 허용하면…" 안내 | 자동 + 폰 |
| 10 | 전화 · 시리 · 알람으로 끊김 | 아이폰 | 멈추고 "전화나 다른 앱 때문에 멈췄어요" | 자동 + 폰 |
| 11 | 앱이 뒤로 감 · 화면 잠금 | 폰 | 듣기를 멈춰요 (마이크를 잡고 있지 않게) | 자동 + 폰 |
| 12 | 화면을 나가도 계속 들음 | 모두 | 화면을 나가면 듣기를 끄고 소식도 그만 받아요 | 자동 |
| 13 | 줄임말을 풀어 적음 (I would ↔ I'd) | 모두 | 인정 | 자동 |
| 14 | 짧은 낱말 모음 차이 (on · in ↔ an) | 모두 | 인정. 자음이 다르면(to ↔ do) 틀림 | 자동 |
| 15 | 띄어쓰기 자리 차이 (a nice ↔ an iced · some thing ↔ something) | 모두 | 인정 | 자동 |
| 16 | 숫자로 적음 (2 ↔ two) · 하이픈 (wifi ↔ Wi-Fi) | 모두 | 인정 | 자동 |
| 17 | 한국어 말투 (r↔l · v↔b · f↔p · 모음) | 모두 | 4글자 이상 낱말은 인정 (light ↔ right) | 자동 + 폰 |
| 18 | 군말 · 더듬기 · 고쳐 말하기 (um · I I'd · like like) | 모두 | 틀린 말로 보지 않아요 | 자동 |
| 19 | 패턴 자체를 틀림 (I like ↔ I'd like) | 모두 | 봐주지 않고 틀림 | 자동 |
| 21 | 낱말 목록으로는 끝이 없음 (an 다음엔 또 다른 낱말…) | 모두 | 낱말마다 '소리 열쇠'를 만들어 비교 — 모든 낱말에 같은 규칙. 레슨 낱말 + 자주 쓰는 낱말 100여 개에 변형을 자동으로 만들어 시험 | 자동 |
| 22 | 소리 규칙으로도 못 잇는 경우 (latte → nothing) | 모두 | 같은 칸에서 말로 2번 틀리면, 다음엔 그 자리에서 한 말을 인정 (앞뒤 낱말이 맞을 때만) · 폰 앱은 후보 3개 중 가장 잘 맞는 것 | 자동 + 폰 |
| 23 | 어디까지 정답인지 | 모두 | 앞에서부터 순서대로 맞은 데까지만 정답. 어긋난 곳부터 끝까지는 맞는 낱말이어도 전부 오답(빨강). 군말만 빼요 | 자동 + 웹 |
| 24 | 순서를 바꾸거나 다른 말을 끼움 (Do you wifi have) | 모두 | 틀림. 틀린 말 뒤에 말이 더 오면 말하는 중에 바로 표시 | 자동 + 웹 |
| 20 | Expo Go 처럼 음성 인식 모듈이 없음 | Expo Go | 말하기를 막고 단어 카드로 풀게 해요 | 웹 · 폰 |

## 3. 폰에서 직접 하는 시험 (아이폰 사파리 → 나중엔 진짜 앱)

체크하면서 해요. 이상하면 화면을 캡처하고 **"들린 말"** 에 뭐라고 나왔는지 같이 알려 주세요.

**기본**
- [ ] 문장을 끝까지 한 번에 말하기 → 카드가 다 이어지고 완료
- [ ] 반만 말하고 멈추기 → 듣기는 계속 켜져 있고 "말로 n개 이었어요"
- [ ] 아무 말 없이 20초 기다리기 → 저절로 꺼지지 않음 (버튼이 계속 분홍)
- [ ] 분홍 버튼을 눌러 멈추기 → 바로 꺼짐
- [ ] 말하기 → 멈추기를 **10번** 연달아 → 매번 들림 (3 ~ 4번 뒤 먹통 없음)

**틀렸을 때**
- [ ] 한 낱말만 바꿔 말하기 ("I'd like to have an iced latte") → I'd like to 만 이어지고, have an iced latte 는 빨강 → 이어서 "order an iced latte" 말하면 끝까지
- [ ] 순서 바꿔 말하기 ("Do you wifi have") → do you 만 이어지고, 말하는 중에 Wi-Fi 카드에 틀린 표시
- [ ] 다른 낱말 말하기 (order 대신 have) → 그 낱말이 카드에 있으면 분홍 점선 + ×, 보라 팔로 한마디
- [ ] 같은 칸에서 3번 틀리기 → 정답 카드가 반짝, 눌러서 이을 수 있음
- [ ] "I like to…" (패턴 틀림) → 첫 칸부터 안 이어짐

**말하는 버릇**
- [ ] "음… I I'd like… like to" 처럼 더듬기 → 틀림 표시 없이 이어짐
- [ ] "an" 을 "on" 처럼 말하기 → 인정
- [ ] 일부러 r ↔ l 섞어 말하기 (light 를 right 처럼) → 인정

**환경**
- [ ] 시끄러운 곳 (카페 · TV 소리)
- [ ] 작은 목소리 · 폰을 멀리 두기
- [ ] 에어팟 · 블루투스 이어폰을 낀 채로
- [ ] 다 이은 뒤 읽어 주는 소리가 나오고 → 다음 문제에서 바로 말하기 (TTS 뒤에도 잘 들리는지)
- [ ] 듣는 중에 다른 앱으로 갔다 오기 → 멈춰 있고, 다시 누르면 들림
- [ ] 듣는 중에 화면 잠금 → 다시 열면 멈춰 있음
- [ ] 듣는 중에 전화가 옴 (다른 폰으로 걸어 보기) → 멈추고 안내
- [ ] 와이파이 · 데이터 끄기 → 안내가 나옴 (사파리는 인터넷이 필요할 수 있어요)

**권한** (추후에 — 진짜 앱 빌드 때 같이)
- [ ] 마이크를 "허용 안 함" → 안내가 나오고 단어 카드로 풀 수 있음
- [ ] 설정에서 다시 허용 → 다시 들림

## 4. 진짜 앱(개발 빌드)에서 다시 할 것

사파리와 진짜 앱은 음성 인식이 달라요 (사파리 = 웹 음성 인식, 앱 = 애플 음성 인식).
Apple 개발자 계정이 생겨 개발 빌드를 깔면 **3번 목록 전체를 한 번 더** 해요.
앱에서만 되는 것: 문제 낱말 힌트(`contextualStrings`)로 더 정확하게 알아듣기.
