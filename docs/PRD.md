## 1. 제품 개요

PALLO는 **오프라인 지점의 회화 세션을 중심에 두고, 그 앞뒤를 앱으로 이어 주는 어학 서비스**예요. 언어는 영어 · 일본어 · 중국어 · 스페인어이고, 여러 지점과 해외에 있는 회원까지 한 앱에서 이어져요.

앱이 하는 일은 네 가지예요.

| 순서 | 하는 일 | 화면 |
|---|---|---|
| ① 예습 | 세션 전에 교재 과의 예습 단계를 풀어요 | 라이브러리 · 홈 스터디 맵 |
| ② 출석 | 세션 날 지점에서 QR로 출석해요 (미리 '사전 출석'도 가능) | 홈 스터디 카드 |
| ③ 복습 · 본학습 | 세션 뒤 복습, 세션에 못 온 날은 AI와 본학습 | 라이브러리 레슨 |
| ④ 이어지기 | 세션 밖에서 회원끼리 글 · 스토리 · 번개 · 동아리 · 챌린지 · 이벤트 | 라운지 · 이벤트 |

**성공 기준** (PRODUCT.md)
- 회원이 세션 사이에도 끊기지 않고 공부해요 (**연속 학습** = 그날 학습 단계를 1개 이상 하면 이어짐. 출석 기준이 아니에요).
- 실제로 입을 열어 말하는 시간이 늘어나요.

**제품 원칙** — 세션이 중심 · 말하게 만들기 · 혼자가 아니에요 · 누구나 할 수 있어요(말하기 · 듣기가 어려워도 같은 학습을 끝냄) · 하나의 PALLO(언어 · 지점이 달라도 같은 앱 · 캐릭터 · 말투).

**플랫폼** — iOS · Android에 **같은 PALLO 디자인 하나**를 써요. 뒤로 가기 · 시스템 시트 · 알림처럼 OS가 정한 기본 동작만 OS를 따라요. 실제 앱은 React Native나 Flutter 같은 크로스플랫폼으로 다시 만들어요. 프로토타입은 디자인과 동작의 기준이에요.

## 2. 대상 사용자와 역할

디자인 결정의 기준은 **회원**이에요. 다른 역할은 회원 경험을 돕는 쪽이에요.

### 2-1. 앱 역할 (권한)

프로토타입 라운지 맨 위 점선 표시(`예시 · 회원으로 보는 중`)를 누르면 회원 → 비회원 → 리더 → 매니저로 바뀌어요 (`LG_ROLES`). 이 토글은 프로토타입 전용이에요. 실제 앱은 로그인 계정의 역할로 정해요.

| 역할 | 누구 | 할 수 있는 것 | 못 하는 것 |
|---|---|---|---|
| **비회원 (체험 고객 · 게스트)** | 아직 등록 전인 사람, 지점 연동을 기다리는 회원 | 라운지 · 이벤트 구경, 좋아요(바로 됨, v291), 체험 신청 | 댓글 · 참여 · 가입 · 글쓰기 → 누르면 '함께하려면 체험부터 해요' 시트 → 체험 신청 |
| **회원** | 지점 세션에 다니는 성인 회원 | 출석, 학습 전체, 라운지 글 · 스토리 · 댓글, 번개 열기, 동아리 만들기(매니저 승인), 챌린지 열기, 이벤트 **제안**, 신고 · 차단 | 이벤트 바로 열기, 공지 고정, 신고함 |
| **리더** | 세션을 이끄는 사람 | 회원 권한 + 글 메뉴의 공지 고정 · 글 숨기기, 이벤트 바로 열기 + 신청 설문 만들기, 스토리 '이벤트' 카테고리 올리기 | 신고함, 스토리 고정 |
| **매니저** | 지점 · 본사 운영자 | 리더 권한 + 신고함(처리 전 · 처리 완료, 숨기기 · 경고 · 이용 제한 · 문제 없음), 스토리 고정 · 내리기, 동아리 만들기 승인, 이벤트 제안 검토, 신청 설문 결과 · 엑셀 받기 | — |

### 2-2. 학습 유형

| 유형 | 홈 맨 위 | 비고 |
|---|---|---|
| **스터디 회원** | 오늘 스터디 카드(출석) | 기본 |
| **앱 구독자** | '앱 구독 · 오늘의 목표'(학습 2개 깨기 · 연속 학습) + 이어서 하기 | 지점에 안 다니고 앱만 써요. 본학습(AI)이 세션 대신이에요. 구독 결제 · 무료 범위는 정해지지 않았어요 → [Q-B3](#9-열린-질문) |

### 2-3. 모임 안의 역할 (라운지)

| 역할 | 범위 | 할 수 있는 것 |
|---|---|---|
| **호스트** | 번개 · 동아리 · 챌린지 · 이벤트를 연 사람 | 소개 고치기, 공지 쓰기(동아리 게시판), 서브 호스트 정하기, 모집 닫기(번개). 프로필에 노랑 왕관 |
| **서브 호스트** | 호스트가 정한 동아리 멤버, 최대 3명 | 공지 · 정기 모임 · 가입 승인을 함께 맡아요. 흰 왕관 |

호스트 · 서브 호스트 정하기 버튼은 내가 만든 동아리의 호스트이거나 매니저일 때만 보여요. 예전 이름 '모임장 · 운영진'은 v140에서 '호스트 · 서브 호스트'로 바뀌었어요.

**홈 · 라이브러리 · 라운지 · 이벤트 · 마이** (`TABS`). 퀘스트 · 파티 탭은 v163에서 빠졌고, 이벤트는 v166에서 라운지에서 떼어 탭이 됐어요.

## 4. 핵심 사용자 흐름

### F1. 세션 날 출석 (스터디 회원)

```
홈 스터디 카드
 ├─ QR 출석 시간 전 → [사전 출석체크] → 시간 · 언어 고르기 → "20:00 · 영어 참석 알리기" → 카드 상태 '참석 예정'
 │                     (QR 시간 전이면 버튼은 "19:30부터 출석"으로 잠겨 보임)
 └─ QR 출석 시간(시작 30분 전 ~ 시작 20분 후) → [출석체크 하기]
        → 시간 · 언어 확인 (사전 출석했으면 그 수업이 골라져 있음)
        → "20:00 · 영어 QR 찍고 출석" → QR 스캐너 (위에 고른 수업 표시, '참석 정보 변경')
        → 출석 완료 시트 (출석 도장 · 팔로 · +30P · 이번 주 n번째 출석) → "좋아요, 다녀올게요"
        → 카드 상태 '입장 완료' → 세션 시작 뒤 'ON AIR · 스터디 중' (+경과 시간)
```
- 언어는 **꼭 직접 골라요**. 시트를 열면 언어가 비어 있고(점선) 버튼은 회색 '언어를 골라주세요'로 잠겨요.
- 지금 출석할 수 없는 시간대는 빗금 + '출석 마감'으로 못 눌러요 (8시반 회원이 6시를 잘못 고르지 않게).
- 사전 출석을 안 해도 바로 출석할 수 있어요.

### F2. 예습 → 세션 → 복습 (한 과)

```
홈 스터디 맵 정류장 / 라이브러리 과 목록 → 과 화면(예습 · 본학습 · 복습 탭)
 → 단계 카드 → 레슨 진행기(문제 하나씩) → 축하 화면(포인트 · 정확도 · 오늘 목표)
 → [이어서 하기]로 다음 단계 / [홈 아이콘]으로 라이브러리
```
- 한 과 = 예습 → 본학습 → 복습. Lv.1은 8단계(예습 3 · 본학습 3 · 복습 2). 레벨마다 단계가 달라요 → [pages/02](./pages/02-library.md).
- 과는 **잠금 없이 자유롭게** 골라요 (교재 중간에 합류한 회원이 있어서). 한 과 안의 단계는 홈 스터디 맵에서 순서대로 보여 줘요.
- 중간에 나가면 '정말 그만할까요? · n문제만 더 하면 끝나요' → 그만두면 멈춘 곳 저장 → 다시 열면 '이어서 할까요?'.
- 예습 답변은 '처음 답변'으로 저장돼서 복습 Before / After에서 비교해요 (Lv.3 · Lv.4).

### F3. 말하기 · 듣기가 어려울 때

- **말하기가 어려워요**: 레슨 아래 버튼(말하기가 필요한 문제에서만). 켜면 15분 동안 말하기 문제가 단어 카드 · 고르기 · 쓰기로 바뀌고 제한 시간이 꺼져요.
- **소리 끄기**: 모든 학습 화면 위 줄 오른쪽 스피커 아이콘 하나. 켜면 15분 동안 소리가 안 나고 듣기 버튼이 숨어요. 듣기 문제는 읽기 문제로, 5초 즉답 문제는 시작 시간 +3초.
- **소리 끄기 때 정답 문장을 글로 미리 보여 주면 안 돼요** (전역 규칙).
- 둘 다 같이 켤 수 있고, 마이 › 설정 › 학습에서도 같은 값을 바꿔요.

### F4. 표현 저장 → 챌린지

```
학습 중 '표현 저장'(책갈피) → 표현 카드로 저장(핵심 표현 + 뜻 + 나온 곳) → 토스트 '챌린지로 열기'
 → 마이 › 내 표현함 / 라운지 챌린지 + '챌린지 열기' → 카테고리 '표현' → 표현 1개 고르기 → 기간
 → 표현 챌린지 카드 ('나만의 문장 완성하기') → 누구나 문장 · 팁으로 참여
```
- 고친 문장(AI 프리토킹 마무리)도 저장돼요. 같은 표현의 챌린지가 이미 열려 있으면 새로 못 열고 그 챌린지로 안내해요.

### F5. 라운지에서 모임 참여

```
카드(번개 티켓 · 동아리 회원증 · 이벤트 초대장) → 상세 화면 (카드에서 바로 참여 안 됨)
 → [참여하기 / 가입하기] → 확인 시트(모임 내용 · '확인했어요' 체크해야 버튼 켜짐)
 → 번개: 참여 완료 / 동아리: '가입했어요! 가입 인사 남길래요?' → 게시판 가입 인사 · 채팅 입장 알림
```
- 가득 찬 모임은 '빈자리 알림 받기'. 참여 · 가입 취소는 확인 창을 거쳐요. 동아리에서 나가면 참석하기로 한 정기 모임도 함께 취소돼요.

### F6. 이벤트 신청 · 입금

```
이벤트 탭 → 상세 → [참여하기] → 확인 시트(신청 설문 답 · 확인 체크)
 → 무료: '내 신청 · 참여 확정'
 → 유료: '15,000원 입금하고 참여하기' → '내 신청 · 입금 기다리는 중'(24시간 안에 입금 · 계좌 복사)
   → 입금 확인되면 확정 (확인 방법은 열린 질문)
```

### F7. 비회원 → 체험 신청

```
비회원이 댓글 · 참여 · 글쓰기를 누름 → '함께하려면 체험부터 해요' 시트 [구경 계속하기 | 체험 신청하기]
 → 1 지점 → 2 언어 · 날짜(일요일 휴무) · 시간(마감 표시) → 3 이름 · 휴대폰 · 실력 · 개인정보 동의 → 예약 요약 · 오시는 길
```

### F0. 첫 실행 → 로그인 → 사용 가이드

```
첫 화면(관리자 웹 그림) → [카카오로 시작하기] / [Apple로 계속하기] / [다른 방법] / [먼저 둘러볼게요 → 비회원]
 → 로그인 성공
    ├─ 처음 가입: 약관 → 닉네임 → 캐릭터 → 지점 회원이에요? → (회원) 지점 연동 요청 / (아님) 언어 · 레벨 → 알림 → 환영
    └─ 이미 가입: 바로
 → 사용 가이드 5장 (계정마다 한 번, 건너뛰기 가능) → 홈
```

첫 화면 그림(비율별 3장, 잘리지 않고 꽉 채움)과 가이드 5장은 운영팀이 관리자 웹에서 올려요. 지점 회원은 **연동 요청 → 지점 매니저가 전산 회원과 맞춰 연동**해야 회원 기능이 열려요(그 전엔 비회원 권한). 자세한 규칙은 [pages/09-onboarding.md](./pages/09-onboarding.md).

### F8. 수강 관리 (마이)

- **연기 · 팀 · 지점 변경**: 한 화면 신청서 → '운영진 확인 중' → 신청 취소 가능. 새 일정은 오늘 + 2주 ~ 멤버십 끝.
- **홀딩**: 최대 2번, 한 번에 4주까지 → 카드에 '홀딩 신청됨'.
- **연장 · 재등록**: 상품 3개 중 고르기 → 매니저 연락.

## 5. 전역 규칙

### 5-1. 문구

- 친근한 존댓말 **해요체**, 짧게. 설명 문단 · 힌트 줄을 늘어놓지 않고 라벨 한 줄로 써요.
- 대괄호(`[지점명]`, `[과 제목]`, `[보상]`)는 실제 데이터가 들어갈 자리예요.
- 색 카드 위의 카운트다운 · 상태는 박스 · 알약 없이 글씨로 보여 줘요.

### 5-2. 브랜드 · 디자인

- 크림 바탕 + 잉크 2px 테두리 + `4px 4px 0` 딱 떨어지는 잉크 그림자. 누르면 그림자만큼 들어가요. 토큰은 `DESIGN.md`가 기준이에요.
- **캐릭터는 원본 3D 이미지 그대로** 써요. 새로 그리지 않고 색 바꾸기 · 좌우 반전만 해요.
- 시스템 이모지는 쓰지 않고 PALLO 전용 아이콘을 써요 (`ICONS`, `ICON(이름, 크기)`). 디자이너가 정식 아이콘을 만들면 같은 이름으로 바꿔요.
- 언어 색(영 `#4463A8` · 일 `#F06593` · 중 `#EA373F` · 스 `#69BE5F`)은 언어를 가리킬 때만 써요.
- 뒤로 가기 · 닫기 버튼은 모두 아이콘만(상자 · 테두리 · 그림자 없음). 과 화면은 왼쪽 `<`, 학습 중에는 왼쪽 위 `X` + 오른쪽 소리 버튼.

### 5-3. 접근성

- 기기 '동작 줄이기'(`prefers-reduced-motion`)가 켜지면 컨페티 · 깡충 · 파티클 · 자동 넘김 · 깜빡임을 끄고, 필요하면 토스트로 대신 알려요.
- 키보드 초점은 글씨 밑줄 · 옅은 보라 배경으로 보여 줘요.
- 한국어는 단어 단위 줄바꿈(`word-break: keep-all`). 344 · 360 · 375×667 · 430px 폭에서 확인했어요. 세로 740px 이하 폰은 레슨 화면을 촘촘하게.
- 새 문제 유형을 만들 때마다 **'말하기가 어려워요'와 '소리 끄기' 두 대체 흐름을 같이 설계**해요.

### 5-4. 공통 동작 패턴

- 확인이 필요한 행동(참여 취소 · 동아리 나가기 · 학습 그만두기 · 신청 취소)은 확인 창을 거쳐요.
- 내 글 · 댓글 · 인사 삭제는 되돌리기가 있어요. 차단도 되돌릴 수 있어요.
- 저장 · 복사 같은 결과는 아래 토스트로 알려요. 토스트에 '바로 보기' 같은 버튼을 붙일 수 있어요 (`toast(msg, { label, fn })`, 3.8초).
- 모든 글에 ⋯ 메뉴 → 신고하기(사유 고르기) · 차단하기.
- 긴 이름 · 긴 제목은 말줄임(…). 긴 소개글은 8줄 넘으면 '더보기 / 접기'.

### 5-5. 포인트 · 연속 학습 · 랭킹 (프로토타입 값)

| 항목 | 프로토타입 값 | 상태 |
|---|---|---|
| 출석 | +30P | 결정 필요 |
| 학습 단계 처음 완료 | 단계마다 +5 / +10 / +15P (`xp`) | 결정 필요 |
| 스터디 맵 정류장 (예전 퀘스트) | +10P | 결정 필요 |
| 오늘 목표 | 학습 2개 (`DAILY_GOAL`, 설정에서 바꿈) | — |
| 연속 학습 | 그날 학습 1개 이상이면 이어짐 | 확정 |
| 랭킹 | 개인 · 지점 대항전, 이번 주 · 이번 달 | 마감 시점 · 보상 결정 필요 |
| 스파크 | 꾸미기 아이템 사는 화폐 (마이) | 모으는 규칙 결정 필요 |

## 8. 수용 기준 (전역)

화면별 수용 기준은 각 `pages/` 문서 끝에 있어요. 아래는 앱 전체에 걸리는 기준이에요.

- [ ] 하단 탭은 홈 · 라이브러리 · 라운지 · 이벤트 · 마이 5칸이고, 같은 탭을 다시 누르면 맨 위로 부드럽게 올라간다.
- [ ] 화면 맨 위 여백은 기기 안전 영역 값을 따른다 (구형 아이폰 · 신형 아이폰 · 갤럭시 모두 상태 바와 겹치지 않음).
- [ ] 미리보기 틀 · 가짜 상태 바 · 데모 패널 · 역할 토글 · '24시간 지난 걸로 보기'가 실제 앱에 없다.
- [ ] 학습 진도 · 출석 · 사전 출석 · 표현함 · 포인트 · 꾸미기 · 설정이 서버에 저장되어 앱을 껐다 켜도, 다른 기기에서도 이어진다.
- [ ] 동작 줄이기가 켜진 기기에서 움직임이 꺼지고, 같은 정보는 글이나 토스트로 전달된다.
- [ ] 비회원은 구경과 좋아요만 되고, 댓글 · 참여 · 가입 · 글쓰기는 체험 안내 시트로 막힌다.
- [ ] 리더 · 매니저 전용 버튼(공지 고정 · 글 숨기기 · 신고함 · 스토리 고정 · 이벤트 바로 열기 · 설문 결과)이 해당 역할에게만 보인다.
- [ ] 모든 학습 문제에서 '소리 끄기'를 켜면 소리가 나지 않고, 정답 문장이 글로 미리 노출되지 않는다.
- [ ] 시스템 이모지가 화면에 없고 PALLO 아이콘만 쓴다.
- [ ] 캐릭터 이미지가 원본 3D(색 교체 · 좌우 반전만)다.

### 비즈니스 · 운영

| # | 질문 | 관련 |
|---|---|---|
