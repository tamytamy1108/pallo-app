# PALLO 3D 캐릭터 세트

원본 3D 캐릭터(`Downloads/PALLO_card_character`)의 **모양·얼굴·빛과 그림자를 그대로 두고 몸 색만 바꾼** 캐릭터 모음이에요. 모든 파일은 `3d/` 폴더에 있는 배경 투명 PNG예요.

## 팔레트 (`palette.json`)

| 이름 | HEX | 추천 쓰임 |
|---|---|---|
| 팔로 옐로 | `#FFE200` | 원본 · 축하·완료 |
| 팔로 퍼플 | `#493087` | 랭킹·레벨 |
| 버블 핑크 | `#F28CB1` | 아지트·이벤트 |
| 스카이 | `#7FA7E8` | 해외살이·안내 |
| 민트 그린 | `#5CBF8A` | 동아리·성공 |
| 코랄 | `#FF7A59` | 계절·이벤트 |

눈(검정 테두리·흰자)과 하트 코는 모든 색에서 똑같아요.

## 파일

`{포즈}-{색}.png`, 반대쪽을 보는 버전은 끝에 `-flip`

| 포즈 | 원본 | 크기 | 반전 |
|---|---|---|---|
| `upright` 정면 | `character_3d_upright.png` | 가로 1000px | 있음 |
| `tilted` 기울임 | `character_3d_tilted.png` | 가로 1000px | 있음 |
| `corner` 카드 모서리용 | `card_corner_original.png` | 가로 900px | 없음 (카드 오른쪽 아래 고정) |

예: `upright-purple.png`, `tilted-pink-flip.png`, `corner-sky.png`
색 6 × (정면 2 + 기울임 2 + 모서리 1) = 30개.

## 사용 규칙

- **원본 디자인을 바꾸지 않아요.** 얼굴·팔다리 비율·표정은 원본 그대로이고, 바꾸는 건 몸 색과 좌우 방향뿐이에요.
- 캐릭터와 **같은 색 배경**에는 두지 않아요. 예: 노랑 캐릭터는 핑크·보라 카드 위, 보라 캐릭터는 노랑 카드 위.
- 반대쪽을 봐야 할 땐 `-flip` 버전을 써요. 버튼이나 중요한 정보 쪽을 바라보게 두면 시선이 자연스럽게 따라가요.
- `corner` 이미지는 카드 오른쪽 아래에 `right: 0; bottom: 0`으로 붙이고, 카드에 `overflow: hidden`을 줘요 (원본 안내와 같음).

## 만드는 방법

원본 PNG에서 노랑~주황 계열이면서 채도가 높은 픽셀만 골라 색상을 바꾸고, 밝기(빛과 그림자)는 원본 비율을 유지했어요. 눈의 검정·흰색과 그림자는 건드리지 않아요. 새 색이 필요하면 같은 방식으로 바로 추가할 수 있어요.
