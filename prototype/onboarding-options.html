정해야 할 것

  1. 사용 가이드를 언제 보여 줄지. 시안은 '로그인 성공 → (처음이면 가입 단계) → 가이드 → 홈'이에요. 가입 단계 앞에 보여 주는 쪽도 돼요. 계정마다 한 번, 관리자가 '한 번 더 보여 주기'를 켜면 다시.
  2. 가이드 대상을 나눌지. 지점 회원과 체험 · 앱 구독자는 쓰는 기능이 달라요(출석 · 이용권). 처음엔 '전체' 한 벌로 시작하고, 필요하면 대상별로 더 올려도 돼요.
  3. 관리자 웹 범위 (PRD Q-T10). 시작 화면 · 사용 가이드는 '홈 운영' 묶음에 들어가요. 관리자 웹을 이번에 만들지 않으면, 처음엔 서버에 직접 넣고 관리자 화면은 나중에.
  4. 시작 화면마다 그림 3장. 잘리지 않고 꽉 채우려면 디자인팀이 같은 그림을 비율 3가지(짧은 화면 · 기본 · 긴 화면)로 만들어야 해요. 관리자 웹에서 받는 틀 파일로 만들면 돼요.
  5. 닉네임 시안 1 · 2 · 3 중 어느 것? 추천은 1(이름표)이에요.
  6. 지점 전산 연동 (PRD Q-T1 · Q-T2). 지점 전산에서 회원(이름 · 번호 · 팀 · 이용권)을 읽어 올 수 있어야 해요. 매니저가 요청마다 '연동하기'를 누를지, 이름 · 번호가 같으면 바로 연동할지도 정해야 해요.
  7. Apple 로그인 · 나이 (Q-L4)는 그대로 열려 있어요.
